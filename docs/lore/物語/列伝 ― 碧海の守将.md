# 列伝 ―― 碧海の守将

> 視点：[[コンラート・フォン・メーアブルク]]（[[碧晶公国]]・碧海の守将）。中核の幹との交点＝[[アウレリア・ファルケンハイト|アウレリア]]の因縁。

秩序とは、美しくあらねばならぬ。[[碧晶公国]]の貴族士官[[コンラート・フォン・メーアブルク|コンラート]]は、そう信じて生きてきた。名門メーアブルク家に生まれ、由緒ある艦隊の伝統を受け継ぎ、重厚で崩れぬ布陣を芸術の域にまで磨き上げた男――人は彼を「碧海の守将」と呼ぶ。

ある要衝の[[回廊]]を守る戦いで、コンラートは一糸乱れぬ方陣を敷いて寄せ手をことごとく跳ね返した。その冷たいまでの完璧さの前に、攻め手の猛将がただ一人、退かずに食い下がった。家名から貴族の証を自ら捨てた女――[[アウレリア・ファルケンハイト|アウレリア・ファルケンハイト]]。かつてコンラートと同じ「フォン」を戴いた世界の住人でありながら、いまや血統の通じぬ[[黎明評議会]]の旗の下にある。守将の静かな憐れみと、元貴族の燃える反骨が、回廊の出口で火花を散らした。

決着はつかなかった。だが、コンラートは知る。アウレリアの背後には、彼女に「いまだ」と短く告げる、もう一人の影があることを――回廊の流れを読み切り、三倍の軍を地の利で覆す、まだ名もなき女[[ミレイア・セルウィン|ミレイア・セルウィン]]の。

「血を捨てた者が、血の世界を脅かす」。コンラートは静かに制帽を正した。秩序の美しさを信じる彼の前に、秩序を持たぬ者たちが、別の美しさを掲げて立ちはだかろうとしている。その問いに答えを出さぬまま、守将はまた次の回廊へと向かう。
