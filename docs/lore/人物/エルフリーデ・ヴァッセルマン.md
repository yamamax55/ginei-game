# エルフリーデ・ヴァッセルマン

> 「算盤侍」――数字に強い能吏。碧晶公国式部省に在って、人事・選叙を司る。

## 概要
[[碧晶公国]]の[[官僚|文官]]。43歳。**式部省**（人事・選叙）に属し、官職は**式部少丞**、位階は**従六位上**。文才（運営・情報）を本領とし、旧連合貴族の世襲公領。古い官制と門閥の格式が政務を律するなかで実務の屋台骨を担う。

## 容姿
冷静沈着、感情を読ませない静かな美貌。碧晶公国の文官正装に従六位上の位色をまとう。43歳。

## 来歴
- 碧晶公国の市井に生まれ、名門の家塾に学んだのち碧晶公国式部省に任官した。
- 考課を重ねて従六位上に叙され、現在は式部少丞として人事・選叙にあたる。

## 性格・信条
- 慎重で口数少なく、機を見て確実に動く。
- 信条は**門閥主義**。碧晶公国の理念「正統なる権威による統一の再建」との距離が、時に去就を左右する。
