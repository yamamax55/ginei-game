# 祝祭（しゅくさい）

> [[環暦]]の節目を彩る記念日と祭儀。建国の誇り、灯の喪、[[信仰]]の祈りが、同じ game-time の上に折り重なる。

> ⚠️ 暦そのものの正は `GameClock`/`GameDate`。祝祭は暦境界（日/月/年）に相乗りするフレーバー＝独自の時計を作らない。

## 全銀河に共通の日
- **喪の日（環暦元日）**――[[灯台|首座灯]]停止の日（[[環暦|CE1]]）。全勢力が黙祷を捧げ、[[回廊]]に還らぬ者を悼む。唯一、敵味方が剣を収める日とされる（守られぬことも多いが）。

## 各勢力の建国記念
| 勢力 | 記念日 | 由来（→ 会戦） |
|---|---|---|
| [[鉄環兵団]] | 鉄環の日（CE5） | [[スサノオ攻略戦]]。武で本営を奪った日 |
| [[碧晶公国]] | 玉座祭（CE6） | [[アマテラス継承戦]]。正統を競い公国成る |
| [[自由港同位体]] | 五海祭（CE7） | [[ワタツミ港湾防衛戦]]。併呑を退け自立 |
| [[黎明評議会]] | 連邦の誓い（CE8） | [[アコンカグア連邦結成戦]]。植民星が連帯 |
| [[灯心自由市ファロス]] | 灯明祭（CE9） | [[ツクヨミ自由市防衛戦]]。攻囲を耐え独立 |

## 信仰の祭儀（→ [[信仰]]）
- **聖灯節**（灯統教会）――首座灯の再臨を祈る荘厳な典礼。[[碧晶公国]]で国家儀礼を兼ねる。
- **掲灯の集い**（黎明福音派）――各人が己の灯を掲げる会衆の祭。[[黎明評議会]]の自治の気風と結ぶ。
- **環の黙想**（環理の道）――万物の巡りを観想する静かな斎日。[[自由港同位体]]の交易民に浸透。
- **星骸の夜**（故地回帰派）――秘された狂信の儀。表に出ず、複数勢力に信徒が潜む。

## 市井の祭
- 港の市（[[自由港同位体]]・[[灯心自由市ファロス]]）、植民星の収穫祭（[[黎明評議会]]）、宮廷の叙任式（[[碧晶公国]]・→ [[封土|叙任]]）。

## ゲームデータ参照
- 暦の正は `GameClock`/`GameDate`、境界の発火は `CalendarDispatcher`（per-day/month/year フック）。祝祭日は民心・士気の小バフ等のフレーバー・フックに使える（数値は内政側に委譲）。表示は `TimeDisplay`（二重暦）。
