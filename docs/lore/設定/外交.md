# 外交（がいこう）

> 多極の世は、剣だけで決まらない。同盟と裏切り、不可侵と属国――関係の網が、誰と誰が敵かを刻々と書き換える。

## 関係の状態
勢力の間柄は、固定の「敵か味方か」でなく、移ろう**状態**として表される：
- **平時**――敵対も同盟もない通常の間柄。
- **同盟**――共に戦う盟約（→ [[条約]]）。
- **不可侵**――互いに矛を向けぬ約束。多極の牽制の要。
- **属国**――一方が他方の保護下に入る従属。
- **交戦**――戦争状態（→ [[戦争]]）。

加えて各ペアは**好感度（opinion）**を持ち、援助や裏切りで上下する。交戦は敵対、同盟・不可侵・属国は非敵対を上書きし、平時は素の勢力判定（思想差）に戻る。

## 多極の綱引き
[[諸侯]]四勢力と[[都市国家]]が割拠する世では、固定の主敵は置かれない。中立の[[自由港同位体]]・[[灯心自由市ファロス]]が不可侵を広く結んで均衡を保ち、[[黎明評議会]]は反専制で連帯し、[[碧晶公国]]と[[鉄環兵団]]は専制と征服で警戒される――関係の網のどこかが切れれば、戦端は連鎖する。

## ゲームデータ参照
- 敵対判定の唯一の窓口は `FactionRelations.IsHostile`。関係の正は `DiplomacyState`（opinion＋状態）／`DiplomacySession`、遷移は `DiplomacyRules`（締結・破棄・宣戦・講和）、AI判断は `DiplomacyAiRules`。年次オーケストレータ `DiplomacyTickRules`（`GalaxyView.RunDiplomacyTick`）。観測＝Y（外交＝関係マトリクス）。各勢力の外交姿勢は[[星骸の諸侯#各勢力を多層でたどる|各勢力の外交]]ノート。
