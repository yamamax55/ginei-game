# ドラッカー『マネジメント』参考設計（EPIC #1668・MGMT）

> 参照元：ピーター・ドラッカー『マネジメント（エッセンシャル版）』（ダイヤモンド社）。
> 経営学の古典。**「組織を成果のための器官にする」**思想——目的の定義・目標管理（MBO）・知識労働者の自律・連邦分権——を体系化した実践経営論。
> 本ドキュメントは、当プロジェクト（Ginei＝銀英伝風の星間国家戦略＋省庁/組織/人事の純ロジック大系）にとって**役に立つ構造パターンだけ**を抽出し、EPIC `#1668` として issue 化する提案。
> **著作権注意**：固有名・文章・固有図表・固有設定は流用せず、**経営メカニクス／組織論の構造パターンのみ**を参考にする。

## 0. なぜ「ドラッカー『マネジメント』」が本システムに役立つか

当プロジェクトは人事・組織の**構造純ロジックを大量に保有**している（[CLAUDE.md] 参照）：

| 既存（構造・抽象） | カバー範囲 |
|---|---|
| `Organization`/`SuccessionRules`（#812/#814/#816） | カリスマ/制度化/崩壊/英雄死後の継承 |
| `Person`/`PersonRules`（#866） | 軍人/文民・適材適所・役割一致Effectiveness |
| `OfficeRules`/`GovernmentRegistry`（GOV-1/3） | 役職・任命資格・提案権限 |
| `MinistryRules`/`Ministry`（GOV-5 #158） | 省庁ツリー・配属・省益摩擦 |
| `AutonomyRules`/`CommandDoctrine`（#544-550） | 集団依存vs自律分散・創発シナジー |
| `GrowthRules`/`Growth`（Wave1 #537-543） | 経験→実効能力成長 |
| `MeritRankRules`（#900-905） | 戦功→爵位・制度駆動インセンティブ |
| `SeniorityRules`（#155/156） | 席次vs実力 |
| `FactionStateRules`/`FactionState` | 王朝/統治体/組織/共同体の合成 |

**しかし、これらは「構造的適合性と制度の完全性」という静的設計**であり、ドラッカーが固有に描く以下が**欠けている**：

| ドラッカーが固有に持つ視点 | 当プロジェクトでの欠落 |
|---|---|
| **事業の定義（Theory of the Business）** | 組織がなぜ存在するかを問い、前提が陳腐化したときに再定義する回路がない。`DynastyRules.腐敗`（道徳的腐食）とは別の**戦略的陳腐化**（正しい組織が間違った目的を持ち続ける）が無い |
| **目標管理 MBO（成果目標vs実績の自己統制ループ）** | 安定度・正統性・結束などの現在状態はあるが、**「この組織・役職は何を達成すべきか」の目標設定と達成評価のループ**が無い。すべての組織は目標なしに動く |
| **知識労働者の生産性（支援≠管理）** | `PersonRules.Effectiveness`（役割一致）があるが、**管理強化でパフォーマンスが下がり・自律と目的整合で上がる**知識労働の逆説が無い |
| **連邦分権の動学（自律vs統制のスペクトル）** | `AutonomyRules`は2値（集団依存/自律分散）。**分権化の程度と本社肥大リスク、部門自律と全体整合の緊張**という連続スペクトルが無い |
| **成果が権限を正当化する** | `Regime.正統性`は歴史的継承。**「成果を出し続けない役職は制度的に退場する」**メリトクラティックな正統性回路が無い |
| **体系的廃棄（成果なき事業の計画的撤退）** | 研究・建艦・省庁が自動継続。**「成果が出なければ廃棄し資源を再配分する」という能動的選択**が無い |
| **官僚制の自己目的化（成果でなく手続きを守る組織病）** | `MinistryRules.sectionalismFriction`は省益対立。**組織が手続きや自己維持を目的にすり替えていく漸進的病理**の軸が無い |

**結論**：ドラッカーは当プロジェクトの静的人事/組織大系に**「成果というベクトル」**を与える。①**事業の定義** ②**目標管理MBO** ③**知識労働者の自律** ④**連邦分権の動学** という4欠落軸が最大の貢献。省庁#158・組織#812・人事#866 を「**成果で測られる経営組織**」へ昇格させる。タイクン化回避＝高位の決断（ミッション・分権度・廃棄）→エンジン駆動→創発帰結。

## 1. 役に立つ視点（要約）

ドラッカーの組織論を、**本システムに効く形**で1行ずつ：

1. **「組織の目的は何か」が戦略の起点**。目的を失った組織は活動量を増やすほど衰退する（活動と成果の乖離）。→ `FactionState`の正統性崩壊に**目的喪失という新ルート**を追加。
2. **成果は目標によってのみ測れる**。目標なき組織は意図せざる方向に漂流する（MBO）。→ 役職・省庁・艦隊に**達成すべき目標と自己統制評価**を与える。
3. **知識労働者は管理されると萎縮し、貢献の場を与えられると増殖する**。強権的管理は生産性の天敵。→ `AutonomyRules`/`PersonRules`に**管理強化→逆効果**の非線形をかける。
4. **分権化は革新の温床、中央集権化は調整の武器**。どちらも絶対値で良い/悪いはなく、課題による使い分けが要る。→ `MinistryRules`/`CivilianControlRules`に**分権度スペクトルと本社肥大警戒**を付与。
5. **成果が出ない事業を廃棄しないと、革新への資源が枯渇する**。継続のデフォルト化が組織を老化させる。→ 体系的廃棄を`FactionState.Tick`のトリガーとして組み込む。
6. **官僚制の病：組織が手続きを守ることを目的に置き換える**。→ `MinistryRules.sectionalismFriction`の**自己目的化軸**として具現化し、崩壊リスクに連動させる。

## 2. 取り入れるべきメカニクス（優先度つき・既存への接続）

> 大原則：**省庁#158/組織#812/役職GOV-1/人事#866 を作り直さない**。MGMT はそれらに**欠落軸を足し、接続する**だけ（additive）。

### ★★★ 最優先（真の欠落・ドラッカーの signature）

#### MGMT-1 事業の定義（ミッション）と目的喪失・陳腐化→再定義
- 各勢力/組織が**ミッション**（顧客×価値）を持つ。ミッションと実態の乖離→目的喪失。前提の陳腐化（成功が目的を風化させる）→再定義を迫る回路。
- 接続：新 `MissionRules`/`Mission`（純ロジック・test-first）。`FactionState.Regime.正統性` に目的整合度を係数として接続。

#### MGMT-2 目標管理（MBO）＝成果目標 vs 実績・自己統制で評価
- 役職・省庁・勢力が**達成目標**を持ち、実績と差分を自己統制（上からの管理でなく目標に基づく自律点検）で評価。慢性未達→制度的退場（MGMT-5 接続）。
- 接続：新 `ObjectiveRules`/`PerformanceTarget`（純ロジック・test-first）。`GovernmentRegistry`（役職台帳）×`FactionState`。

#### MGMT-3 知識労働者の生産性（貢献=役割一致×動機×自律裁量・実効値パターン）
- 知識労働者（提督・文官・研究者）の**生産性は貢献で測る**：役割一致（既存）×**動機**（ミッション整合）×**自律裁量**（管理強化で低下）。基準値は非破壊（実効値パターン）。
- 接続：新 `KnowledgeWorkRules`（純ロジック・test-first）。`PersonRules`#866（適材）×`AutonomyRules`×`MeritRankRules`#900 の生産性版。HCM#992 に配線。

### ★★ 高（組織構造の動学を足す）

#### MGMT-4 連邦分権（事業部の自律 vs 本社統制・本社肥大・遠心力）
- 分権度スペクトル（集権↔分権）と**本社肥大リスク**：分権化は革新↑・調整コスト↑、集権は調整↑・官僚化↑。どちらに傾くかで`OrganizationTheory`のトレードオフを表現。
- 接続：新 `DecentralizationRules`（純ロジック・test-first）。`MinistryRules`/`CivilianControlRules` の統制-分権軸として拡張。`AutonomyRules.CommandDoctrine` に連続性を与える。

#### MGMT-5 マネジメントの正統性＝成果が権限を正当化（慢性未達→制度的退場）
- 職位の権限は成果によって正当化される。**長期未達成は制度的退場**（解任・組織縮小）トリガー。
- 接続：`ObjectiveRules`（MGMT-2）×`GovernmentRegistry`（任命/解任）×`OfficeRules`（就任資格）。

#### MGMT-6 体系的廃棄＝成果なき事業/部署/研究を計画的に捨て機会へ再配分
- 年次で事業・部署・研究プロジェクトの**収益性**（コスト対成果）を評価し、閾値割れを廃棄。解放資源を革新的事業へ再配分。
- 接続：新 `AbandonmentRules`（純ロジック・test-first）。`MinistryRules`（省庁廃止）×`ResearchRules`（研究中止）×`ShipyardRules`（造船キャンセル）×`CalendarDispatcher`（年次トリガー）。

### ★ 中（組織病理・世界観lore）

#### MGMT-7 マネジメントの病＝官僚制の自己目的化（省益肥大が成果を侵食）
- `MinistryRules.sectionalismFriction`（既存・省益摩擦）を**自己目的化軸**に拡張：手続き優先度が成果優先度を侵食する漸進的病理。`FactionState.IsCollapsing` へのリスクルート。
- 接続：`MinistryRules` 拡張＋`FactionStateRules.Stability` への係数追加。純ロジック test-first。

#### MGMT-8 （lore）経営思想の開示データ
- 「目的を問え」「廃棄は革新の母」「知識労働者は管理しない」「成果なき継続は衰退」。
- 接続：**コード新設せず** `DisclosureLedger`（FND-4）への**lore データ入力**のみ。

### ❌ 不採用（重複・既存で十分・タイクン化）

| 不採用 | 理由 |
|---|---|
| 省庁ツリー/配属/省益そのもの | `MinistryRules`#158 が既にカバー |
| 役職・任命・就任資格・提案権限 | `OfficeRules`/`GovernmentRegistry`（GOV-1/3）が既にカバー |
| 適材適所・軍人/文民の役割一致 | `PersonRules`#866 が既にカバー（貢献=動機ルートだけ足す） |
| 制度化投資・カリスマの継承 | `Organization`/`SuccessionRules`#812 が既にカバー |
| 財政・予算編成の数値モデル | `FiscalRules`#161/162 が既にカバー（廃棄の決断だけ足す） |
| 人事評価マイクロゲーム（査定UI） | タイクン化回避＝係数で背景的に効く |
| 顧客満足/マーケティングのシミュ | `MarketRules`#179/支持#113 に集約済み |
| コンサルテーション/変革管理の手続き | 高位の決断に収束（手続きUI新設しない） |
