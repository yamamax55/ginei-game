# 第二章 ―― 名もなき旗

物語は、銀河の片隅、痩せた辺境星域から始まる。

主人公は、ある小諸侯に[[封土|叙任]]された一個の艦隊を率いる、名もなき指揮官である。預けられた船はわずか。[[封土]]は貧しく、隣接する[[回廊|要衝]]はことごとく、はるかに強大な諸侯の手にある。最初の戦いは、栄光のためではなく、生き延びるための戦いだ。通商破壊から痩せた交易船団を守り、[[回廊]]の細い分岐を縫って追手をまき、自分より数倍も大きな敵艦隊を、地の利と陣形の妙だけで出し抜く。一度の判断の誤りが、艦隊の全滅と封土の消滅を意味した。

それでも、勝てば兵が増え、要衝をひとつ奪えば次の戦への足がかりができる。主人公は小さな勝利を積み重ね、近隣の小諸侯を従え、あるいは降し、やがて辺境にひとつの勢力を築いていく。負け戦の殿（しんがり）で部下に己を逃がさせた借りを、次の戦で返す。そうして人は、主人公の旗の下に集まりはじめる。

集う者の素性はさまざまだ。滅んだ家から流れてきた老練な参謀。功を立てても血統ゆえに重用されなかった、貴族領あがりの猛将。理想に倦んで議会を去った若い戦術家。そして、敵だったはずなのに、戦場での主人公の采配に惚れ込み、主君を見限って降ってきた者すらいた。だが、来る者があれば、去る者もある。恩賞に不満を抱いた将が、より大きな禄を約束する隣国へ寝返り、昨日まで味方だった配置の弱点を敵に売る。主人公は、戦場の采配だけでなく、人の心の[[旗幟]]をも読み、繋ぎとめねばならなかった。武で奪った版図は、信なくしては一夜で瓦解する。それを、主人公は幾度もの裏切りを通して学んでいく。

辺境にも、噂は届く。――近ごろ、各地の戦の様相が、根本から変わってきた、と。ある諸侯が、停止していたはずの[[灯台|地方灯台]]を再起動させ、これまで死んでいた回廊を「**開いた**」というのだ。死んだ航路を生き返らせる力は、すなわち戦略地図そのものを書き換える力である。それを持つ者は、誰も予期せぬ方角から艦隊を送り込み、難攻不落とされた要衝を、まるで裏口から入るように背後から衝ける。逆に、生きた回廊を「**閉じて**」敵の補給線を断ち、無傷のまま一国を飢えさせることすらできる。

[[灯台]]を制する技術――それは失われた[[大環状連合|連合]]の遺産であり、断片化した銀河を再び一つに束ねうる、唯一の鍵だった。そして今、その断片が、諸侯たちの争奪の的となりつつあった。辺境の小勢力にすぎなかった主人公もまた、否応なくその奔流へと巻き込まれていく。
