# 幕間 ―― 回廊の会戦

この時代の戦は、平らな宙域での力比べではない。すべては[[回廊]]の地形の上で起こる。

[[回廊|要衝星系]]の周りには、太い本流と、いくつもの細い分岐が複雑に絡み合っている。攻める側は、どの回廊から、どれだけの艦隊を、どの順で流し込むかを賭ける。守る側は、敵がどこから現れるかを読み、限られた艦隊をどの出口に置くかを賭ける。本流から大艦隊が押し寄せると見せて、細い分岐から精鋭を回り込ませ、敵の側面――脆い横腹を衝く。あるいは退路の回廊をわざと一本だけ残し、そこへ敵を追い込んで殲滅する。

[[ミレイア・セルウィン|ミレイア]]の名を辺境に轟かせたのも、こうした一戦だった。三倍の兵を擁する隣国の征伐軍に対し、彼女は正面でわざと押され、じりじりと後退してみせる。〈[[グリニッジ]]〉の艦橋で、ミレイアはただ静かに回廊の流れを読んでいた――どの分岐が今もかすかに生きているか、敵がどこまで深追いすれば退路を失うか。敵が勝ちを確信して伸びきった、まさにその瞬間。彼女は[[アウレリア・ファルケンハイト|アウレリア]]に短く告げた。「いまだ」。

伏せられていた別働隊が、死んでいたはずの細い回廊を抜けて敵の背後に現れる。先頭を駆けるのは大時鐘の名を負う〈[[ビッグベン]]〉。アウレリアの猛攻が、刻を告げる鐘のように敵陣の横腹へ突き刺さった。挟撃。陣形を崩した大軍は、狭い回廊の出口で次々と各個に討ち取られていく。**ミレイアが刻を読み、アウレリアが刻を告げる**――守勢の知将と攻勢の猛将、二人の呼吸が、三倍の数をあっけなく覆した。数で劣る者が、地の利と陣形、そして読みで数を制する。それが、この乱世の戦の妙であった。
