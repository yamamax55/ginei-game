# ティエポロ海運

> [[自由港同位体]]の海運。船主[[ルチア・ティエポロ]]が率いる。

## 概要
[[自由港同位体]]を本拠とする**海運**。船主の[[ルチア・ティエポロ]]が興した商会で、財力は**中堅**と目される。港と航路を回し、自由港同位体の経済を裏から支える。

## 事業・経営
- 主力＝海運。財産は**投資**で運用。利潤は法人税ぶん国庫へ（私有企業）。

## 関係

- 主・創業者：[[ルチア・ティエポロ]]（船主）
