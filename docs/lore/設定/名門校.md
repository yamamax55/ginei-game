# 名門校（めいもんこう）

> 提督と官僚を生む揺籃。**どこで・誰が学ぶか**が、その勢力の出世の形そのものを映す。

> ⚠️ 候補母数・任官の正は `MilitaryAcademyRules`/`UniversityRules` 等。ここは学び舎の像＝二重管理しない。観測＝U（教育）。

## 首席という栄誉
[[黎明評議会|連邦]]の士官学校では、卒業時の席次が初任官と将来を左右する。中核の[[ミレイア・セルウィン]]は**首席任官**（22歳・新任少尉）、親友[[アウレリア・ファルケンハイト]]は**次席**――身分でなく成績で並んだ二人は、「お前が読み、わたしが斬る」の原点をここで結んだ。

## 失われた学園
- **環状学園**――[[大環状連合]]が銀河中の英才を集めた最高学府。崩壊とともに散り、その卒業者の系譜を引くことが今なお一種の権威とされる（騙る者も多い）。

## ゲームデータ参照
- 士官の輩出は `OfficerAcademyRules`/`MilitaryAcademyRules`（幼年学校→士官学校→大学校の多段選抜）、文民は `UniversityRules`（科挙型は `ImperialExamRules` の多段選抜＝進士のみ登用）。就学率・質は教育チェーン（幼→小→中→高）＝`GalaxyView.BuildEducationDump`。観測＝U。
