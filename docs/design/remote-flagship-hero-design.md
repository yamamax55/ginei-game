# 〔廃止〕MOBA要素の落とし込み（検討記録）

> **本構想は廃止。** MOBA の「リスポーン」「アイテム購入」「1体集中のヒーロー没入」を本作へ載せる検討を行ったが、**MOBA要素は廃止**の判断に至った（本作の identity ＝ RTS艦隊戦＋戦略シムに載せない）。EPIC #2747（ヒーロー会戦モード）と配下 HERO-1〜11／#2757 はクローズ。
> 本書は「何を検討し、なぜ廃止し、何を残したか」の記録として残す。

## 経緯
1. MOBA を落とし込む検討＝リスポーン（予備旗艦の遠隔再投入）／戦功ショップ／会戦内レベリング／賞金首没入／1体直接操作。
2. リスポーン・購入は**戦略レイヤーの艦隊消耗と喧嘩する**ため先に見送り（HERO-8 #2760／HERO-10 #2762）。
3. 操作体系の MOBA 化（直接操作＋Q/W/E/R）へ寄せる方針に転換。
4. 最終的に **MOBA要素そのものを廃止**。EPIC #2747 ＋ HERO-1〜11／#2757 をクローズ。

## 残したもの（MOBA非依存）
- **Q/W/E/R アビリティバー** → #2752（旧 HERO-4）＝「**通常会戦で戦法/号令をキー即発動する操作改善**」として独立存続。MOBA没入とは無関係。`ActiveCommandRules`#2175／号令 SGT-2／采配ゲージ SGT-1／`GameInput`#107 に接続。
- **遠隔座乗の lore** → `docs/lore/設定/遠隔座乗.md`＝「提督は根拠地の〈感応座〉から旗艦を遠隔に指揮する（旧連合の遺産技）。旗艦撃沈≠提督の死／根拠地喪失で提督の運命」。**既存ゲームの俯瞰指揮と捨てがまり仕様の辻褄を良くする世界観**として残す（MOBA非依存）。

## 廃止したもの
- リスポーン／戦功ショップ／会戦内レベリング（#2757）／1体集中のヒーロー没入・直接操作・AI委任・賞金首没入・モード切替・会戦目標バフ・階級投入コスト・最終能力合成式（HERO-1〜11）。
