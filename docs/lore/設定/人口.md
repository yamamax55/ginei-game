# 人口（じんこう）

> 国の地力は人にある。生まれ、老い、移り住む人々の流れが、徴募源と税源と民心の土台を成す。

## 人口の局面
惑星の人口は年齢のコホートで捉えられ、若年が多ければ伸び盛り、老年に偏れば従属指数が上がり活力を失う。出生と死亡が局面を決め、人口の厚みが軍の徴募源（軍属）と労働力（→ [[労働]]）と税源（→ [[財政]]）を同時に支える。

## 人が動く
人は住みよい星へ移る。生活水準・賃金・治安の高い星系へ流れ、痩せた星から離れる――この**移住**が、星々の盛衰を静かに均し、時に亡命の波を生む。魅力ある星は人を吸い、荒れた星は人を失って細る。

## 思想を運ぶ人々
人口は数だけでなく**思想**を抱える。占領しても住民の思想は即は変わらず、不一致は[[黎明評議会連邦憲章#第五章　専制への抵抗権|抵抗]]の温床となる（→ [[身分]]）。移民は思想も持ち込み、星系の色を塗り替えていく。
