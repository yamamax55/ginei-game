# 言語（げんご）＝言葉の二重構造

> 「カウ（牛）」と「ビーフ（牛肉）」――育てる者と食らう者は、同じものを別の名で呼ぶ。階級は、舌に刻まれている。

## 歴史的背景（なぜ言葉が割れたか）
旧[[大環状連合]]は、銀河を一千年束ねた**高等文化の超国家**だった。その洗練された**宮廷語**――統べる側・消費する側の、装飾的で抽象的な「征服者の言葉」――が、各地の植民星に根づいた**在来語**――育てる側・生産する側の、泥臭く直感的で力強い「土着の言葉」――の上に覆いかぶさった。

連合の貴族と知識層は、宮廷語で**完成された成果物・贅沢品**を語った。辺境の植民星の民と労働者は、在来語で**生きた物・自然そのもの・労働の現場**を語った。[[環暦|大解体]]ののち連合という大樹は倒れたが、舌に刻まれた言葉の階級は残った。いまも――育てる者と食らう者は、同じものを違う名で呼ぶ。

## 分断のルール（生産の言葉 ↔ 消費の言葉）
| もの | 在来語（庶民・生きた物・労働） | 宮廷語（貴族・完成品・贅沢） |
|---|---|---|
| 牛 | **カウ**（牧場で鳴く獣） | **ビーフ**（銀皿に盛られた極上のステーキ） |
| 豚 | **ピッグ**（泥にまみれた獣） | **ポーク**（白ワインで煮込んだメインディッシュ） |
| 鉱と鋼 | **くろがね／掘った鉱**（坑道の汗） | **精鋼・装甲鋼**（磨き上げられた艦の鎧） |
| 船と人 | **はたらき船・荷船・船乗り**（油に汚れた現場） | **艦・旗艦・提督**（誉れと称号） |
| 穀と饗 | **実り・刈り入れ**（畑の労） | **饗・美食・料理**（卓上の贅） |
| 布と装い | **作業着・なめし革**（手の仕事） | **礼装・宝衣**（宮廷の装い） |

> ※宮廷語の多くは失われた故郷の言葉の残響（連合が持ち込んだ「高い言葉」）。在来語は植民の地で根づいた「低い言葉」。

## 例外（日常の言葉）
- **魚（フィッシュ）**や**鳥（チキン）**など、庶民でも手に入り日々口にしたものは、階級による分断がなく**共通の名**で呼ばれる。誰の卓にも上るものに、階級の刻印はない。

## 勢力と階級（誰がどの言葉を話すか）
- [[碧晶公国]]――旧連合貴族の世襲公領。**宮廷語が公用＝「正統」の証**。門閥は在来語を「汚らわしい」と退ける（→ [[身分]]の「冷たい秩序」・[[碧晶公国大憲章|門閥の特権]]）。
- [[黎明評議会]]――植民星の民の連邦。**在来語が母語**。合議も労働も土の言葉で語り、宮廷語を「城の上の幻」とみなす（→ [[黎明評議会連邦憲章|法の前の平等]]）。
- [[自由港同位体]]――交易民。**両方を使い分け**、客の階級に舌を合わせる商人の処世（→ [[商人]]）。
- [[鉄環兵団]]――叩き上げの軍閥。在来語の力強さを好み、宮廷語を「飾り」と嗤う（功が言葉に勝る）。
- [[灯心自由市ファロス]]――中立都市。実務の在来語＋交渉の宮廷語。

## NPC・フレーバーへの適用指針
- **貴族NPC**：完成品・贅沢は宮廷語で誇るが、それが「生きていた時」の在来語は口にしない。「今宵の**ビーフ**は絶品だ」とは言うが、「**カウ**」とは言わない。
- **庶民・労働者NPC**：生きた物・労働は在来語で語る。「あの**カウ**を育てるのは骨が折れる」「**ビーフ**なんざ、城の上の幻さ」。
- **アイテム・フレーバー**：誰の視点で作られたかで名を変える。労働者の得物＝粗野な在来語名（「叩き斧」「現場槍」）／貴族の宝剣＝優美な宮廷語名（「セレスティアル・エペ」）。提督の[[旗艦]]＝宮廷語（世界遺産名・誉れ）／配下の働き船＝在来語（「荷船」「楯船」）。

## ゲームデータ参照
- 言語そのものに機構はない（フレーバー／ナラティブ層）。話者の階級は `socialOrigin`（平民／植民星／門閥貴族＝`SocialOriginRules`）・信条 `creed`、勢力は `FactionData.ideology`。**台詞・アイテム名・解説文のレジスタ選択の指針**として使う（高register＝宮廷語／低register＝在来語）。物語生成は話者の階級・勢力からレジスタを選ぶ（→ [[正史と稗史]]・[[語録]]）。
