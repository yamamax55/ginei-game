# ワタツミ

> 交易の要衝に浮かぶ海神の惑星。あらゆる航路がここで結ばれる（惑星名は日本神話 → [[惑星名]]）。

## 概要
[[自由港同位体]]の首星。[[モンブラン星系]]の第二惑星で、海神ワタツミの名を負う＝**交易と航海**の象徴。祖国も大義も持たぬ商業ギルド連合の本拠であり、五つの海（航路）が集う巨大な自由港として、あらゆる勢力の船と銭が行き交う。

## 地誌・軌道
- 所属星系：[[モンブラン星系]]（→ [[星系名|名峰]]）
- 軌道：第2惑星（複数回廊の結節に近い交易適地）
- 首星：true（門閥総代の評議会と巨大な港湾・取引所が置かれる）

## 内政（`Province`）
- 商法と契約が国是。富は交易で回り、信用そのものが資本（→ [[自由港同位体の法令]]）。参政権は商会に偏る寡頭。
- 住民の思想は実利・中立に傾く。常備軍より傭兵・私掠に依存。

## 防衛・攻城（`Planet`／`PlanetSiegeRules`）
- 武装中立ゆえ正規の守備は薄いが、港の富で傭兵を雇い、[[諜報機関|商会連絡網]]で先手を読む。
- 港を封じれば食と富が痩せる（→ [[食|交易が断たれる]]）＝攻めるより干上がらせる方が効く。

## 帰属・歴史
- 現支配：[[自由港同位体]]
- 自立：[[ワタツミ港湾防衛戦]]（環暦7年）で併呑を退け、商人の自治を確立した。
