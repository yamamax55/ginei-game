# 碧晶公国の役職体系

> 世襲公領＝**君主統帥**。大公を頂点に、門閥貴族が官職を格式とともに占める。在任は[[碧晶公国#名鑑（所属の人物・組織）|名鑑]]・runtime で変動。

## 元首・統帥
- **大公**（世襲・君主統帥）：軍と政を統べる頂点。在任例 → [[ヒルデガルト・フォン・アイゼンブルク]]（女大公）。王家は[[アイゼンブルク家]]ほか門閥（→ [[碧晶公国#名鑑（所属の人物・組織）|名鑑]]）。

## 政府役職（文官・官職）
- **宰相**：太政官の長＝文官筆頭。中央行政を統べる（官位相当で銓衡＝`CivilAppointmentRules`）。
- **省卿**：式部卿（人事）／民部卿（内政）／大蔵卿（財政）／兵部卿（軍政）＝二官八省の長。
- **総督**：各星系（[[エベレスト星系]] ほか封土）の地方官。受領として内政を担う。
- ※要職は位階（`CourtRank`）の高い門閥貴族が占め、平民の登用は限られる（公領の「冷たい秩序」）。

## 立法・評議
- 民選議会は持たない。**門閥貴族会議**が大公への諮問機関として機能（政党＝[[正統派]]／[[門閥連合]]／[[宮廷改革派]]は宮廷内の派閥）。

## 軍役職（階級＋指揮職）
- **階級**：元帥〜兵卒（18階級）。由緒ある艦隊伝統を重んじ、家格が昇進に影響。
- **指揮職**：艦隊司令／旗艦長／参謀長。重厚な方陣・物量戦の名手を要職に。
- 在任例 → [[コンラート・フォン・メーアブルク]]（碧海の守将・大佐）。

## 勢力固有の役職
- **公宮の鋳貨庁長**（[[公領マルク]]の発行）／**紋章院総裁**（家格・叙位の管理）。
