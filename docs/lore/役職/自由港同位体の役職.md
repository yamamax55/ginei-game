# 自由港同位体の役職体系

> 商業ギルド連合＝**寡頭制の共和国**。選出された元首のもと、大商会の代表が評議会を握る。在任は[[自由港同位体#名鑑（所属の人物・組織）|名鑑]]・runtime で変動。

## 元首・統帥
- **元首（ドージェ）**：ギルド評議会が選ぶ任期制の長（文民統制）。在任例 → [[シモネッタ・モチェニーゴ]]。

## 政府役職（文官・官職）
- **商権長**：交易・関税・港湾・与信を統べる実務の長（宰相相当）。
- **各部局長**：関税局／港湾局／与信（金融）局。文官は算盤に強い実務官僚。
- **商務総督**：各星系（[[モンブラン星系]] ほか）の通商を差配する地方官。

## 立法・評議
- **商業ギルド評議会**：門閥総代と大商会（→ [[自由港同位体#名鑑（所属の人物・組織）|名鑑]]の商会）の代表による寡頭の合議。政党＝[[自由貿易党]]／[[商権同盟]]／[[中立堅持派]]。

## 軍役職（階級＋指揮職）
- **遊撃船団司令**：通商破壊（私掠）と機動戦を率いる。常備軍より遊撃・傭兵に依存。
- 在任例 → [[キアラ・ヴェントゥーラ]]（遊撃隊長）／[[マッテオ・サルヴィアーティ]]。

## 勢力固有の役職
- **発券銀行総裁**（[[自由港リラ]]の発行・準備管理）／**関税長**（生きた[[回廊]]の通行料徴収）。
