# 遠隔操作旗艦・リスポーン・戦功ショップ 設計（MOBAの落とし込み）

> MOBA の「リスポーン」「アイテム購入」を、本作（銀英伝風の星間国家戦略＋戦術艦隊戦）の世界観を壊さずに落とし込む設計。
> ヒーロー会戦モード EPIC #2747／会戦中の旗艦成長 #2757／LoL EPIC #2739（賞金首LOL-3・中立目標LOL-1）の延長線。**本書は設計のみ（実装はまだ）**。
> 著作権注意：MOBA のメカニクス/構造のみ参考（固有名は不使用）。

---

## 0. コンセプト：遠隔操作旗艦（lore の鍵）

MOBA のリスポーンを直訳すると「沈んだ旗艦が湧く」＝艦隊戦の lore を壊す。これを**「人物（提督）は根拠地に待機し、旗艦を超技術で遠隔操作する」**設定で解く：

- **提督は旗艦に物理的に乗らない**＝旗艦は遠隔操作のドローン的存在。よって**旗艦撃沈 ≠ 提督の死**。
- 旗艦が沈んだら、提督は**予備旗艦を遠隔で再投入**できる。超技術により**会戦内で積んだ経験値（#2757 レベル）は予備旗艦へ引き継がれる**＝MOBA の「死んでもレベルは保持」。
- ただし**根拠地を失えば**遠隔操作の拠点も指揮官の身柄も失う＝**提督の撤退/死亡/捕縛**判定＝これが真の「死」。

→ 「旗艦は何度でも沈められるが、根拠地と提督の命は一つ」という二層の賭けになる（MOBA の respawn の手触り＋銀英伝の将の生死ドラマ）。

## 1. リスポーン ＝ 旗艦撃沈 → 予備旗艦の遠隔再投入

- **トリガ**：旗艦撃沈（撃墜）。提督は根拠地で無事ゆえ lore 整合で**本当に沈めてよい**。
- **再投入タイマー**（death-timer 相当）：会戦経過・レベル・階級で延びる（クランプ付き＝終盤の喪失は重い）。`RallyRules`（再集結）に接続。
- **経験値引継ぎ**：会戦内レベル（#2757 `FlagshipBattleGrowthRules`）は予備旗艦へ**保持**（超技術）。失うのは①テンポ②沈んだ旗艦の配下艦（`Squadron.ScatterEscorts` 損耗）③戦功の勢い。
- **予備旗艦**：在庫モデルは §1.1（有限ストック＋根拠地補充トリクル＝決定済み）。
- 受け皿：HERO-6（#2754 被撃破・退避・賞金首）に「再投入タイマー＋予備旗艦＋XP引継ぎ」を足す。新Coreは薄い `RemoteRedeployRules`（タイマー＝レベル/経過/階級の関数・XP保持・予備消費）。

### 1.1 予備旗艦の在庫モデル（論点1＝決定）

> 純MOBA（無限リスポーン）は艦隊戦の消耗（戦略の核）を壊し、純・有限（N隻で打ち止め）は雪だるま（負け側が枯渇して一方的に狩られる）を生む。**「遠隔操作旗艦」の lore がそのまま中庸の答え**＝予備は根拠地の在庫から引き、根拠地が健在な限り補充され続ける。

**採用＝有限ストック＋根拠地からの補充トリクル（会戦限定）**

- **`ReserveStock`（予備旗艦在庫＝リスポーン残数）**：会戦開始時に各ヒーロー旗艦へ初期在庫 `R0` を割当。`R0` は §4 `DeploymentCostRules`（階級が高いほど少なく＝重い）＋戦略状況（補給/国力）で決まる。プレイヤーは出撃時にコミット量（多く積む＝粘れるが負ければ痛い）を選べる。
- **撃沈→再投入**で `ReserveStock -= 1`（§1の再投入タイマー後に予備が根拠地側マップ端から湧く）。
- **根拠地が健在な限り**、`ReserveStock += 補充レート × 経過`（造船力 `ShipyardRules.ProductionFactor`／戦略状況に比例・**上限 `R0` でクランプ**）。これが MOBA の「湧き続ける」手触り＝**即死ロックアウトしない**。
- **`ReserveStock == 0` かつ前線旗艦も撃沈** → その提督は**会戦から脱落**（前線を維持できず＝退いて根拠地防衛へ）。**ただし提督自身は根拠地で生存**（遠隔操作する旗艦が一時的に無いだけ）。
- **根拠地喪失** → 補充停止＋在庫接収/破壊 → **再投入不能＋提督の撤退/死亡/捕縛判定**（§2＝真の死）。

**規律との整合（重要）**：本在庫は**会戦限定の薄い別台帳**（戦功ポイントと同じ＝会戦終了でリセット）。**恒久の戦略消耗は従来どおり `StrategicFleet.strength`** が担い、「`FleetPool` は建艦でのみ増える／会戦では減らない」既存規約は壊さない（CLAUDE.md 艦隊編成プール節）。予備在庫は「兵力(strength)の塊」でなく**ヒーロー旗艦の本数（少数・数隻）**＝二層分離を保つ。

**雪だるま防止**：①補充トリクルで負け側を即ロックアウトしない ②賞金首 LOL-3＝連続撃破で賞金上昇→敵戦功に還元（ラバーバンド）③在庫薄＝退却誘因＝戦線の伸縮（観るべき展開）④再投入タイマー逓増（§1）。

**既定値（暫定・要バランス）**：`R0` ＝ 2〜3（上位階級ほど少）／補充 ＝ 数十秒に1隻（根拠地健在時・上限 `R0`）／タイマー ＝ レベル/経過/階級で逓増（クランプ）。AI 旗艦も同モデル（オフスクリーン/非係争は `AutoBattleSim` 抽象＝本数を積分で扱いPERF確保）。

## 2. 根拠地 ＝ 再投入アンカー ＋ 戦功ショップ ＋ 敗北条件

- **根拠地**＝保有星系（`PlanetSiegeRules` の攻防対象）。MOBA の base に相当。
  - ①予備旗艦の**再投入地点**（マップ端/根拠地から湧く）
  - ②**戦功ショップ**（§3）の所在＝戦線を離れて戻る/留まるのテンポ判断
  - ③**喪失＝敗北条件**：敵に根拠地を制圧されると**遠隔操作不能＋提督の撤退/死亡/捕縛**を判定（`PersonnelFateRules`/`CaptivityRules`/`SurrenderRules`/`EncirclementRules` に接続）。撤退（無事逃走）/死亡/捕縛は統率・謙虚さ（`SutegamariRules` 系）・戦略状況・敵の追撃で決まる決定論 roll。
- → 「ヤンの旗艦は何度でも沈むが、イゼルローン（根拠地）を落とされたら終わり」という構図。

## 3. 戦功ポイント（会戦限定通貨）＋ アイテム購入

- **戦功ポイント**＝会戦内で稼ぐ専用通貨（撃破/中立目標確保 LOL-1/賞金首 LOL-3）。**会戦限定でリセット**（#2757 と整合）。金銭（国庫/私有財産）とは独立＝バランスしやすい。
- **再補給拠点（根拠地）で購入＝会戦限定の換装**（永続の艦強化は `ArmamentDesignRules`/造船が担う＝二重計上しない）。
- **買えるもの（少数厳選＝タイクン回避）**：
  - 応急修理（`RepairRules`）／配下艦の増援補充
  - 弾種・ビーム換装（対シールド貫通＝`ShieldTechRules`/`BeamWeaponRules` の**カウンター**）
  - 一時的な戦法/号令スロット開放（SGT-1/2）／采配ゲージ上限
  - 再投入タイマー短縮（戦功で粘る）
- **カウンタービルド**＝敵の艦種（SGT-4）/シールド/ビームに対して買い分ける（MOBA の「物理なら鎧」）。
- 新Core `MeritShopRules`（戦功収入・品目コスト・購入可否・会戦限定リセット）。

## 4. 全旗艦がヒーロー ＋ 階級投入コスト ＋ 最終能力合成式

- **全旗艦が遠隔操作のヒーロー**（プレイヤーの旗艦も AI の旗艦も同じ枠組み＝リスポーン/成長/購入が成立。プレイヤーは"今操作している1隻"に集中＝HERO-1/2）。AI/オフスクリーン/非係争は LOD 抽象化（`AutoBattleSim` 寄せ）でPERF確保。
- **階級が高いほど会戦への投入コストが重い**：上位提督の旗艦を会戦に投入するほど**投入コスト（出撃予算）が重い**＝精鋭を全戦線に撒けない。新Core `DeploymentCostRules`（コスト＝階級の関数）。SGT-7 出撃コスト編成（#2727）／`FleetCapRules` と接続。
- **最終能力＝合成式**：旗艦の実効戦闘力を **`階級 × 提督能力 × 戦略状況 × 旗艦`** で決める（`ModifierStack` で積む・各々の単一窓口へ委譲＝二重実装しない）：
  - **階級** → 指揮影響圏 GIR-1 `CommandAuraRules`／指揮容量 `CommandCapacityRules`
  - **提督能力** → `CombatModifiers.AbilityFactor`（実効値・既存）
  - **戦略状況** → 補給/士気/国力差/中立目標バフ LOL-1/厭戦（`WarWearinessModifiersRules` 等）
  - **旗艦** → 艦種 `ShipClass`#80 ＋ 会戦内成長 #2757 ＋ 換装（§3）
  - 新Core `FlagshipEffectivePowerRules`（上記を `ModifierStack` で合成する単一窓口）。

## 6. 未決の論点（実装前に決める）

1. ~~**予備旗艦の有限性**~~ → **決定済み（§1.1）**＝有限ストック `ReserveStock` ＋根拠地からの補充トリクル（会戦限定の薄い別台帳・恒久消耗は `StrategicFleet.strength` のまま）。
2. **根拠地喪失の運命 roll の係数**：撤退/死亡/捕縛の確率を何で引くか（統率・謙虚さ・戦略状況・敵追撃・`EncirclementRules` 包囲度）。
3. **戦略状況の合成への入れ方**：補給/士気/国力差/中立目標をどう1つの「戦略状況倍率」に畳むか（レンジ定義）。
4. **階級投入コストの数値**：階級×コスト曲線、出撃予算の総量、SGT-7 との重複整理。
5. **AI/PERF**：全旗艦ヒーロー化の負荷＝係争会戦のみ精密・他は `AutoBattleSim` 抽象（観測解像度とシミュ解像度の分離・PERF#1117）。
6. **HERO EPIC #2747 との統合**：「全旗艦がヒーロー」は HERO-1/3（ヒーロー指定・AI委任）を一般化＝EPIC の再整理が要るか。

## 7. 規律
- **lore**：蘇生でなく遠隔操作＋予備旗艦＋根拠地の命。 **タイクン回避**：ショップは数SKUに厳選。 **二重計上回避**：会戦限定のみ・永続は造船/R&D・人物能力は練度/覚醒。 **雪だるま**：再投入タイマー＋予備上限＋カウンター品＋賞金首(LOL-3)＋能力上限クランプ。 **PERF**：ヒーロー化はLODで抽象。 **合成は単一窓口**：`ModifierStack`/`CombatModifiers` に積む。
