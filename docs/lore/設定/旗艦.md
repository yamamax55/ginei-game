# 旗艦と艦名（きかん）

> 旗艦には、失われた故郷の**世界遺産・自然遺産**の名を冠する。勢力を問わぬ、銀河共通の慣わし。

## 概要
艦隊の中核＝提督が座乗する**旗艦**には、固有の名が与えられる。その名の出どころは、人類が散らばる以前の故地――**揺籃の星々（旧き故郷）に遺された世界遺産・自然遺産**である。〈ヨセミテ〉〈京都〉〈アクロポリス〉〈セレンゲティ〉〈マチュピチュ〉――いずれも、もはや誰も帰り着けぬ遠い故郷の、山河と都市の名だ。

この慣わしは[[大環状連合]]の時代に生まれ、連合が倒れた後も諸侯の別なく受け継がれた。死んだ[[回廊]]の海に隔てられ、故郷へ二度と戻れぬ者たちが、せめてその名を艦に冠して記憶を継ぐ――艦名は、失われた故郷への追慕の儀礼であり、提督が背負う誇りの象徴でもある。だから艦名は**勢力に属さない**。敵も味方も、同じ故郷の遺産の名を分け合って戦う。

## 命名の作法
- **重複なし**：同時に生きる旗艦が同じ名を持つことはない。名は一つの艦にのみ宿る。
- **返却（退役・安全退却）**：艦が役目を終え、あるいは生きて戦場を退けば、その名は名簿へ返され、いつかまた別の艦が継ぐ。
- **永久欠番（撃沈）**：艦が撃ち沈められると、その名は**二度と払い出されない**。沈んだ艦の名を新たな艦に与えるのは、戦死者への不敬とされる。失われた名の数だけ、戦史が刻まれていく。
- **名の払底**：約二百の遺産名を使い尽くせば、由緒ある名に世数を添えて継ぐ（〈◯◯ II〉〈◯◯ III〉…）。命名が途切れることはない。

## 専用旗艦（愛着の旗）
名のある提督には、**いつ乗っても必ず同じ名の旗艦**となる「専用旗艦」が結びつく。提督とその艦は不可分の象徴となり、「あの提督の、あの艦」として語り継がれる。専用旗艦は[[世界遺産プール]]の内外を問わず指名でき、ひとたび主が定まれば他の艦隊へは払い出されない。

## ゲーム実装との対応
> ※数値・名簿の正は Core 側。ここは「どの実装に乗るか」の見取り図。

| 設定 | 実装 |
|---|---|
| 世界遺産・自然遺産の名プール（約200・重複なし） | `HeritageShipNames.Names`（差し替えれば命名規則ごと変わる単一の源） |
| 重複なしの払い出し（決定論・プール順に最小の空き名） | `ShipNameRegistry.Assign()` |
| 返却（退役・安全退却で再利用可） | `ShipNameRegistry.Release(name)` |
| 永久欠番（撃沈は以後払い出さない） | `ShipNameRegistry.Retire(name)`／`IsRetired(name)` |
| プール枯渇時の世数フォールバック（〈◯◯ II〉…） | `ShipNameRegistry.Assign()` 内のローマ数字サフィックス |
| 専用旗艦（提督に固定の艦名） | `SignatureShipRegistry.Resolve(admiral)`＝①`AdmiralData.signatureShipName` 明示 → ②既定表（提督名キー）→ ③なし |
| 専用旗艦の指名払い出し（プール外名も可） | `ShipNameRegistry.TryAssignSpecific(name)` |
| 勢力非依存の名前体系 | 名簿・払い出しは勢力を見ない（普遍の遺産名） |
