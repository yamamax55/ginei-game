# #38 [C-5] 援軍（ワープイン）QA 手順

対象：通常PC の Unity 版のみ。Windows 出力は **v6**（`Ginei-Strategy-Map-v6/Ginei.exe`）。**v5 は上書きしない**。
役割：実機操作・GitHub 更新は ChatGPT。プログラムは Claude。
前提：**既存セーブは変更しない**。QA メニューは **Play 中のみ動作し、何も保存しない**。

派遣の入口は**艦隊メニュー**（上段「艦隊」ボタン／盤面の右クリック／**Alt+A**）です。
Alt+A は「即派遣」ではなく、**艦隊メニューを援軍モードで開く**操作に変わりました。
待ち時間の短縮には `Ginei > QA（Play中のみ・保存しない）/援軍 #38/到着を10秒後に寄せる` を使う。

---

## A. 派遣できる

1. 艦隊メニューから自軍の艦隊を敵艦隊のいる星系へ移動させ、交戦状態を作る。
2. **期待**：`敵艦隊と接敵：… （…秒で自動解決／ダブルクリックで潜行）` の通知が出る。
3. 上段の「艦隊」ボタン（または盤面の右クリック）で艦隊メニューを開く。
4. 後方に残した別の自軍艦隊を一覧から選び、「援軍を送る」を押す。
5. **期待**：交戦中の戦場の一覧が出る（**MAP をクリックしなくても選べる**）。戦場を選んで実行する。
6. **期待**：`第n艦隊を A–B へ派遣（C 側から到着予定 mm:ss）` の通知が出る。
   到着予定は**即時ではなく**、回廊の距離とワープ速度に応じた時間になっている。
6. **期待**：派遣した艦隊は盤面から消えず「増援航行中」として動かなくなる。
7. `Ginei > QA（…）/援軍 #38/航行中の援軍を一覧` で、宛先・到着時刻・残り秒・進捗が出る。

### A-2. 送れない場合の挙動
1. 交戦中の戦場が1つも無い状態で「援軍を送る」を押す。
   **期待**：宛先の一覧が空で、`援軍は進行中の戦場にのみ送れます` に相当する案内が出る。
2. 既に**交戦中**の艦隊を選ぶ。**期待**：状態が「交戦中」と表示され、派遣できない。
3. 既に**増援航行中**の艦隊を選ぶ。**期待**：状態が「増援航行中」と表示され、派遣できない。
4. **Alt+A** を押す。**期待**：艦隊メニューが援軍モードで開く。カーソルが交戦中の回廊の上なら、
   その戦場が選ばれた状態で開く（カーソルがどこでも開く。即派遣はしない）。

## B. 時間差で到着し、参戦する（本命）

1. A 節の状態で、交戦中の回廊をダブルクリックして会戦へ潜行する。
2. **期待**：Battle シーンに入り、暦時刻が戦略から連続している。
3. 到着予定時刻まで待つ。
4. **期待**：`(勢力) 第n艦隊がワープイン（m,mmm隻）` の通知が出て、**自陣側の端**に艦隊が現れる。
   帝国は左端、それ以外は右端。中央（戦場）へ正対している。
5. **期待**：同じ艦隊が**二度出現しない**。
6. 複数隊を同時に派遣した場合、**期待**：縦にずれて並び、重ならない。

---

## C. 時計の整合（ポーズ・倍速・分割）

1. B 節で待っている間に Space でポーズする。
2. **期待**：残り時間が進まない。ワープインしない。
3. ポーズを解除する。**期待**：続きから進む。
4. `2` / `3` キーで倍速にする。
5. **期待**：残り時間が倍速ぶん速く減る。到着は**表示された到着予定の暦時刻ちょうど**で起きる。
   等速で待った場合と同じ暦時刻になること（早着・遅着しない）。
6. 一度戦略へ戻り（Backspace）、また潜行し直す。
   **期待**：往復しても到着予定の暦時刻が変わらない。

---

## D. 別戦場に混ざらない

1. 別の回廊でも交戦を作る。
2. そこへ別の艦隊を艦隊メニューの「援軍を送る」で派遣する。
3. `Ginei > QA（…）/交戦中の回廊を一覧（援軍の宛先候補）` で 2 つの戦場が出ることを確認。
4. 片方の会戦へ潜行して到着を待つ。
5. **期待**：その戦場には**そこ宛ての援軍だけ**が現れる。もう一方宛ての艦隊は出てこない。

---

## E. 戦闘終了後に到着した場合（差し戻し）

1. 到着予定が残っている状態で、会戦を決着させる（敵を全滅させる、または Backspace で離脱する）。
2. **期待**：`戦闘終了により援軍 n 隊が帰投します` の通知が出る。
3. 戦略マップに戻る。
4. **期待**：`第n艦隊は戦闘終了により帰投しました` が出て、その艦隊が**盤面に戻っている**（消えない）。
   「増援航行中」が解けて、また操作できる。
5. **潜行せず放置して自動解決**させたケースでも同じことを確認する。
   **期待**：自動解決の決着通知のあと、未到着の援軍が盤面へ戻っている（宙に浮かない）。
6. `Ginei > QA（…）/航行中の援軍を一覧` で、閉じた戦場宛ての援軍が残っていないことを確認。

---

## F. 取り消し

1. 派遣したあと到着前に `Ginei > QA（…）/航行中の援軍を全部取り消す（盤面へ戻す）` を実行。
2. **期待**：艦隊が即座に盤面へ戻り、会戦にワープインしない。

## G. セーブ互換

> **重要：このゲームのセーブは1枠だけ**（`campaign_save.json`）。「新しいセーブ枠」は作れず、
> セーブすると既存の戦役データを上書きします。**必ず先に退避してから**試してください。
>
> 退避（PowerShell）：
> ```
> Copy-Item "$env:USERPROFILE\AppData\LocalLow\DefaultCompany\My project\campaign_save.json" "$env:USERPROFILE\Desktop\campaign_save.backup.json"
> ```
> 復元（QA を終えたら必ず実行）：
> ```
> Copy-Item "$env:USERPROFILE\Desktop\campaign_save.backup.json" "$env:USERPROFILE\AppData\LocalLow\DefaultCompany\My project\campaign_save.json" -Force
> ```


1. 援軍を航行中にしたままセーブする（F5）。上の手順で**先に退避しておくこと**。
2. タイトルへ戻り、そのセーブを再開する。
3. **期待**：航行中の援軍が**同じ到着予定の暦時刻**で復元されている。
   `Ginei > QA（…）/航行中の援軍を一覧` の「あと ○ 秒」がセーブ前と一致する。
4. **期待**：ロードした瞬間に一斉到着しない。
5. **旧セーブ**（この版より前に作ったもの）を再開する。
6. **期待**：エラーにならず、援軍なしとして読める。旧セーブのファイル内容が書き換わっていない。

## H. 回廊要塞（#40）との組み合わせ

1. 要塞に足止めされた艦隊がいる回廊へ、後続の艦隊を艦隊メニューの「援軍を送る」で派遣する。
2. 要塞戦の戦術マップへ潜行して待つ。
3. **期待**：援軍が水路の入口（自陣側の端）からワープインし、要塞攻めに加わる。
4. **期待**：援軍も岩壁と封鎖線に拘束される（要塞を撃破するまで突破線へ行けない）。

## 既知の制約（設計上の選択）

- **援軍は進行中の戦場にしか送れない**。交戦していない回廊へは派遣できない（宛先が無いため）。
- **到着位置は自陣側の端に固定**。帝国は左端、それ以外は右端で、既存の増援（#2182）と同じ窓口を使う。
  回廊の入口を左右どちらにするかは戦術マップの座標系に従い、戦略側の進軍方向とは連動しない。
- **派遣中の艦隊は戦略盤面で動かない**。占領や迎撃には使えない（戻ってくるまで拘束される）。
- **取り消しは QA メニューのみ**。ゲーム内 UI からの取り消しは未実装（既知の残課題）。
- **到着予定の常設 HUD は未実装**。到着予定は派遣時の通知と QA メニューで確認する。

## I. 実機QAで見つかった不具合の回帰（**新規Playで必須**）

1. **即時ワープインしないこと**
   1. 要塞戦の準備コマンドで、予備艦隊を戦場回廊の**入口の星系**に停泊させる。
   2. 艦隊メニューからその回廊へ派遣する。
   3. **期待**：到着予定が `00:00` ではなく、回廊の長さに応じた時間になる。
   4. 戦術マップへ入った直後にワープインしない。到着予定の時刻になってから現れる。
      （修正前は端に停泊していると所要0秒になり、入った瞬間に出現しました。）

2. **参戦した援軍が操作不能にならないこと**
   1. 援軍を到着させて参戦させる。
   2. 戦術マップから戦略へ戻る。
   3. **期待**：`第n艦隊は援軍として参戦し、戦線へ復帰しました` の通知が出る。
   4. **期待**：艦隊メニューでその艦隊の状態が「増援航行中」ではなくなり、移動命令を出せる。
      （修正前は「増援航行中」のまま残り、二度と動かせませんでした。）

3. **戦っている最中に戦略側が横取りしないこと**
   1. 要塞戦へ潜行して、しばらく戦術マップに留まる。
   2. **期待**：戦略側の通知に `攻略に失敗＝難攻不落` などの**自動解決が出ない**。
   3. **期待**：戦略へ戻ったとき、突入した艦隊が盤面から消えていない。
      （修正前はウィンドウ会戦だと横取りが起き、突入中の艦隊が消えました。）

## 既知の制約（追加）

- **要塞戦（#40）に参戦した援軍は、損害を戦略へ書き戻します**（2026-09-09 に修正済み。
  旧記述＝「書き戻さない」は当時の制約で、要塞戦には該当しません）。
  書き戻しは `BattleManager.ReturnFromCorridorFortress`→`GalaxyView.ApplyPerFleetSurvivors`＝
  **戦略艦隊IDごとの生存明細**なので、参戦した援軍にだけその損害が返ります
  （生存＝実残存・全滅＝0・未到着の帰投＝派遣時のまま・二重加算なし）。
- **通常（要塞でない）回廊戦に参戦した援軍への書き戻しは未対応＝残件です**。この場合は
  元の艦艇数のまま、元の星系に停泊した状態で復帰します。
