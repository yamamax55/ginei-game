# 義肢と人造（ぎしとじんぞう）＝失われた自動化の名残

> 「旧連合は人手なんざ要らなかった。機械が船を動かし、機械が傷を継いだ。……いまは、その『からくり』を直せる職人すら、片手で数えるほどさ。」

## 核心（旧連合の自動化が失われ、今は半ば手仕事で継ぐ）
旧[[大環状連合]]は高度な自動機械（からくり）と人造技術で繁栄したが、[[環暦|大解体]]でその大半が失われた。いまや残骸の機巧を動かし、戦傷者に義肢を継ぎ、艦の自動装置を保つのは、稀少な[[工房と職人|名工]]の半ば失われた知である。義肢は戦で四肢を失った兵を再び戦列へ戻し（→ [[医療と疫病]]・[[兵站]]）、遺された自動機械は[[建艦]]や[[鉱と採掘|採掘]]の生産力を支える。動く旧連合製の機巧は国宝級の戦略資産であり、その独占と修理の技は一国の[[技術]]力を映す。

## 失われた技の名残（からくりは誰のものか）
- **戦傷義肢**――手足・目を失った兵を戦列へ戻す。粗末な木鉄の義肢から、旧連合製の精巧な義体まで格差は大きい（→ [[身分]]・[[医療と疫病]]）。
- **遺された自動機械**――旧連合の動く機巧は生産・航行を助ける貴重な遺産。修理できる職人は希少（→ [[工房と職人]]・[[技術]]）。
- **機巧の独占**――動く旧技術の艦・設備は戦略資産。その帰属が[[戦争]]の動機にも（→ [[兵站]]の戦略物資）。
- **人造への畏れ**――人を模した機巧、自律する機械への畏怖と禁忌。[[信仰|灯統教会]]は「灯の秩序を侵す」と忌む向きも（→ [[占いと予兆]]の凶兆）。

## 勢力ごとの人造技術
- [[碧晶公国]]――宮廷工房が旧連合の機巧を秘蔵し独占。精巧な義体は門閥の特権（→ [[身分]]・[[工房と職人]]）。
- [[黎明評議会]]――技術の公開と義肢の普及を進め、戦傷者を社会へ戻す（→ [[黎明評議会連邦憲章|市民の権利]]・[[名門校]]の技術者）。
- [[鉄環兵団]]――兵を再び戦列へ戻す軍用義肢を量産。実用一辺倒で粗いが速い（→ [[練度]]の古参兵）。
- [[自由港同位体]]――旧連合の機巧と部品を売買する技術交易の中枢（→ [[商社]]・[[鉱と採掘|希少部品]]）。
- [[灯心自由市ファロス]]――機巧の修理と精錬に長けるギルド都市（→ [[工房と職人]]）。

## NPC・クエストへの適用指針
- **隻腕の古参兵NPC**（義肢で再起）――「この鉄の腕でな、まだ舵は握れる。安物だが、無いよりはマシだ。……公領の連中が着けてる『本物の義体』とは、比べ物にならねえがな。」（→ [[身分]]）
- **機巧職人NPC**（失われた技の番人）――「この自動装置を直せるのは、この星系じゃ俺だけだ。旧連合の図面？　とうに失われた。俺が死んだら、この技も終わりさ。」
- **クエスト分岐**：動く旧連合製の機巧を巡る場面で → (a) **正規に職人を雇い修理/複製を試みる**＝確実だが時間と稀少な技（→ [[工房と職人]]）／(b) **機巧ごと武力で奪う**＝速いが[[戦争]]と恨み／(c) **[[汚職とフィクサー|フィクサー]]に部品と技を闇で調達させる**＝高くつくが速い（偽部品の罠も）。
