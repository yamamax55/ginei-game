# アムステルダム

## 概要
[[ロレンツォ・ダンドロ]]（PER-320）の専用旗艦。名は失われた故郷の世界遺産・運河と交易で栄えた商都**アムステルダム**に因む。烏合になりがちな商業連合の船々を一個の艦隊にまとめ、戦列を組んで崩れず受けて返す――ロレンツォの「正面の壁」を象徴する、堂々たる戦列旗艦。

## 座乗提督
- [[ロレンツォ・ダンドロ]]（[[自由港同位体]]の中将・艦隊戦／防御反撃）。専用旗艦＝`signatureShipName`＝「アムステルダム」で固定。

## 来歴・戦歴
- 私掠の[[リアルト]]（[[キアラ・ヴェントゥーラ]]）・船団の[[サンマルコ]]（[[マッテオ・サルヴィアーティ]]）と同じ自由港リバリーを共有しつつ、戦列を張る正面戦力に振った重厚な艦容。
- 寄せ集めの護衛船団を規律ある一個艦隊へまとめる旗艦として、幾度も大勢を退ける戦列の要となってきた。

## 意匠（アートメモ）
[[リアルト]]・[[サンマルコ]]と同じ自由港同位体のリバリー＝生成り（オフホワイト）の船体に赤と紺の差し色、金の自由港ギルド章を共有。私掠艦の鋭さ・船団艦の実務性に対し、本艦は**戦列を張る重厚な正面戦力**＝幅広で安定した船体、艦首中心線に大型連装の主砲、舷側に整然と並ぶ副砲列で「崩れぬ壁」を体現する。中央に金のギルド章。現実寄りハードSFの溶接装甲・パネル継ぎ目・センサーマスト、艦尾は青いプラズマ噴射。
