# 第一章 ―― 諸侯の時代

灯が消えて十年。銀河には、すでに新しい現実が根を張っていた。

[[回廊|回廊網]]は、完全に死んだわけではなかった。停止した[[灯台]]のいくつかは余命をたもち、あるいは地方に残った技術者が断片的に回廊を読み直し、限られた航路だけが「[[回廊|生きた回廊]]」として残った。そして人は、生きた回廊の交点――幾本もの航路が交わる[[回廊|要衝星系]]こそが、富と兵を制する鍵だと悟った。要衝を握れば、交易の関を設けて通行料を取り、四方へ艦隊を送り出せる。要衝を失えば、封土は孤島となって干上がる。

要衝を押さえた者が、周辺の星々を「[[封土]]（ほうど）」として囲い込み、自らの旗を立てた。旧連合の貴族は世襲の権威を盾に、領民に忠誠を求めた。植民星の議会は民の支持を頼みに、合議で兵を募った。交易を生業とした商人は、蓄えた資本と私設船団を武器に星域を買い占めた。そして、連合の解体で職を失った無数の軍人たちは、純然たる武力でもって星を奪った。――こうして銀河は、互いに等しく「正統」を主張する**諸侯の群雄割拠**の時代へと姿を変えた。勝ち残った者は、最も名のある要衝に己の首府を据える。旧貴族は太陽神の名を負う惑星〈[[惑星名|アマテラス]]〉に宮廷を、軍閥は暴風の戦神の名を負う〈[[惑星名|スサノオ]]〉に本営を構え、滅びた連合の荘厳を、それぞれの流儀で僭称しはじめた。

だが、要衝を握った者の誰もが諸侯になったわけではない。生きた[[回廊]]の交点に栄えた豊かな星系のいくつかは、周辺を併呑して版図を広げる代わりに、**自らの星ひとつだけを自治の府として守り抜いた**。難民と船と資本を吸い寄せて一夜に膨れ上がったそれらの星都は、近隣の貴族や軍閥に[[封土|叙任]]されて頭を垂れることを拒み、商工ギルドと船長たちの評議会を立てて独立を宣した。版図ではなく港・市場・金融を武器とし、四囲の諸侯を天秤にかけて生き延びる――この第三の極を、人は[[都市国家]]（自由市）と呼んだ。諸侯が領を広げる垂直の権力なら、都市国家は一個の星に深く根を張る凝集の権力であった（→[[灯心自由市ファロス]]）。

諸侯のもとで、忘れられていた提督という官職が息を吹き返した。封土はその国力に応じて艦隊を保有し、提督はそれを「[[封土|叙任]]」されて指揮する。功を立てれば昇叙し、より大きな艦隊を預けられる。敗れれば領は召し上げられ、提督は浪々の身となって次の主を探す。忠誠は、もはや絶対ではない。よりよい禄を求めて主を替える者、機を見て主家に反旗をひるがえす者、滅びゆく主君に殉じる者――裏切りと忠節が、この時代の日常となった。提督たちの「[[旗幟]]（きし）」――どの旗のもとに立つか――は、戦況ひとつ、恩賞ひとつで揺れた。
