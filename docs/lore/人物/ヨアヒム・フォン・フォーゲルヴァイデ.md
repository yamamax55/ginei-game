# ヨアヒム・フォン・フォーゲルヴァイデ（2世）

> 碧晶公国の大公。正統を背負う者。

## 概要
[[碧晶公国]]の**大公**。65歳。旧連合貴族の世襲公領の頂点に立ち、統治にあたる。王朝（[[フォーゲルヴァイデ家]]）の血を引く。

## 容姿
老練で重厚、玉座が板につく。碧晶公国の元首にふさわしい礼装をまとう。65歳。

## 統治・信条
- 果断にして冷徹、目的のためには手段を選ばない。
- 信条は**帝政擁護**。国家理念「正統なる権威による統一の再建」を体現する立場にある。徳と正統性が王朝の寿命を左右する（DynastyRules）。
