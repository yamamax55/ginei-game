# 回廊名（かいろうめい）

> 恒星間の[[回廊]]には、失われた故郷の**名高い海峡・水道・運河**の名を冠する。

## 概要
[[回廊]]は宇宙に走る見えざる河であり、星系と星系を結ぶ唯一の高速航路――すなわち**狭く・流れが速く・押さえれば富と兵を制する隘路（チョークポイント）**である。その性質は、故郷の海に走った**海峡・水道・運河**にそのまま重なる。ゆえに名のある回廊には、揺籃の星々の海に名を刻んだ**名高い海峡の名**をカタカナで冠する――〈ジブラルタル〉〈ボスポラス〉〈マラッカ〉〈ホルムズ〉。いずれも、二つの海を結び、世界の交易と戦の咽喉を握った隘路の名だ。

回廊が「[[回廊|回廊の海]]」と呼ばれるのは偶然ではない。星系（[[星系名|名峰]]）が天を衝く高みなら、回廊は星々を隔てる海であり、その海の最も狭まる関所が回廊である。

## 命名の作法
- **海峡由来**：回廊名は世界の名高い海峡・水道・運河（ジブラルタル／ボスポラス／ダーダネルス／マラッカ／ホルムズ／ドーバー／ベーリング／マゼラン／スエズ／パナマ ほか）から採る。
- **カタカナ表記**：原語を問わずカタカナで統一する。
- **「◯◯回廊」**：接尾に「回廊」を付して呼ぶ（例：ジブラルタル回廊）。
- **重複なし**：プールをシャッフルして引き、使い切れば連番フォールバック。

## 四つの命名体系（領分）
| 対象 | 名の出どころ | 実装 |
|---|---|---|
| **星系** | 世界の名峰（カタカナ・日本除く） | `MountainSystemNames` → [[星系名]] |
| **惑星** | 日本神話の神々 | `MythicPlanetNames` → [[惑星名]] |
| **旗艦** | 世界遺産・自然遺産（土地の名） | `HeritageShipNames` → [[旗艦]] |
| **回廊** | 世界の名高い海峡・水道・運河 | `Corridor`（[[回廊]]） |
