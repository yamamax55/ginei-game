# 世界遺産・自然遺産プール（旗艦名 参照プール）

> Ginei の**旗艦名**を払い出す参照資料。各旗艦は「失われた故郷の世界遺産・自然遺産」の名を負う。
> **情報源＝インターネット（UNESCO 世界遺産リスト）**：https://whc.unesco.org/en/list/ （実在 約1,248件＝文化972/自然235/複合41・2025年）。
> **ゲーム内の正＝`HeritageShipNames.Names`**（`Assets/Scripts/Core/Fleet/HeritageShipNames.cs`）と一致。有名なものから収録（計 548 件）。

## 命名規則（旗艦名への変換ルール）
- **一般地形語の接尾辞は省略**：島/諸島・海・湾・山地/山脈・湖・国立公園・砂漠・渓谷・滝・洞窟 等（例：ガラパゴス諸島→ガラパゴス、ハロン湾→ハロン）。固有名が消える複合語は残す（例：グレートバリアリーフ、グランドキャニオン）。
- **漢字名はカタカナ化**（例：京都→キョウト、姫路城→ヒメジ、兵馬俑→ヘイバヨウ）。
- **東西南北は英語読みカタカナ**（West=ウエスト/East=イースト/South=サウス/North=ノース。例：西ガーツ→ウエストガーツ）。
- **異名の方が有名ならそちらを採用**（例：エリザベスタワー→ビッグベン）。
- **★山岳・峰・火山・山脈系の名は除外**：星系名（`MountainSystemNames`）と命名域が重なる（星系は山岳名で命名）ため、旗艦名には使わない（例：フジサン／キリマンジャロ／タイザン／ドロミテ／ピレネー／テーブルマウンテン 等は除外）。
- **★古戦場との重複除外（予定）**：今後「有名な古戦場」プールを追加する。古戦場名と本プールが重複したら、**旗艦への割り当てから除外**（古戦場側を優先）。重複が出たらこの台帳に「除外」注記。
