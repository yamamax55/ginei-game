# ラフォンテーヌ海運商会

> [[灯心自由市ファロス]]の海運。大商人[[ジャン・ラフォンテーヌ]]が率いる。

## 概要
[[灯心自由市ファロス]]を本拠とする**海運**。大商人の[[ジャン・ラフォンテーヌ]]が興した商会で、財力は**中堅**と目される。港と航路を回し、灯心自由市ファロスの経済を裏から支える。

## 事業・経営
- 主力＝海運。財産は**貯金**で運用。利潤は法人税ぶん国庫へ（私有企業）。

## 関係
- 本拠勢力：[[灯心自由市ファロス]]
- 主・創業者：[[ジャン・ラフォンテーヌ]]（大商人）
