# 灯台（ラントゥル）

> [[回廊]]を管制する旧連合の中枢設備。大半が停止している。

## 概要
[[回廊]]の流れを読み、束ね、誰にどの航路を・いつ開くかを差配したのが、[[大環状連合]]の各所に建てられた管制中枢〈灯台（ラントゥル）〉。灯台が灯っているかぎり銀河は一つだった。

## 首座灯（だいいちとう）
銀河中心に据えられた最大の灯台。[[環暦|環暦元年（CE1）]]に原因不明の停止に陥り、連鎖して各地の灯台が沈黙した。その**制御鍵**が、死に絶えた回廊網をもう一度読み直し銀河を再び一つに束ねうる――銀河再統一の鍵。物語の終着点 → [[終章 ― 鍵の行方]]。

## 地方灯台
停止した灯台のいくつかは余命をたもち、地方に残った技術者が断片的に回廊を読み直した。**死んでいた回廊を「開く」**諸侯が現れたことで、戦略地図そのものが書き換わりはじめる（→[[第二章 ― 名もなき旗]]）。

## ゲーム実装
回廊管制の中枢。再起動＝戦略地図の書き換えとして[[回廊]]（`Corridor`/`GalaxyMap`）と連動。
