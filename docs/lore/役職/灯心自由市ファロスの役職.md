# 灯心自由市ファロスの役職体系

> 港湾都市国家＝**市民自治**。選出された統領と市民参事会が、一個の星に深く根を張る凝集の権力を担う。在任は[[灯心自由市ファロス#名鑑（所属の人物・組織）|名鑑]]・runtime で変動。

## 元首・統帥
- **統領**：市民参事会が選ぶ自由市の長（文民統制）。在任例 → [[ローラン・ロシュフォール]]。

## 政府役職（文官・官職）
- **市政長官・執政**：市政の実務を統べる（宰相相当）。
- **各局長**：港湾局／財庫／**灯台管制局**（生きた[[灯台]]の差配）。都市国家ゆえ地方総督は持たず、単一星系に官を集中。

## 立法・評議
- **市民参事会**：市民自治の合議体。政党＝[[市民自治党]]／[[灯台同盟]]／[[中道市民連合]]。

## 軍役職（階級＋指揮職）
- **港湾防衛艦隊司令**：要塞防衛・機動迎撃の守りの長。少数精鋭＋**傭兵運用**で中立を守る。
- **情報長**：四囲の均衡を読む偵察・諜報の長。
- 在任例 → [[アマーリア・ヴァレンティ]]（港湾防衛司令）／[[セリーヌ・マルロー]]（情報）。

## 勢力固有の役職
- **灯台管制長**（[[回廊|航路]]の開閉権）／**灯心自由市中央銀行総裁**（[[灯心フラン]]の発行）／**傭兵契約官**。
