# 官僚（かんりょう）＝文官

> 政を司る者。軍ではなく**省庁と位階**の中で国を回す常勤の文民。[[職分]]の屋台骨。

## 概要
**文官**は行政を本領とする[[職分]]＝官僚・宰相・総督。能力は**文才**――運営（行政の実務）と情報（諜報・調査）で測られる。武官（[[提督]]）が前線で戦うのに対し、文官は**省庁（二官八省）**に属し、官職と位階の階梯を昇って国家を運営する。神権国家では聖職者が文官機構を兼ねる（→ [[信仰]]）。

## 官職・位階・省庁
- **官職**：宰相・総督・各省の卿など。所掌（domain）とスコープ（中央／地方）を持つ。
- **位階**：従四位上のような序列。官職とは別に人物の格を示す。
- **省庁**：二官八省にならった縦割り組織。各省は省益（institutional interest）を持ち、行政効率は配属官僚の文才×充足率で決まる。

## 文民統制と政治
官僚機構は政治任用（[[人物/_政治家テンプレート|政治家]]）の上に常勤として横たわる。軍は文民政府の統制に服し（民主勢力ほど厳格 → [[黎明評議会連邦憲章#第四章　軍と文民統制]]）、文官はその統制の担い手でもある。稟議（目安箱）は文官機構を通って起案・決裁される。
