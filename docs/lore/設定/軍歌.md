# 軍歌（ぐんか）

> 勢力の魂を一節に込めた歌。出撃の鼓舞、戦没の悼み、そして大義の自画像――旗のもとで歌われる。

## 各勢力の歌
| 勢力 | 曲名 | 気風・一節 |
|---|---|---|
| [[碧晶公国]] | 「碧き玉座へ」 | 荘厳な行進曲。正統と秩序を讃える。〽 *血の絆は星より固く* |
| [[自由港同位体]] | 「五つの海の歌」 | 港々を巡る舟唄。祖国でなく航路を恋う。〽 *帰る港はどこにもなく、どこにでもある* |
| [[黎明評議会]] | 「灯を継ぐ者」 | 市民の合唱。反専制と自治を高らかに。〽 *一つの灯が消えても、無数の灯が継ぐ* |
| [[鉄環兵団]] | 「鉄の環」 | 勇壮な略奪行進。武功こそ序列。〽 *功を立てよ、明日は功の上にだけ来る* |
| [[灯心自由市ファロス]] | 「灯明の街」 | 中立都市の市民歌。武でなく信用を誇る。〽 *剣を持たぬ手で、灯を絶やさず* |

## 失われた賛歌
- **「環状の賛歌」**――[[大環状連合]]の旧国歌。かつて全銀河が同じ旋律を知っていたが、いまや**誰も全部は歌い切れない**。断片だけが各勢力の歌に紛れ込み、統一の記憶の残響となっている（[[環暦|大解体]]の象徴）。

## ゲームデータ参照
- BGM/SE の再生は `AudioManager`（`PlayBGM`/音量）。歌そのものはフレーバーだが、出撃・士気の演出フックとして `FleetMorale`（士気＝能力補正）と結べる。歌詞・曲は二重管理せずここに集約。
