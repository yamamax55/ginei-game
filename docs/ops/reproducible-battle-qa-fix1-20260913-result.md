## 2. 原因

### 2.1 退却：観測時間が、実際に動くまでの時間より短かった（製品の不具合ではない）

`FleetAI` と `FleetMovement` を読んで確かめた。
- プリセットでは退却軍団が敵（上方向）を向いて置かれている（向き 0 度）。退却方向はその反対（下方向）。
- 撤退状態では、敵との距離が 50 と `reverseRetreatRange=14` より遠い。そのため後退移動ではなく通常移動（`SetDestination`）を使う。
- `FleetMovement.MoveProcess` は、正面が目標から ±`faceThreshold`(10度) に入るまで `targetSpeed=0` のまま（その場で回頭するだけ）。回頭の速さは `rotationSpeed=42度/秒`×機動倍率で、紡錘陣の 1.10 などが掛かり、約 1.0〜1.1 と見積もった。
  - 艦隊1は約 170 度回ってから加速を始める。かかる時間は約 3.7〜4.0 秒。
  - 艦隊2・3は、敵が x=0 にいるので退却方向が約 9 度ずれ、回る角度が少し小さい。そのぶん早く動き出す。変位が艦隊1より大きいのはこのためと読める。
- 動き出した後は `acceleration=1.4` なので、1 単位進むのに約 √(2/1.4)≈1.2 秒かかる。
- 合わせると、しきい値に届くまで**最低でも約 5.3 秒**かかる。4 秒の観測は、回頭が終わった直後で打ち切っていた。0.16 と 0.34 は、加速し始めて数分の1秒ぶんの変位と矛盾しない。
- 退却経路がリセットされていないかも確認した。`FleetAI` は毎フレーム `SetDestination(pos + 敵から離れる向き×20)` を呼ぶが、`SetDestination` は `currentSpeed` と回頭をリセットしない。目的地の向きも毎フレーム変わらない。`BattlefieldCommandManager.ApplyCorpsRetreat` は状態を撤退にするだけで、移動の API は呼ばない。混雑による減速も確認した。`escortCount=0` なので外接円の半径は `spacing=1.2`、隊どうしは 8 離れていて接触しない。**リセットや減速を起こす製品側の不具合は見つからなかった**。

### 2.2 不退転：初期士気 30 が高く、効果の 8 秒では実被弾で下限まで下がらなかった

- 標的は撃ち手に背を向けているので交戦にならず、`FleetMorale` の自然回復（0.7/秒）が被弾による低下と打ち消し合う。
- 実測では、効果 8 秒間の正味の低下が 21=18.4、22=13.8 だった（30 から 1 までは 29 必要）。
