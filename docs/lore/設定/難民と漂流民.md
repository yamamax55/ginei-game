# 難民と漂流民（なんみん・ひょうりゅうみん）＝故郷を失った者たち

> 「灯が消えた夜、回廊の途中で立ち往生した船団がいた。彼らはまだ、どこかを漂っているという。」

## 核心（大解体が生んだ、国を持たぬ民の群れ）
[[環暦|大解体]]で[[灯台]]が沈黙し[[回廊]]が乱れたとき、無数の人々が故郷と航路を同時に失った。星系を追われた者、回廊の途中で漂流した船団、戦に焼かれた植民星の民――彼ら**難民・漂流民**は、どの[[諸侯]]にも属さぬまま辺境をさまよう。受け入れれば[[労働|労働力]]と[[人口|徴募源]]になり、拒めば[[流言|不穏]]と疫病の種になる。難民の処遇は、その勢力が掲げる**大義の本音**を露わにする試金石である。

## 難民をめぐる力学（重荷か、資源か）
- **受け入れの損得**――難民は[[労働]]力・[[人口]]・[[植民|入植]]の担い手になるが、食と職と治安の負担にもなる（→ [[財政]]・[[医療と疫病]]の疫病リスク）。
- **棄民と排斥**――重荷とみて締め出せば、難民は[[海賊]]・[[通商破壊|私掠]]・傭兵に流れ、盤外から刃を返す。
- **亡命貴族・亡命将**――身分ある者の漂流は別格。請求権を抱えた[[捕虜と亡命|亡命者]]は、次の戦の大義名分にも駒にもなる（→ [[旗幟]]・[[名誉と面子]]）。
- **漂流船団の伝説**――灯の消えた夜に回廊で消えた船団の噂は[[流言]]の定番。[[信仰|故地回帰派]]はこれを「故郷へ還る兆し」と説く（→ [[信仰]]）。

## 勢力ごとの処遇
- [[碧晶公国]]――身分なき難民を厄介者として辺境に押し込める。亡命貴族だけは家格次第で遇する（→ [[身分]]）。
- [[黎明評議会]]――難民受け入れを理念とし[[植民|入植]]へ繋ぐが、急増は財政と治安を圧迫し政争の火種に（→ [[政体]]の民主の負荷）。
- [[鉄環兵団]]――使える者は兵に、使えぬ者は捨てる。難民は格好の徴募源（→ [[階級]]の実力主義）。
- [[自由港同位体]]――労働力として受け入れ商売に組み込むが、無慈悲な使い捨ても辞さぬ（→ [[商人]]）。
- [[灯心自由市ファロス]]――市民権を絞り、難民は周縁の労働者層に留める都市の現実。

## NPC・クエストへの適用指針
- **難民のリーダーNPC**（誇りと窮状）――「施しが欲しいんじゃねえ。土地と、働く場所をくれ。それだけで、俺たちはあんたの民になる。」
- **排斥派の役人NPC**――「これ以上は受け入れられん。食わせる分がない。……どこへ行く？　それは、こちらの知ったことではない。」
- **クエスト分岐**：漂流船団/難民の群れと遭遇 → (a) **受け入れる**＝労働力・徴募源を得るが負担と疫病・治安リスク（→ [[医療と疫病]]）／(b) **見捨てる/締め出す**＝負担を避けるが彼らが海賊・敵に流れる／(c) **選別して使う**＝有用な者だけ取り、残りは切る（[[民心]]・[[名誉と面子]]を損なう）。

## ゲームデータ参照
- 難民そのものに専用機構はない（ナラティブ層）。受け入れは[[人口]]（移住＝`PopulationMigrationRules`＝住みよい星系へ移動・亡命）・[[労働]]（労働力）・[[植民]]（`ColonizationRules`）へ接続。亡命将・請求権は[[捕虜と亡命]]（`PersonFate`／`CaptiveStatus`／`isFreeAgent`＝在野）。海賊化は[[通商破壊]]（`CommerceRaidingRules`）、負担は[[財政]]・[[民心]]（`Province.livingStandard`）・[[医療と疫病]]。
