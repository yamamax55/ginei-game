## `PauseManager` に足したもの（3つとも読み取り専用の窓口）

```csharp
public bool IsPaused => isPaused;                       // 状態の出所を一つにする
public static bool IsTimeInputDeferred                  // 艦隊詳細・編制パネル
    => FleetDetailPanel.IsOpen || OrderOfBattlePanel.IsOpen;
public bool IsSystemUiShown                             // システムメニュー・設定
    => (pauseMenuRoot != null && pauseMenuRoot.activeSelf)
    || (settingsPanel != null && settingsPanel.activeSelf);
```

後ろ2つは**既にあったインライン条件**を名前付きにしたもので、
`HandleInput`（Space を譲る判定）と `UpdateActivePauseState`（アクティブポーズの許可）が
そのまま同じ式を使い続けています＝**Space の挙動は変わっていません**。
ボタンも同じ窓口を見るので、判定が二重実装になりません。
`EnsureEventSystem()` は中身が状態を持たないので `public static` にして再利用しました（新規生成しない）。

## 巨大な PAUSE 表示への対処（決め打ち座標にしなかった理由）

調べたところ、あの表示（`PauseManager.timeScaleText`）は `Battle.unity` の Canvas に載っていて、
その `CanvasScaler` は **参照解像度 800×600・match=0（幅基準）** でした。
一方この HUD や `TimeDisplay` は 1920×1080 参照です。
つまり同じ「24pt・200×50」でも**画面上では約2.4倍**になり、
1920 幅では上端から約 38〜158 px を占めます（これが「巨大な PAUSE 表示」の正体）。

座標を直接そろえると確実に隠れるので、
`GetWorldCorners()` でその表示の**実際の画面矩形を毎フレーム測り**、
左端から 12 px 左・縦は中央にそろえて置いています（`LayoutBesideTimeLabel`）。
矩形が変わらないフレームでは何も書き換えません。
表示が見つからない構成では従来どおり固定オフセットにフォールバックします。

上端中央の「下」へ逃がさなかったのは、そこが縦に詰まっているためです
（戦況バー −8..−24 → PAUSE 表示 −38..−158 → 戦況メッセージ −192..−312、しかも全幅）。
横へ避けるほうが安全でした。

## 実機での確認手順（ChatGPT へ）

Unity Play → タイトル →「会戦開始」→ シナリオを選んで会戦へ（**フルスクリーン会戦**）。
※ 戦略マップから潜行する**ウィンドウ化会戦にはボタンを出しません**
（そこでは時間制御を統一クロックが担い `PauseManager` 自身が止まっているため。仕様どおり）。

1. **見た目**：画面上端、`SPEED: 1.0x` 表示のすぐ左に「停止」ボタンが出る。
   濃い半透明で控えめ、文字は読める。艦隊HUD・戦況バー・戦況メッセージに重なっていない。
2. **ホバー**：マウスを乗せたときだけ少し明るくなる。
3. **停止 → 再開 → 停止**：クリックで「停止」→「再開」→「停止」と文字が入れ替わり、
   艦の移動・時刻表示（右上の日付/時刻）が止まる／動くこと。
4. **直前の速度**：`2` キーで 2 倍速にしてから停止 → 再開 → **2 倍速のまま**戻ること
   （`SPEED: 2.0x` 表示で確認）。
5. **Space との同期**：Space で停止 → ボタンが「再開」になる。Space で再開 → 「停止」に戻る。
   ボタンで停止 → Space で再開 → 表示が追従する。
6. **アクティブポーズ**：ボタンで停止中に艦隊を選択し、右クリックで移動命令を出せること
   （上端表示が `PAUSE（命令可能）` になる）。再開すると実際に動き出すこと。
7. **クリック透過しないこと**：ボタンの上でクリックしても、**背後の盤面で選択が外れたり
   移動命令が出たりしない**こと（ボタン直下に艦隊が居る状態で試すと分かりやすい）。
8. **モーダルの停止維持**：
   - 艦隊をダブルクリック等で**艦隊詳細**を開く → ボタンが**消える**（その停止を解除できない）。閉じると戻る。
   - `O` キーで**編制画面** → 同上。
   - `Esc` で**システムメニュー** → 同上。メニューの「再開」で戻ること。
9. **残留しないこと**：会戦 → 結果 → タイトル → もう一度会戦、と往復して
   ボタンが**1つだけ**出ること（重なって濃くなったり、二重に反応したりしない）。
10. **支援要請（第5次の続き）**：停止／再開を挟んでも、他軍団への要請の返事と実移動が
    これまでどおり進むこと（要請の時間は game-time で進むため、停止中は止まって当然）。
