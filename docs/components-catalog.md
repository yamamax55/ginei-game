# 既存コンポーネント・カタログ

> CLAUDE.md から分離した詳細リファレンス（#CLAUDE.md分割）。各コンポーネントの責務・主なAPI・依存。
> **現状＝正。これに合わせる**。CLAUDE.md 本体には索引（クラス名）だけを残し、詳細はここを引く。
> 新規コンポーネントを足したら、この表に1行追記し、CLAUDE.md の索引にもクラス名を加える。

### システム・管理層
| クラス | 対象 | 責務 / 主なAPI |
|---|---|---|
| `BattleSetup` | Battle シーンに1つ | `[DefaultExecutionOrder(-100)]`。**`SceneManager.GetActiveScene().name != "Battle"` の場合は Awake で即 return**（Title 等に誤配置されても艦隊を湧かせない）。`ScenarioData` から艦隊生成・配置。`fleetPrefab` 必須。生成時に手置き艦隊をクリア＋`FleetRegistry.Clear()`。生成位置は原点中心に `spawnSeparation`(既定2.5)倍して両軍を離す。生成後 `OrientFleetsToEnemy` で各艦を相手陣営重心へ正対させる。プレイヤー陣営以外のみ `FleetAI` を有効化。`scenarioOverride` で直接指定可。**複数艦隊の会戦**：`BattleHandoff.IsMultiFleet` なら `SpawnHandoffFleets`＝明細の各艦隊を1旗艦として陣営ごと（左x=-7/右x=+7）に縦並びで湧かせる（接敵内容を会戦へ合わせる・1対1へ畳まない）。**惑星攻城(#131)**：`BattleHandoff.IsPlanetSiege` なら `SetupPlanetSiege`＝中心に `SiegeArena`(惑星＋首飾り射程リング)、攻城艦隊を惑星周囲に円環配置（射程外・惑星へ正対・プレイヤー操作）。 |
| `BattleManager` | Battle シーンに1つ | 勝敗判定（`checkInterval` 秒ごと、`EvaluateVictory`）・戦績記録。**勝利条件**は `ScenarioData.victoryCondition` に従う：殲滅/時間防衛(`objectiveFaction` が `timeLimit` 秒生存)/旗艦撃破(`targetAdmiral` 撃破)/護衛(`targetAdmiral` を守り切る)。**汎用の終了条件は「敵対する旗艦ペアが残っていない」**（`HasHostilePair`＝多勢力対応の殲滅）。勝者勢力は残存旗艦数最多（同数は兵力）＝`DetermineWinner`、`winner`(legacy enum)＋`winnerName`(勢力名)＋`victoryReason`＋MVPを `GameSettings` に記録し `ResultManager` が表示（3勢力以上対応）。**戦績は勢力名キーで集計**：開始時数 `CountInitialByFaction`→決着時 `RecordFactionStats` で勢力ごとの残存数/残存兵力/喪失数を `GameSettings.factionStats` に格納（旧 imperial/alliance フィールドも後方互換で併記）。`ResultManager` は `factionStats` があれば勢力数可変で表示、無ければ2勢力にフォールバック。生存数・敵対判定は `FleetRegistry.AllFlagships`＋`FactionRelations.IsHostile`/`LegacyOf`（退却・破棄・配下艦は数えない）。**非戦闘艦(#128)は勝敗判定から除外**＝`CountsForVictory`(生存かつ `IsCombatant`)で `HasHostilePair`/`DetermineWinner`/勝者代表を絞る（撃沈はされうるが終了条件・勝者算定に数えない）。経過時間 `battleElapsed` は timeScale 追従（ポーズで停止・倍速で加速）。開始時隻数は全 Start 完了後の最初の Update で記録。決着で timeScale=0→Result へ遷移。Rキーでリスタート。**戦略からの実会戦(C-2 #586)**：`BattleHandoff.Pending` なら決着で `WriteHandoffResultAndReturn`(残存兵力を `StrengthScale` で割り戻し→`returnScene` へ)。**Handoff 経由の会戦は殲滅で判定**＝`ResolveScenarioAndVip` は `BattleHandoff.Pending` の間 `scenarioName` を Resolve しない（直前に遊んだ単発シナリオの勝利条件〔旗艦撃破/護衛 等〕を引き継いで**対象VIP不在で即決着するバグを修正**）。**Backspace でいつでも戦略マップへ復帰**＝暫定優勢側(`LeadingFaction`)を勝者として書き戻し撤収（以後は自動委任）。開始時にHUDで操作を通知。 |
| `FleetRegistry` | static（シーン内在庫） | 全 `IShipTarget`（旗艦＋配下艦）を**陣営非依存の単一リスト**で保持（多勢力対応）。各艦が出現時 `Register`／破棄・退却時 `Unregister`。`AllTargets`(全個艦)/`AllFlagships`(全旗艦)/`Clear()`。敵味方は探索側が `FactionRelations.IsHostile` で判定する（陣営別バケットは廃止＝`GetEnemies`/`GetFlagships(faction)` は無い。全艦を巡回して判定）。`ShipCombat`/`FleetWeapon`/`EscortShip`/`FleetAI`/`BattleManager`/`FleetCommander`/`BlackHole`/`FleetMovement` がここを参照（`FindObjectsByType` を置換）。`BattleSetup.Awake` が `Clear()`。 |
| `TitleManager` | Title シーン | 新規開始/続きから/設定/終了。`SaveManager` と連携、`continueButton`/`settingsPanel` 参照、`SetVolume`。**シナリオ選択／プレイ陣営選択UIを実行時生成**（自前 Canvas＋全画面ディマーのモーダル、初期非表示）。フロー：「会戦開始」=`StartBattle()`→`ShowScenarioSelect()` で選択画面表示／`SelectScenario(string)` で `GameSettings` に反映＆ハイライト更新。**プレイ陣営は `Resources/Factions` の `FactionData` を列挙してボタン動的生成**＝`SelectPlayerFactionData(FactionData)`(`playerFactionData`＋`legacyFaction`を`playerFaction`へ)。**アセットが無ければ従来の2勢力 enum ボタンにフォールバック**＝`SelectPlayerFaction(int)`。3勢力目は `Resources/Factions` にアセット追加だけでタイトルから選べる／「この設定で会戦開始」=`BeginBattle()` で Save＋ResetStats＋`LoadScene("Battle")`／「戻る」=`HideScenarioSelect()`。**戦略（キャンペーン）導線**：「銀河の戦役（新規）」=`ShowCampaignSetup()`＝**キャンペーン設定モーダル**（実行時生成・専用 Canvas sortingOrder=55）でプレイ陣営（`FactionData`列挙 or enumフォールバック）と難易度（`CampaignDifficulty` 易しい/普通/難しい＝`SetCampaignDifficulty`・`CampaignDifficultyRules.Describe` 表示）を選び「この設定で戦役開始」=`StartCampaign()`＝`GalaxyView.BeginNewCampaign()`(StrategySession 破棄)→`LoadScene("Strategy")`／「戦役を再開」=`ContinueCampaign()`＝`CampaignSaveManager.LoadSession()`→`LoadScene("Strategy")`（`continueCampaignButton` は `CampaignSaveManager.HasSave()` の時だけ活性）。`DestroySelectionUI` は会戦/戦役遷移で選択UI＋設定モーダルを破棄。Canvas/EventSystem(`InputSystemUIInputModule`) が無ければ生成。**設定画面もフルスクリーンで実行時生成**(`OpenSettings()`→`BuildSettingsScreen()`、銀河背景＋暗幕の専用 Canvas sortingOrder=70)：スライダーで「マスター音量」「開始ズーム(`cameraStartZoom`)」、ボタンで「ゲーム速度(`defaultTimeScale` 1x/2x/3x)」「射界表示(`alwaysShowGizmos`)」を設定し即時反映、「戻る」=`CloseSettings()` で `GameSettings.SavePrefs()` 永続化。uGUI Slider はコード生成(`CreateSlider`)。旧式の手置き `settingsPanel` は不使用(非表示)。 |
| `ResultManager` | Result シーン | `GameSettings` の戦績を `winnerText`/`statsText` に表示。`BackToTitle()`。 |
| `CampaignEndOverlay` | Strategy シーン | **戦役（キャンペーン）の終了画面**（遊べる縦スライスの締め）。`GalaxyView.RunCampaignVictoryCheck` がプレイヤー勢力の勝敗（`CampaignVictoryRules`）を判定したとき `Show(win, player, ownedFraction)` で全画面モーダル（勝利=金/敗北=赤＋支配率＋決着日時`TimeDisplay.TryFormatNow`）を出す。「タイトルへ戻る」=`StrategySession.Clear`＋`BattleHandoff.Clear`＋`GalaxyView.ResetCampaignStatics`→`LoadScene("Title")`／「観戦を続ける」=閉じて停止中の盤面を眺める。統一クロックは既に `GameClock.Pause` 済み＝本オーバーレイは入力を塞ぐだけ（`IsOpen` を `GalaxyView.Update` が見て譲る）。UIは実行時コード生成（`SystemDetailPanel` と同作法）。 |
| `PauseManager` | Battle シーン | Space=ポーズ／Esc=ポーズメニュー／数字1-3=倍速。`Time.timeScale` 制御。ポーズUIをコードで自動生成し EventSystem(`InputSystemUIInputModule`) を保証。`SetVolume`/`SetAlwaysShowGizmos`。 |
| `PlaytestRunner` | Battle シーン（QA自動化） | **自動プレイテストの駆動殻**。AI対AIで会戦を速回し（`forceAllAI`＝全旗艦の `FleetAI` を有効化／`timeScale`）、`FleetRegistry.AllFlagships` で生存戦闘艦数・総移動量をサンプリング、`Application.logMessageReceived` で例外/Error 捕捉、`GameSettings.winner`/Result 遷移で決着判定。観測(`PlaytestObservations`)を **Core の `PlaytestInvariants` に渡して所見(`PlaytestReport`)を導き JSON 出力**＝判定ロジックは持たない（薄い殻）。起動：起動引数 `-ginei-playtest [シナリオ名] [出力パス]`（`Bootstrap`＝`RuntimeInitializeOnLoadMethod`・引数が無ければ通常プレイ）or 任意 GameObject に AddComponent。GameCI(headless Unity)で無人実行する想定。**既存スクリプト非改変・追加のみ**。`LastReport`。**スクショ可視化(`-ginei-shots [出力ディレクトリ]`＝`captureScreenshots`/`screenshotDir`/`screenshotIntervalSeconds`/`maxScreenshots`)**＝会戦中に `ScreenCapture.CaptureScreenshot` で PNG を定間隔＋決着時に撮る（描画が要る＝`-nographics` 不可・既定OFFで後方互換）。**`playtest-visual.yml`** が StandaloneLinux64(Mono) をビルド→xvfb 上で起動→PNG＋JSON を artifact 化＝ローカルで Unity が動かない環境でもクラウドで会戦を描画して結果だけ見られる。 |

### 入力・UI・カメラ
| クラス | 対象 | 責務 / 主なAPI |
|---|---|---|
| `UIWindowStack` | static（Core・#ウィンドウESC） | 重ねて開いたウィンドウを「最前面から1枚ずつ」ESCで閉じる**中央スタックの唯一の窓口**。`Register(isOpen, close, order, name)`→トークン／`Unregister(token)`／`CloseTopmost()`(最前面=`order`最大・同 order は新しい登録 を1枚閉じ true／開いている窓が無ければ false＝フォールバックへ)／`AnyOpen`/`Clear`。観測オーバーレイ(G/J/M/N/E/P)・`HelpOverlay`(H)・`FleetDetailPanel`/`OrderOfBattlePanel`/`SystemDetailPanel`/`SystemMapWindow`/`FleetOrganizationPanel`/`DecisionBoardPanel` が Awake/Build で登録し OnDestroy で解除。**各ウィンドウは Esc を直読みしない**（`escapeKey` 読みを増やさない＝二重実装回避）。会戦=`PauseManager.HandleEscape`、戦略=`GalaxyView.HandleStrategyEscape` が呼ぶ。純ロジック（UnityEngine 非依存・test-first）。 |
| `StrategySystemMenu` | Strategy シーン | 戦略のシステムメニュー（#ウィンドウESC・会戦の `PauseManager` ポーズメニューの戦略版）。重ねたウィンドウを ESC で全部閉じたあと、もう一度 ESC で開くフォールバック＝**再開／セーブ（`GalaxyView.SaveCampaign`）／タイトルへ戻る（`StrategySession.Clear`＋`BattleHandoff.Clear`＋`GalaxyView.ResetCampaignStatics`→Title）**。表示中は統一クロックをポーズ。`IsOpen`/`Toggle`/`Open`/`Close`。`GalaxyView` は `IsOpen` の間 盤面入力を譲る。Esc 制御は `GalaxyView` が `UIWindowStack` 経由で行うため自前でキー直読みしない。自動生成（`HelpOverlay` と同方式）。 |
| `FleetCommander` | 入力統括(1) | 選択の唯一の窓口 `SelectedFleets`(`List<Selectable>`)。左ク=選択（空白で解除／別艦で切替、UIは無視）／右ク=`CommandMenu`。移動先指定モード `StartWaitingForMoveTarget()`＋`IsWaitingForMoveTarget`：カーソルで位置→**右押下で目標確定→押したままドラッグで向き→離して確定**（`SetDestination(pos, 向き)`）、Esc/で取消。`FormationPreview` で配置を半透明表示。**後退指定モード** `StartWaitingForReverseTarget()`：同じ `isWaitingForMoveTarget` フローを `moveIsReverse` で共用（Esc/Pause連携も流用）。向きドラッグ無し＝**現在の向き（射界）を維持**して位置のみ指定、右クリックで確定し `SetReverseDestination(pos)`（追尾は解除＝後退と競合させない、射界内の敵には自動発砲継続）。**前方（向き側）には移動先プレビューを出さず確定も不可**（`IsReversibleTarget`＝前方成分>0で不可。後退で到達できない場所を指示させない）。攻撃目標指定モード `StartWaitingForAttackTarget()`＋`IsWaitingForAttackTarget`：**左クリック=通常攻撃を即時発令／右クリック=攻撃種別メニュー(`CommandMenu.OpenAttackTypeMenu`、通常/ミサイル)を開く**。敵艦（旗艦/配下艦）を親までさかのぼり**その敵艦隊全体**を選択中全部隊の手動攻撃目標に設定（`ConfirmAttack`→`SetManualTargetFleet`＋`SetMissileMode`、確定で `ConfirmPendingAttack`）、`FleetHUDManager.ShowMessage` で「攻撃対象：◯◯艦隊（種別）」を表示、Escで取消。**艦隊円**(`UpdateFleetCircles`/LateUpdate、`Squadron.GetBoundingCircle`＋LineRenderer プール、マテリアル共有・頂点色で色分け)：選択中の艦隊は常時緑円、攻撃目標指定中は全敵艦隊を黄円（カーソル下は橙）で囲う。**ZOC円(#81)**：選択中の自艦隊は薄い `zocSelfColor` 円、攻撃目標指定中のみ敵艦隊を薄赤 `zocEnemyColor` 円で囲う（半径は `ZoneOfControl.GetRadius`＝外接円×zocRadiusScale、`DrawCircleRadius`）。色/線幅は `selectionCircleColor`/`targetCircleColor`/`targetHoverColor`/`zocSelfColor`/`zocEnemyColor`/`circleWidth`。確定/取消後 `DeselectAll`。`SelectFleet`/`GetMouseWorldPosition()`。**陣形変更の実体 `ChangeFormation(int)`**（`CommandMenu`/`FleetHUDManager` はここへ委譲）。**部隊グループ(#83・`HandleControlGroups`)**：Alt＋1/2/3（`GameInput.グループ選択1〜3`＝会戦コンテキスト・**Alt修飾で倍速（素の数字）・Unityエディタの Ctrl＋数字（ウィンドウ切替）と分離**）で、選択中の艦隊があれば `controlGroups` へ割り当て、無ければそのグループを呼び出して選択（破棄・退却艦は除外＝`IsAlive`）。割当/呼出は同じキーで状況により切替。 |
| `CameraController` | Main Camera | パン(WASD/矢印/中ドラッグ)・**画面端スクロール(#87・`edgeScrollEnabled`/`edgeMargin`/`edgeScrollSpeed`＝マウス画面端でパン・非フォーカス/画面外/中ドラッグ中は無効・`GameSettings.edgeScrollEnabled` を毎フレ反映)**・**カーソル中心ズーム(#87・ホイール前後でカーソル下ワールド座標を維持＝`ScreenToWorldPoint` 差分で位置補正)**(`zoomSpeed`/min/maxZoom)・開始時は `startZoom`／`GameSettings.cameraStartZoom`・F=選択艦隊フォーカス・min/maxBounds クランプ・撃沈時 `Shake()`（unscaled で減衰、LateUpdate でオフセット復元）。設定トグルは `TitleManager` 設定画面（射界表示の隣・`edgeScrollEnabled` を PlayerPrefs 永続化）。 |
| `CommandMenu` | uGUI | 右クリックメニュー。選択状況で 移動/後退/攻撃/陣形変更/情報/選択 を動的生成。「後退」は `FleetCommander.StartWaitingForReverseTarget()`（向きを保って下がる）。「攻撃」は選択中つねに表示し、押すと `FleetCommander.StartWaitingForAttackTarget()` で目標指定モードへ移行（左ク=通常攻撃／右ク=攻撃種別メニュー）。`OpenAttackTypeMenu(screenPos)` で通常/ミサイルの選択メニューを開く。陣形サブメニューのボタンは `Formation` enum から動的生成（`BuildFormationButtons`、シーン手配線に非依存）。**「軍団陣形」/「前列交代」は軍団長が乗艦している軍団旗艦(`IsCorpsFlagship`)の選択時のみ表示**（CSG＝乗艦している艦からのみ軍団指揮）＝同じ陣形サブメニューを軍団モード（`corpsFormationMode`）で開き選んだ陣形で `CorpsFormation.FormCorpsFromSelection`（選択艦隊で集結・軍団長は後方）／`CorpsFormation.RotateCorps`（方陣の前列を後方へ）。`OpenMenu`/`CloseMenu`/`IsOpen`/`ChangeFormation(int)`。画面端クランプ。 |
| `FleetHUDManager` | uGUI | 選択艦隊の 提督/陣営/兵力バー/士気バー/陣形 を表示。任意で `shipCountText`(旗艦艦艇数＋配下艦残存数)を表示。`ChangeFormation(int)`。`ShowMessage(text, duration)` で画面上部に通知を実時間で一定時間表示（攻撃対象通知などに使用、TMPテキストを実行時生成）。 |

### 戦略レイヤー（Phase C／純ロジックは test-first）
> 銀河グラフ（星系＝ノード／回廊＝エッジ）上を戦略艦隊が時限ワープで移動し、敵対勢力に挟まれた回廊（前線）では亜光速で侵入→接触で実会戦（Battle シーン）に移行する。**敵対判定は `FactionRelations`、艦在庫は `StrategicFleetRegistry`、戦闘ロジックは `StrategyRules`（static）が唯一の窓口**。非 MonoBehaviour の純データ/純ロジックは EditMode テストで担保（`Assets/Tests/EditMode`）。
