# カンチェンジュンガ星系

> ヒマラヤの霊峰を継ぐ、灯台の聖座たる港湾都市国家――[[灯心自由市ファロス]]の首都。

## 概要
〈カンチェンジュンガ〉の名を冠する星系。[[灯心自由市ファロス]]の首都星系で、武装中立を貫く[[都市国家]]。首星[[ツクヨミ]]――月の神の名のとおり、夜の航路を照らす[[灯台]]の聖座を抱く港湾都市。市民自治のもと、港と財庫を回す実務[[官僚]]と[[海賊・私掠・傭兵|傭兵]]運用が独立を支える。

## 地理・接続
- 隣接回廊：[[ホルムズ回廊]]（↔[[モンブラン星系|モンブラン]]・[[灯台]]管制）／[[ドーバー回廊]]（↔[[エベレスト星系|エベレスト]]）＝要衝の灯台が航路を扼す
- 主要惑星：[[ツクヨミ]]（首星・自由市／日本神話の月の神＝[[惑星名]]）

## 産業・資源
- 港湾交易・[[金融]]と[[灯台]]管制の利権。[[要塞]]防衛・機動迎撃・[[海賊・私掠・傭兵|傭兵]]運用で中立を守る。→ [[灯心自由市ファロスの内政]]・[[通貨|灯心フラン]]

## 帰属・歴史
- 現支配：[[灯心自由市ファロス]]（中立・[[都市国家]]）
- 過去の領有：旧[[大環状連合]]の灯台管制拠点。灯台沈黙後、市民が自由市を宣して独立を維持。
