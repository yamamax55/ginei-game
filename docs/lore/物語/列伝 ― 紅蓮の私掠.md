# 列伝 ―― 紅蓮の私掠

> 視点：[[キアラ・ヴェントゥーラ]]（[[自由港同位体]]・私掠エース）。中核の幹との交点＝回廊での船団をめぐる交差。

銀河は広い。儲け話はもっと広い。[[自由港同位体]]の遊撃隊長[[キアラ・ヴェントゥーラ|キアラ]]は、ゴーグルを跳ね上げて不敵に笑う。神出鬼没の機動で敵の補給線を食い破る私掠の名手にとって、灯の消えた乱世は、危ない橋ほど旨い儲けが転がる絶好の漁場だった。

その日、キアラの遊撃隊が狙ったのは、ある痩せた交易船団だった。だが網を絞った[[マラッカ回廊]]の出口で、彼女は妙なものを見る――三倍の征伐軍に正面から押されながら、じりじりと退く一隊。負け戦に見えて、退き方が美しすぎた。回廊の分岐を一本ずつ確かめるような、計算ずくの後退。「……あれは、誰だい」。

伏兵が死んだ回廊から湧き、大軍の横腹を貫いた瞬間、キアラは口笛を吹いた。儲けより面白いものを久しぶりに見た、という顔で。守るも食らうも損得しだいの自由港にあって、彼女は一つだけ義理を通す――一度懐に入れた船乗りは見捨てない。その気風が、寄せ集めの遊撃隊を一枚岩に変える。

「[[ミレイア・セルウィン|ミレイア・セルウィン]]、ねえ」。標的の船団は、その名もなき女の旗の下にあった。襲うか、それとも――手を組めば、もっと広い儲け話になるか。博徒は危ない賭けほど好む。キアラは小型艇の舵を切り、紅蓮の髪をなびかせて、まだ見ぬ取引へと加速した。
