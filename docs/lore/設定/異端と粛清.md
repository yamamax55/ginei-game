# 異端と粛清（いたんとしゅくせい）＝信仰が刃に変わるとき

> 「同じ灯を拝んでいたはずだ。なのに、解釈がひとつ違うだけで、昨日の隣人が今日は薪の上さ。信仰ってのは、人を救うのと同じ手で、人を焼くんだ。」

## 核心（信仰の分岐が、迫害と粛清の口実になる）
[[信仰]]は[[民心]]を束ね救いを与えるが、教義の解釈が分かれた瞬間、それは**異端を裁き粛清する刃**に変わる。[[環暦|大解体]]で[[灯台]]の沈黙という共通の傷を負った銀河には、灯をめぐる無数の信仰が生まれ（→ [[信仰]]）、正統を称する側が異端を弾圧する構図が各地に生じた。異端審問は[[罪と罰|刑罰]]と結びつき、棄教の強制・殉教・密かな信仰を生む。だが信仰の弾圧はしばしば、純粋な教義問題ではなく**政敵排除・支配強化の口実**であり、「異端」の烙印は[[流言|中傷]]と[[報道と宣伝|宣伝]]で塗り重ねられる。

## 粛清の構図（信が刃になる道筋）
- **正統と異端**――どの解釈が正統かを定める権力。正統を握る者が異端を裁く（→ [[信仰|灯統教会]]の位階）。
- **審問と棄教**――異端審問が[[罪と罰|拷問・処刑]]で棄教を迫る。密かに信仰を守る者（→ [[名と諱|偽装]]・[[旅券と身元]]）。
- **殉教と聖性**――迫害に殉じる者は信徒の英雄になる。弾圧が逆に信仰を強める皮肉（→ [[葬礼]]・[[語録]]）。
- **異端の烙印の政治利用**――政敵・[[賤業と穢れ|周縁の者]]・少数派に「異端」を着せて排除する口実（→ [[正史と稗史]]・[[名誉と面子]]）。

## 粛清が動かす物語
- **信仰を隠す者**――表向き棄教し、密かに信を守る二重生活。露見の恐怖と密告（→ [[諜報機関]]・[[流言]]）。
- **弾圧と反乱**――苛烈な粛清が信徒の蜂起を招く。宗教戦争の火種（→ [[戦争]]・[[民心]]）。
- **故地回帰派の地下化**――黙示的な[[信仰|故地回帰派]]は異端として追われ、地下で[[灯台|首座灯の鍵]]を狙う影の動力（→ 物語の核）。
- **寛容という選択**――異端を許すか裁くか。寛容は安定を、弾圧は純化と分断を生む（→ [[政体]]）。

## 勢力ごとの異端観
- [[碧晶公国]]――[[信仰|灯統教会]]を国教格とし、異端審問が制度化。正統の維持が[[身分]]秩序と一体（→ [[碧晶公国大憲章]]）。
- [[黎明評議会]]――信教の自由を法で保障し、異端粛清を退ける。だが少数派への偏見はなお残る（→ [[黎明評議会連邦憲章|市民の権利]]）。
- [[鉄環兵団]]――信仰に無関心ゆえ寛容だが、軍規を乱す狂信は容赦なく潰す実利（→ [[階級]]）。
- [[自由港同位体]]――商売に信仰は問わぬ寛容。あらゆる信徒が交わる港だが、揉め事の種にも（→ [[巡礼と聖地]]）。
- [[灯心自由市ファロス]]――灯の儀礼を重んじるが、市民の信仰は不問とする都市の実利（→ [[都市国家]]）。

## NPC・クエストへの適用指針
- **異端審問官NPC**（正統の刃）――「貴公の唱える教義は、灯統の正典から外れておる。悔い改め、棄教を誓うなら、命だけは助けよう。……さもなくば、薪の上だ。」（宮廷語の慇懃＝→ [[言語]]）
- **隠れ信徒NPC**――「表じゃ正統の灯を拝んでるさ。だが心の中の灯までは、奴らにゃ消せねえ。……あんた、密告するのか？　それとも、見逃してくれるのか？」
- **クエスト分岐**：異端の咎で追われる者を前にして → (a) **正規に審問・嘆願の手続きを踏む**＝筋は通るが棄教か処刑の二択を迫られ遅い／(b) **力ずくで逃がす/匿う**＝速いが自らも異端の共犯にされる博打（→ [[罪と罰]]）／(c) **[[汚職とフィクサー|フィクサー]]に異端の記録を揉み消させる**＝高くつくが烙印ごと消える（→ [[旅券と身元]]の漂白）。
