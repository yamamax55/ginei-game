# 教育・人材育成 完成作業票（2026-09-20）

対象: #998 `[人事][HCM-6] 人材育成・教育`

## 確定仕様

- 人物を実績と潜在能力で毎年評価し、9-boxの区分から「師事」「抜擢配置」「現役士官教育」を推薦する。
- 人物の成長は既存の `GrowthRules`、師事は `MentorshipRules`、評価は `PerformanceReviewRules` を使う。
- 艦隊訓練と軍団共同演習は実施中に即応性を下げ、修了後は練度・連携を蓄積する。
- 訓練中の艦隊へ移動命令を出した場合、命令を妨げず訓練と所属軍団の共同演習を中断する。
- 中断中は進行せず即応性ペナルティを解除する。再開後は残り期間から続ける。
- 同じ育成イベントの二重登録・二重修了を防ぎ、台帳をセーブへ保存する。
- 文官は現役士官教育へ誤配属せず、抜擢配置へ切り替える。

## 実装

- `TalentDevelopmentRules`: 評価、推薦、開始、中断、再開、年次修了、実効即応性、重複防止。
- `FactionState.talentDevelopment`: 人物、艦隊、軍団、課程、修了イベントの保存台帳。
- `GalaxyView.TalentDevelopment`: 人物名簿・艦隊移動・年次処理との接続。
- `TalentDevelopmentPanel`: 成長曲線、累計投資、候補者、艦隊訓練、軍団共同演習、課程の中断・再開を操作。
- 教育オブザーバに「人材育成・艦隊訓練を開く」を追加。
