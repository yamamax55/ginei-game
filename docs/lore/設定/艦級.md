# 艦級（かんきゅう）

> 艦隊を構成する船の格と役どころ。旗艦を頂点に、楯となる配下艦が群れを成す。

## 艦の格（部隊の中での役）
- **旗艦**――提督が[[遠隔座乗|遠隔に]]座乗する部隊の中核。固い本体＋名のある艦名（[[旗艦|世界遺産名]]）。失っても提督は遠隔ゆえ無事だが、部隊は敗走の解決へ。
- **主力艦・巡航艦**――会戦の火力の主体。配下艦として旗艦を囲み、[[陣形]]を組む。
- **駆逐艦・砲艦**――軽快な打撃・スクリーン。旗艦を守る楯（殿＝[[旗幟|捨てがまり]]を務めるのもこの層）。

## 役割（戦闘／非戦闘）
戦う艦ばかりではない。役割で艦の振る舞いが変わる：**戦闘艦**（撃ち合う）／**偵察艦**（索敵・逃げ足）／**輸送艦**（補給・通商）／**入植艦**（植民）。非戦闘艦は発砲せず交戦を避け、勝敗カウント外だが**撃沈はされうる**（護衛と通商破壊が成立する）。

## 各勢力の艦づくり
| 勢力 | 設計思想 |
|---|---|
| [[碧晶公国]] | 重厚・装甲厚く崩れぬ正面決戦型（→ [[陣形|方陣・円陣]]） |
| [[黎明評議会]] | 軽快・連携火力。寡兵を捌く包囲型（→ [[陣形|鶴翼陣]]） |
| [[鉄環兵団]] | 攻撃特化・速攻。守りを削っても火力を積む |
| [[自由港同位体]] | 武装商船・私掠艦。交易船に牙を仕込む |
| [[灯心自由市ファロス]] | 防御・要塞砲。武を最小に、灯台と信用で守る |

## ゲームデータ参照
