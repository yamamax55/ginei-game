# ヴィルヘルミーネ・モルゲンシュテルン

> 「夜の太政官」――峻烈な改革者。碧晶公国太政官に在って、内政・統括を司る。

## 概要
[[碧晶公国]]の[[官僚|文官]]。31歳。**太政官**（内政・統括）に属し、官職は**太政官卿**、位階は**従四位上**。文才（運営・情報）を本領とし、旧連合貴族の世襲公領。古い官制と門閥の格式が政務を律するなかで実務の屋台骨を担う。

## 容姿
背筋の伸びた長身、簡素だが上質な正装。碧晶公国の文官正装に従四位上の位色をまとう。31歳。

## 来歴
- 碧晶公国の市井に生まれ、大学を次席で卒え若くして碧晶公国太政官に抜擢された。
- 考課を重ねて従四位上に叙され、現在は太政官卿として内政・統括にあたる。

## 性格・信条
- 野心的で出世に貪欲だが、仕事の精度は高い。
- 信条は**門閥主義**。碧晶公国の理念「正統なる権威による統一の再建」との距離が、時に去就を左右する。

## 関係
- 所属：[[碧晶公国]]
- 配属：碧晶公国太政官（内政・統括）
