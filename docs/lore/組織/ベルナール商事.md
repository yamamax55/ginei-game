# ベルナール商事

> [[灯心自由市ファロス]]の総合商社・交易。大商人[[エドゥアール・ベルナール]]が率いる。

## 概要
[[灯心自由市ファロス]]を本拠とする**総合商社・交易**。大商人の[[エドゥアール・ベルナール]]が興した商会で、財力は**新興**と目される。交易と相場で身代を回し、灯心自由市ファロスの経済を裏から支える。

## 事業・経営
- 主力＝総合商社・交易。財産は**貯金**で運用。利潤は法人税ぶん国庫へ（私有企業）。

## 関係
