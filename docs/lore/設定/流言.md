# 流言（りゅうげん）＝噂と情報の市場

> 「真実？　ここじゃ高くつくぜ。出回ってる噂のほうがずっと安くて、ずっと役に立つ。」

## 核心（公の情報が崩れ、噂が真実を上書きする世界）
[[灯台|首座灯]]の沈黙で銀河規模の通信網が砕けた（→ [[環暦|大解体]]）。勢力をまたぐ確かな報せは届かず、各地の[[正史と稗史|正史]]は手前勝手に書かれる。残された情報源は――港で交わされる**噂**、商人の運ぶ**風聞**、水先案内人の**口伝**。真偽の保証なきこれらが、公の情報の空白を埋め、しばしば事実を上書きする。「事実がどうか」より「**何が信じられているか**」が人を動かす世界――それが流言の支配する辺境である。

## 噂が走る経路（誰が運ぶか）
- **港と酒場**――交易民・船乗りの集まる結節点。最も速く最も雑多な噂の集散地（→ [[自由港同位体]]・[[灯心自由市ファロス]]・[[遊興]]の賭場）。
- **[[商人]]・[[商社]]の網**――商機は情報。与信と人脈に乗って勢力を越え、最も精度の高い風聞が流れる（カネで買える）。
- **[[水先案内人]]**――回廊の潮目と一緒に、どの星系が荒れているかの噂を運ぶ。
- **[[諜報機関]]**――噂を**作る側**。流言は武器であり、偽情報で敵を惑わし、世論を傾ける（→ [[正史と稗史]]の宣伝戦）。

## 流言の二面（武器であり罠であり）
- **攻め**：偽の敗報・偽の寝返り話を流して敵の[[士気]]を挫き、[[旗幟|忠誠]]を揺らす。勝ってもいない会戦を「大勝」と触れ回り[[民心]]を釣る。
- **守り/罠**：信じた噂が[[諜報機関|敵の撒き餌]]なら破滅。「あの星系は手薄」の噂を信じて進軍し、待ち伏せに沈む。フィクサーの「確かな筋」も、出所次第では毒。
- **真偽の値段**：裏を取る（[[諜報機関|情報網]]・[[汚職とフィクサー|フィクサー]]の確かな筋）にはカネと時間が要る。安い噂を鵜呑みにするか、高い真実を買うか――常にこの天秤。

## 勢力ごとの噂の扱い
- [[碧晶公国]]――宮廷の風説は家門政治の刃。流言で政敵の[[名誉と面子|面子]]を潰し、失脚させる（宮廷語の慇懃な悪口＝最も洗練された流言）。
- [[黎明評議会]]――公開と検証を尊ぶが、選挙のたび流言飛語が荒れる（→ [[政体]]の民主の弱点）。
- [[鉄環兵団]]――噂より戦果。だが「あの将軍は弱い」の風聞は軍閥の序列を直撃する。
- [[自由港同位体]]――噂こそ商品。真偽を選り分けて売るのが商人の腕（→ [[商社]]の情報与信）。

## NPC・クエストへの適用指針
- **情報屋NPC**（噂を売る）――「タダの噂と、裏の取れた話は別物さ。前者は酒の肴、後者は……あんたの財布次第だ。」
- **流言に踊るNPC**――「聞いたか、第三艦隊が寝返ったって！　……え、ガセ？　いや、皆そう言ってる。」
- **クエスト分岐**：重要な噂を掴んだ場面で → (a) **鵜呑みにして即行動**＝速いが罠かもしれぬ博打／(b) **裏を取る**（情報網・フィクサーにカネと時間）＝確実だが好機を逃すことも／(c) **逆に噂を流す**＝偽情報で敵を動かす攻めの一手（露見すれば[[名誉と面子|信用]]失墜）。

## ゲームデータ参照
- 噂・秘匿情報は隠し特性 `HiddenTraitRules`（脱税／密貿易／内通の秘匿＝観測側の[[諜報機関|情報力]]で露見）＋開示台帳（`DisclosureRules`/`DisclosureLedger`＝何が公になったか）。通知の流れは `NotificationCenter`（カテゴリ＝政治/外交/人事）。流言の影響先は[[士気]]（`FleetMorale`）・[[旗幟]]（`loyalty`/`intrigue`）・[[民心]]（`GovernanceRules`）。確度はフィクサー＝[[商人]]（`TradingHouse`の与信）と[[諜報機関]]の情報網に依存。
