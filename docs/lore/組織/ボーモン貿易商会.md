# ボーモン貿易商会

> [[灯心自由市ファロス]]の総合商社・交易。商人[[ヴァンサン・ボーモン]]が率いる。

## 概要
[[灯心自由市ファロス]]を本拠とする**総合商社・交易**。商人の[[ヴァンサン・ボーモン]]が興した商会で、財力は**富裕**と目される。交易と相場で身代を回し、灯心自由市ファロスの経済を裏から支える。

## 事業・経営
- 主力＝総合商社・交易。財産は**浪費**で運用。利潤は法人税ぶん国庫へ（私有企業）。
