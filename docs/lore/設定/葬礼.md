# 葬礼（そうれい）＝死生観と弔いの作法

> 「人をどう送るかで、その国が何を尊んでいるかが分かる。死は、生き方の鏡だ。」

## 核心（死の作法は、その勢力の価値観の鏡）
[[環暦|大解体]]は無数の死を生み、各勢力は混沌の中で**死者の送り方**を定めていった。死生観は[[信仰]]と一体で、葬礼は単なる儀礼でなく**何を尊び、何に殉じるか**の宣言である。提督の死をどう悼むかは[[士気]]と[[民心]]に直結し、英雄の壮麗な国葬は士気を鼓舞し、無名兵の即物的な処理は厭戦を募らせる。死は、生き方の鏡として政治に作用する。

## 勢力ごとの死生観（送り方の差）
- [[碧晶公国]]――[[信仰|灯統教会]]の荘厳な葬列。門閥は世襲墓所に葬られ、家名と共に**血統の連続性**を讃える。位階に応じた格式（宮廷語の弔辞＝最高の礼）。平民の死は簡素に処され、ここでも[[身分]]の壁が貫く（→ [[言語]]）。
- [[黎明評議会]]――[[信仰|黎明福音派]]の簡素で平等な喪。植民星の技師も元貴族も同じ弔いを受け、**功と人柄**を市民が語り継ぐ（→ [[黎明評議会連邦憲章|法の前の平等]]）。墓碑は等しい大きさ。
- [[鉄環兵団]]――戦死者は即物的に扱うが、**武勲だけは語り継ぐ**。葬礼より「次の戦」。だが伝説的な将の死は軍歌になり、序列の神話を支える（→ [[軍歌]]・[[階級]]）。
- [[自由港同位体]]――[[信仰|環理の道]]の観想的な送り。万物は環のように巡るとし、死を流転の一過程と見て執着しない（→ [[食]]の質素な供養）。
- [[灯心自由市ファロス]]――市民葬。灯を掲げて送り、故人の生業の道具を共に納める実務的な弔い。

## 死をめぐる作法（物語の動力）
- **殉節と殉死**：滅びゆく主君に殉じる[[旗幟|殉節]]、敗走の殿で主を逃がして散る[[捕虜と亡命|捨てがまり]]――美しい死は[[語録]]に刻まれ、後世の忠誠の規範になる（→ [[旗幟]]）。
- **弔い合戦**：英雄の死は復讐の大義になる。「○○提督の弔い合戦」は[[士気]]を跳ね上げ、[[戦争]]の名分にもなる。
- **死の政治利用**：英雄を壮麗に葬って[[民心]]を釣る、政敵の死を「天罰」と[[流言|触れ回る]]――死すら[[正史と稗史|歴史記述]]の係争地になる。
- **喪の祝祭**：[[祝祭|喪の日]]は大解体の死者を悼む全勢力共通の記念日。だが何を悼むかは勢力で食い違う。

## NPC・クエストへの適用指針
- **門閥NPC**（格式の死生観）――「公の御葬は灯統の大司教が執り行う。位階なき者が同じ墓所に？　……あり得ぬことだ。」
- **叩き上げNPC**（武勲の死生観）――「墓なんざ要らねえ。おれの名が軍歌に残りゃ、それで十分だ。」
- **クエスト分岐**：敬愛する将/縁者の死に際して → (a) **弔い合戦**＝士気沸騰だが私情で戦線を歪める／(b) **静かに送る**＝心は鎮まるが「腰抜け」と謗られることも／(c) **死を政治利用**＝壮麗な国葬で民心を釣る（露見すれば不敬と[[流言]]の的）。

## ゲームデータ参照
- 死生観そのものに専用機構はない（ナラティブ層）。葬礼の格は[[信仰]]（`ReligionCatalog`/`TheocracyRules`）・[[身分]]（`SocialOriginRules`）に従う。英雄の死／弔いは[[士気]]（`FleetMorale`）・[[民心]]（`GovernanceRules`）へ波及し、殉節・捨てがまりは `SutegamariRules`（[[捕虜と亡命]]）、人物の死は人物動態（`LifecycleRules`／`PersonFate`）。死の政治利用は[[正史と稗史]]（`DisclosureRules`）・[[流言]]へ接続。
