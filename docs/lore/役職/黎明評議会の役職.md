# 黎明評議会の役職体系

> 植民星の民選議会連邦＝**文民統制の民主制**。選挙で選ばれた代表が政を握り、軍は議会の統制下にある。在任は[[黎明評議会#名鑑（所属の人物・組織）|名鑑]]・runtime で変動。

## 元首・統帥
- **評議会議長（連邦元首）**：連邦の長（選出）。在任例 → [[アシュリー・カヴェンディッシュ]]。
- **首班（首相）**：与党党首が就く政府の長（`PartyRules.Premier`）。

## 政府役職（文官・官職）
- **国務委員**：各省を預かる政治任用の閣僚。
- **州総督**：各植民星（[[アコンカグア星系]] ほか）の民選の地方長。
- 文官は議会の統制下で実務を担う（文民統制）。

## 立法・評議
- **連邦議会**：植民星の民選代表による合議。政党＝[[自治連合]]／[[進歩評議派]]／[[連邦統一会]]。選挙＝`ElectionRules`。理想は高く、合議は遅い。

## 軍役職（階級＋指揮職）
- **連邦軍司令**：議会の統制を受ける。寄せ集めの艦隊を連携と土地勘で操る。
- 在任例 → [[ミレイア・セルウィン]]（[[群像劇の構成|中核]]・少尉）／[[アウレリア・ファルケンハイト]]／[[セオ・アシュフォード]]。

## 勢力固有の役職
- **連邦準備評議会議長**（[[連邦ポンド]]の発行）／**監察委員**（公職の弾劾・`ImpeachmentRules`）。
