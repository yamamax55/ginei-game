# ヒルデガルト・フォン・アイゼンブルク（4世）

> 碧晶公国の女大公。正統を背負う者。

## 概要
[[碧晶公国]]の**女大公**。62歳。旧連合貴族の世襲公領の頂点に立ち、統治にあたる。王朝（[[アイゼンブルク家]]）の血を引く。

## 容姿
若く華やかだが芯の強い佇まい。碧晶公国の元首にふさわしい礼装をまとう。62歳。

## 統治・信条
- 理想主義者で、旧弊の打破を志す。
- 信条は**帝政擁護**。国家理念「正統なる権威による統一の再建」を体現する立場にある。徳と正統性が王朝の寿命を左右する（DynastyRules）。

- 王家：アイゼンブルク家
