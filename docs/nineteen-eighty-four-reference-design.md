# オーウェル『1984年』参考設計（EPIC #1638）

> 参照元：ジョージ・オーウェル『Nineteen Eighty-Four』（1949）。全体主義国家が**真実そのものを製造・管理する**構造をSF的リアリズムで描いた20世紀の古典。
> 本ドキュメントは、当プロジェクト（Ginei＝社会/政治/秘密警察/開示の純ロジック層を大量に保有）にとって**役に立つ視点**だけを抽出し、EPIC `#1638` として issue 化する提案。
> 著作権注意：固有名（党名/標語/登場人物/省庁名/地名/造語）・文章・キャラクター・固有設定は一切流用しない。**統治メカニクス／全体主義の構造パターンのみ**を参考にし、汎用語（記録改竄・公式言説・監視・恒久敵）で実装する。

## 0. なぜ「1984年」が本システムに役立つか

当プロジェクトは社会・政治シミュの**大規模な純ロジック層**を保有している：

| 既存（社会/弾圧/開示） | カバー範囲 |
|---|---|
| `SecurityRules`/`SecurityApparatus`(#166) | 秘密警察・弾圧・クーデター探知・デセント抑圧 |
| `DisclosureLedger`/`DisclosureRules`(FND-4) | 秘史を「開示する」方向の真実管理 |
| `HopeRules`/`Community`(#852) | 希望・末人・信仰ルート・秩序ルートの安定策 |
| `GovernanceRules`/`Province`(#109) | 内政・安定度・反乱圧力 |
| `ConsentRules`/`Polity`(#836) | 支配への合意・非協力波及 |
| `WarGoalRules`/`DiplomacyState`(#192) | 戦争目標・厭戦 |
| `CultureRules`/`Culture`(#194) | 文化同化・ナショナリズム |
| フーコー#1506 | パノプティコンの理論基盤（見られている意識） |
| ハクスリー#2293 | ソフト全体主義（快楽型・1984の対照軸） |
| 動物農場#2219 | スローガンの書き換え（建国理念ドリフト） |
| ディック#2334 | 偽史プロパガンダ・if歴史の真偽 |

**しかし、これらは「真実は1つで弾圧・開示・合意で扱う」という前提を共有**しており、1984年が固有に描く以下の軸が**欠けている**：

| 1984年が固有に持つ視点 | 当プロジェクトでの欠落 |
|---|---|
| **公式言説の動的製造**（記録省） | `DisclosureLedger` は秘史を「明かす」方向。記録を**上書きして封じる**逆向きのエンジンが無い |
| **真実乖離度の蓄積→突発崩壊** | 改竄は短期安定だが乖離蓄積で突発崩壊する。`ExtractiveDecay`(QIN-5)の認知版が無い |
| **二重思考（認知ギャップ）** | 公式像と実体の分離が潜在不満となり閾値で反乱顕在化。`GovernanceRules`は均衡前提 |
| **監視の萎縮効果（事前抑制）** | `SecurityRules`#166 は弾圧（事後）。**見られているかもしれないだけで行動が変わる**前段が無い |
| **恒久敵による統制** | `WarGoalRules`は戦争目標（終結を目指す）。**意図的に勝たない戦争で結束を演出**するメカニクスが無い |

**結論**：1984年は既存の弾圧・開示・希望系に、**「真実を製造する」という逆向きの軸**と単一のマクロ軸「真実乖離度」を与える。`DisclosureLedger`（秘史開示）↔`NarrativeControlRules`（公式言説改竄）が対をなすことで、統治の「明かす×封じる」の両翼が揃う。

## 1. 役に立つ視点（要約）

1984年の世界観を、**本システムに効く形**で1行ずつ：

1. **「真実は製造できる」**。国家が記録を上書きすれば「公式の過去」が変わる。→ `DisclosureLedger`の逆向き：**秘史を封じる**エンジンが必要。`NarrativeControlRules`/`OfficialNarrative` で実装。
2. **真実乖離度は蓄積する**。改竄は短期に安定度・結束を回復するが、乖離が積み上がり開示や敗北で突発崩壊する。→ `ExtractiveDecay`(QIN-5 法家の罠)の**認知版**。短期最強・長期崩壊の二面性。
3. **認知ギャップは沈黙の不満を生む**。公式像と実体が乖離しても弾圧で表に出ない＝潜在不満。閾値超過・開示イベントで一気に顕在化（`GovernanceRules.RebelPressure` へ合流）。→ `DoublethinkRules` が橋渡し。
4. **萎縮は弾圧より安上がり**。「見られているかもしれない」だけで反対が表面化前に消える。弾圧(`SecurityRules`)の上流に置く事前抑制レイヤー。協力（`ConsentRules`）を蝕み、長期で正統性を下げる代償を持つ。
5. **「勝てない敵」が結束を生む**。終わらない戦争は厭戦ではなく求心力の源泉になる（外敵が必要な政体）。`WarGoalRules` の逆用＝敵の永続化という高位決断。
6. **改竄の極大化はディストピアのlore**。秘史開示が完全に封じられた世界＝`DisclosureLedger`がゼロ進捗のエンドステート。啓蒙・解放エンディングの暗い鏡。

## 2. 取り入れるべきメカニクス（優先度つき・既存への接続）

> 大原則：**`SecurityRules`#166・`DisclosureRules`FND-4・`HopeRules`#852・`GovernanceRules`#109・`WarGoalRules`#192 を作り直さない**。1984年はそれらに**欠落軸を足し、接続する**だけ（additive）。

### ★★★ 最優先（最も固有で欠落の大きい signature）

#### NTEF-1 歴史改竄エンジン（公式言説 `OfficialNarrative`・真実乖離度の蓄積）
- **公式言説モデル**：`CampaignState`/`FactionState` に「公式に流布する歴史・状態像」を持たせる。実体（戦績・経済・占領史）との**真実乖離度 (0..1)** を保持。
- **高位決断「記録上書き」**：短期に安定度・結束を回復するが真実乖離が蓄積、閾値で突発崩壊（`ExtractiveDecay`の認知版）。
- 接続：新 `NarrativeControlRules`/`OfficialNarrative`（純ロジック・test-first）。`DisclosureRules`(FND-4) の**鏡像**（開示↔隠蔽の対）。

#### NTEF-2 二重思考と認知ギャップ（公式像 vs 実体の分離・潜在不満→閾値で反乱顕在化）
- 改竄が続くほど住民の「公式に信じる像」と「実体」が乖離。弾圧で表に出ないだけで**潜在不満**は蓄積。
- 閾値超過・開示イベントで二重思考が崩れ **`GovernanceRules.RebelPressure`** へ一気に流れ込む。
- 言語貧困化・統制階層は修正子として内包（独立システム化しない）。
- 接続：新 `DoublethinkRules`（純ロジック・test-first）× NTEF-1 × `HopeRules`(#852)。

### ★★ 高（既存ルールへの追加レイヤー）

#### NTEF-3 監視の萎縮効果（弾圧の前段＝表面化前に沈黙・協力低下の代償）
- `SecurityRules.DissentSuppression`（事後弾圧）の上流に**事前萎縮レイヤー**。監視密度が高いほど反対が表面化前に消える。
- 支持でなく**沈黙**を生む。不満は消えず潜在化（NTEF-2 認知ギャップへ）。長期で協力 `ConsentRules` を蝕み正統性を下げる代償。
- 接続：`SecurityRules`/`SecurityApparatus`(#166) に萎縮レイヤーを**追加**（重複新設せず既存へメソッド/修正子を足す）。

#### NTEF-4 恒久敵による統制（勝てない外敵を演出・結束底上げ・厭戦と露見の反動）
- 意図的に終結させない戦争による求心力の演出。`WarGoalRules` の逆用（勝つのでなく「敵が必要」な政体）。
- 代償：厭戦が閾値を超えると統制崩壊、「敵は演出だった」露見で正統性が一気に崩れる。
- 接続：`WarGoalRules`/`DiplomacyState`(#192) × NTEF-1（改竄で戦況を歪める）× `GovernanceRules`（安定度への反動）。

### ★ 中（世界観lore）

#### NTEF-5 （lore）真実の終焉＝啓蒙の暗い鏡（改竄極大で開示不能のディストピア系譜）
- 真実乖離度が最大化し `DisclosureLedger` が進捗ゼロとなるエンドステート。啓蒙・解放エンディングの逆。
- 接続：コード新設せず `DisclosureLedger`(FND-4) への**lore データ入力**（`DisclosureEntry` として世界観的終端を定義）。

### ❌ 不採用（重複・既存で十分・タイクン化）

| 不採用 | 理由 |
|---|---|
| 反対派の弾圧・逮捕・処刑そのもの | **`SecurityRules`#166・`CaptivityRules`#154 がカバー** |
| 秘密警察組織・クーデター探知 | **`SecurityRules`/`SecurityApparatus`#166 がカバー** |
| 末人・無気力な被支配者 | **`HopeRules`/`Community`#852 がカバー** |
| 思想の同化・ナショナリズム | **`CultureRules`#194 がカバー** |
| プロパガンダの個別演出（ポスター/放送のミクロ操作） | タイクン化（マイクロ操作）回避 |
| 言語改造の独立システム化 | `DoublethinkRules` の修正子として内包（独立EPIC化しない） |
| 内部党・外部党・大衆の階層レジストリ化 | `DoublethinkRules` 内包。階層レジストリは重複新設 |
