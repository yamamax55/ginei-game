# 親征（しんせい）

> なぜプレイヤーはこの会戦を直接指揮できるのか。盤上に降りるには、降りるだけの**正統性**が要る。

## 戦術指揮の資格
戦略の指示は遠隔から常時下せるが、**会戦の直接指揮**は、その勢力のトップが自ら戦場に臨む――すなわち**親征**したときに開かれる。指導者の臨席が、盤上に降りて采配を振るう資格を与える。誰もが常に全戦線を微管理できるわけではない。

## 服従の質
臨席して指揮しても、艦隊が完全に従うとは限らない。命令の通りやすさ＝**服従の質**は、指揮の正統性で決まる。君主が統帥権者として臨めば兵はよく従い（[[碧晶公国]]）、軍閥の領袖が直率すれば従い（[[鉄環兵団]]）、だが民主政で文民の元首が前線を微管理すれば、本来委任すべき指揮への介入として反発を招く（[[黎明評議会]]・→ [[黎明評議会連邦憲章#第四章　軍と文民統制]]）。正統性を欠く命令は、反応の遅れ・部分的不服従・不達となって現れる。

## 政体が決める指揮
| 政体 | 指揮の根拠 | 直接指揮の正統性 |
|---|---|---|
| 君主統帥（[[碧晶公国]]） | 統帥権者が臨席 | 高 |
| 文民統制（[[黎明評議会]]） | 元首は本来委任 | 低（微管理は反発） |
| 軍部優位（[[鉄環兵団]]） | 領袖が直率 | 高 |
