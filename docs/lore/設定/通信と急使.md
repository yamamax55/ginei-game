# 通信と急使（つうしん・きゅうし）＝報せはいかに運ばれるか

> 「光より速い報せはない。だが灯台が死んだいま、いちばん速い報せは、いちばん腕のいい船乗りの胸の中にある。」

## 核心（灯台亡き世界では、情報そのものが遅い）
旧[[大環状連合]]は[[灯台]]網で銀河規模の即時通信を保っていた。その沈黙（→ [[環暦|大解体]]）で、いまや報せは**人と船が物理的に運ぶ**しかない。命令も戦況も[[回廊]]を渡る早船の速さに縛られ、遠い前線ほど古い情報で戦うことになる。**通信の遅延こそが、この時代の戦略の根本制約**である。速く正確な報せを得る者が先手を取り、偽の報せ（→ [[流言]]）に踊る者が各個撃破される。

## 報せの運び手（速さと確かさ）
- **急使・早船**――最重要の命令を運ぶ専任の使者。[[水先案内人]]の腕が速度を決め、待ち伏せ・[[通商破壊|拿捕]]で報せごと消える危うさも。
- **狼煙・灯火信号**――星系内の近距離通信。[[要塞]]や関の間で符牒を交わす。傍受・偽装のリスク。
- **商人の便り**――[[商社]]の交易網に相乗りする私信。速くないが広く届く（→ [[流言]]の風聞と同じ経路）。
- **暗号と符牒**――重要な報せは暗号化。[[諜報機関]]が解読を競い、鍵の漏洩が会戦を決める。

## 通信の遅延が生む物語
- **時間差の悲劇**――講和が成ったのを知らずに戦い続ける前線、とうに陥ちた城へ送られる援軍。古い命令が悲劇を生む。
- **報せの遮断**――敵の急使を討てば命令系統を断てる（→ [[通商破壊]]）。[[兵站|補給線]]同様、通信線も攻防の的。
- **独断専行の余地**――報せが届かぬ前線では、将の独断が勝敗を分ける。[[親征|トップの臨席]]が無い限り、現場指揮官の裁量が大きい（→ [[階級]]）。

## 勢力ごとの通信
- [[碧晶公国]]――格式ある急使制度と狼煙網。だが宮廷の体面で報告が歪み、敗報が遅れる（→ [[報道と宣伝]]）。
- [[黎明評議会]]――公開と速報を尊ぶが、合議制ゆえ命令の発出そのものが遅い（→ [[政体]]の民主の弱点）。
- [[鉄環兵団]]――軍用急使網が最速。命令一下の速さが軍閥の強み（→ [[階級]]）。
- [[自由港同位体]]――交易網＝通信網。最も広く速い私的情報網を握り、情報を売る（→ [[商社]]・[[流言]]）。
- [[灯心自由市ファロス]]――灯火信号の本場。灯を扱う都市として近距離通信に長ける。

## NPC・クエストへの適用指針
- **急使NPC**（命懸けの運び手）――「この報せが半日遅れりゃ、前線の三千が無駄死にする。回廊が荒れてようが、行くしかねえ。」
- **古い報せに踊る将NPC**――「敵は退いたと聞いた。追撃だ！　……は？　それは十日前の話？」
- **クエスト分岐**：急報を届ける/奪う場面で → (a) **最速の危険な回廊を行く**＝速いが[[通商破壊|拿捕]]・遭難の博打／(b) **安全な迂回路**＝確実だが間に合わぬことも／(c) **[[商社]]・[[汚職とフィクサー|フィクサー]]の私的網を買う**＝高くつくが速くて目立たない。

## ゲームデータ参照
- 通信遅延そのものに専用機構はない（ナラティブ層・戦略の前提）。報せの運搬は[[回廊]]（`GalaxyPathfinder`＝経路）・[[水先案内人]]、遮断は[[通商破壊]]（`CommerceRaidingRules`）・[[兵站]]（補給線途絶）。情報の確度は[[諜報機関]]（情報網）・[[流言]]（`HiddenTraitRules`／`DisclosureLedger`）、通知は `NotificationCenter`。独断の余地は[[階級]]（指揮）・[[親征]]。
