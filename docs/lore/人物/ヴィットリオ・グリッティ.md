# ヴィットリオ・グリッティ

> 「賢相」――条文の鬼。自由港同位体式部省に在って、人事・選叙を司る。

## 概要
[[自由港同位体]]の[[官僚|文官]]。37歳。**式部省**（人事・選叙）に属し、官職は**式部卿**、位階は**正四位下**。文才（運営・情報）を本領とし、商業ギルド連合。帳簿と算盤が物を言う実務本位の官房なかで実務の屋台骨を担う。

## 容姿
長身痩躯で物腰は柔らかいが眼光は鋭い。自由港同位体の文官正装に正四位下の位色をまとう。37歳。

## 来歴
- 自由港同位体の市井に生まれ、地方の書記から叩き上げ自由港同位体式部省に配され頭角を現した。
- 考課を重ねて正四位下に叙され、現在は式部卿として人事・選叙にあたる。

## 性格・信条
- 改革志向で硬直した官制に苛立ち、新制度を持ち込もうとする。
- 信条は**中道**。自由港同位体の理念「交易の自由・武装中立」との距離が、時に去就を左右する。
