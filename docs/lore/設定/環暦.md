# 環暦（Concord Era / CE）

> [[大環状連合]]崩壊（[[灯台|首座灯]]停止）を起点とする共通暦。

## 概要
連合崩壊を起点とする「環暦（CE）」を全勢力が共用する。起点＝**環暦元年（CE1）**＝[[灯台|首座灯]]が停止した年。

## 統一と分裂の象徴
諸侯は各自の私年号を併記し、これが**統一と分裂の象徴**となる（共通暦を使う＝かつて一つだった名残／私年号を併記する＝今は割拠している証）。

## 主な節目
- **CE1** … 首座灯が停止、各地の灯台が連鎖沈黙（[[序章 ― 灯の消えた銀河]]）
- **CE1〜10** … 「大解体」。生き延びることがすべての混沌の十年
- **CE10ごろ** … 諸侯の割拠が定着（[[第一章 ― 諸侯の時代]]）

## ゲーム実装
統一ゲームクロック／二重暦に対応（`GameClock` / `GameDate`）。
