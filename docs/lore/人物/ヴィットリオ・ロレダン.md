# ヴィットリオ・ロレダン

> 数字に強い能吏。自由港同位体太政官に在って、内政・統括を司る。

## 概要
[[自由港同位体]]の[[官僚|文官]]。40歳。**太政官**（内政・統括）に属し、官職は**宰相府少丞**、位階は**正六位下**。文才（運営・情報）を本領とし、商業ギルド連合。帳簿と算盤が物を言う実務本位の官房なかで実務の屋台骨を担う。

## 容姿
小柄ながら声に重みがあり、人を動かす。自由港同位体の文官正装に正六位下の位色をまとう。40歳。

## 来歴
- 自由港同位体の市井に生まれ、名門の家塾に学んだのち下級官から累進して自由港同位体太政官に入った。
- 考課を重ねて正六位下に叙され、現在は宰相府少丞として内政・統括にあたる。

## 性格・信条
- 数字と前例に忠実な実務家。情よりも帳尻を重んじる。
- 信条は**共和主義**。自由港同位体の理念「交易の自由・武装中立」との距離が、時に去就を左右する。
