# グスタフ・フォン・モルゲンシュテルン

> 「能吏」――清廉の士。碧晶公国太政官に在って、内政・統括を司る。

## 概要
[[碧晶公国]]の[[官僚|文官]]。35歳。**太政官**（内政・統括）に属し、官職は**エベレスト総督**、位階は**従五位上**。文才（運営・情報）を本領とし、旧連合貴族の世襲公領。古い官制と門閥の格式が政務を律するなかで実務の屋台骨を担う。

## 容姿
細身で姿勢正しく、感情を表に出さない。碧晶公国の文官正装に従五位上の位色をまとう。35歳。

## 来歴
- 碧晶公国の門閥に連なる家に生まれ、地方の書記から叩き上げ下級官から累進して碧晶公国太政官に入った。
- 考課を重ねて従五位上に叙され、現在はエベレスト総督として内政・統括にあたる。

## 性格・信条
- 慎重で口数少なく、機を見て確実に動く。
- 信条は**中道**。碧晶公国の理念「正統なる権威による統一の再建」との距離が、時に去就を左右する。
