# ID一覧（識別子の採番台帳）

> 『[[星骸の諸侯]]』の lore エンティティに振る**一意の識別子**を一元管理する。
> 新規ノートを作るときは、種別ごとの次番を**ここで採番してから**ノートの `id` に記す（重複防止）。

## 採番ルール
- 形式：**`PREFIX-NNN`**（プレフィックス＋3桁ゼロ詰め連番。`001` から）。
- 一意・不変・再利用しない（撃沈・解散・故人になっても**欠番のまま**＝過去参照が壊れない）。
- ノートの frontmatter `id:` に記す。種別はプレフィックスで一目で分かる。
- **ゲームデータの数値ID（`StarSystem.id`／`Person.id` 等）とは別物**＝lore 内の安定識別子。ゲーム側は手続き生成で別に採番されるため、突き合わせは名前/このIDで行い、二重管理しない。
