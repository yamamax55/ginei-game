# 終章 ―― 鍵の行方

幾多の会戦と謀略の果てに、主人公はついに、失われた[[灯台|首座灯]]の制御鍵にたどり着く。

鍵を握る者は、死に絶えた[[回廊|回廊網]]の全体をもう一度読み直し、銀河を再び一つに束ねうる。すべての航路を意のままに開閉できる力。それは、武力で奪える千の[[回廊|要衝]]にも勝る力だ。だが、その力をどう使うかは、なお定まっていない。

かつての[[大環状連合|連合]]のように、ただひとつの強き中心が万民を束ねる、統一の銀河へと向かうのか。あるいは、二度と一極に権力が集まらぬよう、諸侯が対等に並び立ち、互いを牽制し合う分権の秩序を、新たに編み上げるのか。さもなくば、人を災いへと誘うその鍵そのものを永遠に葬り去り、銀河を緩やかな分裂のまま、自由に漂わせておくのか。

どの道を選んでも、すべての諸侯が満足することはない。統一を布けば、自由を奪われた者が新たな叛旗を掲げるだろう。分権を編めば、隙を突いて再び覇を唱える者が現れるだろう。鍵を葬れば、いつか別の誰かが新たな灯台を見つけ、同じ争いが繰り返されるだろう。完全な結末などどこにもない。あるのは、銀河の次の千年に、どの理想の種を蒔くかという選択だけだ。

辺境の名もなき一艦隊から始まった旅は、こうして銀河そのものの行く末を決める一手へと至る。消えた灯を、もう一度灯すのは誰か。そして、その灯のもとに、どんな銀河を描き出すのか。――それは、最後まで生き残った旗が、すなわちプレイヤー自身の選択が決める。
