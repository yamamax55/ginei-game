# 列伝 ―― 港の盾と目

> 視点：[[アマーリア・ヴァレンティ]]（港湾防衛司令）と[[セリーヌ・マルロー]]（情報）。中核の幹との交点＝ミレイアに足場（港）を貸す。

この港は、誰の船も等しく迎える。だからこそ、誰にも渡さない。[[灯心自由市ファロス|自由市ファロス]]の港湾防衛司令[[アマーリア・ヴァレンティ|アマーリア・ヴァレンティ]]は、難民にも商人にも分け隔てなく[[灯台|灯]]を掲げる。生きた灯台を抱く一星系を要塞化し、回廊の細い出口で少数精鋭の機動迎撃を指揮する守りの名手だ。傍らには、四囲の均衡を読み切る目と耳――右腕の偵察・諜報士官[[セリーヌ・マルロー|セリーヌ・マルロー]]。「戦わずに勝てる場所を、先に見つけておく」のが彼女の流儀だった。

ある日、その港に、寄る辺ない一艦隊が身を寄せた。いずれの諸侯にも属さず、傭兵まがいの戦で禄を食む、[[ミレイア・セルウィン|ミレイア・セルウィン]]の名もなき旗。セリーヌは静かに報せる――「あの娘の采配、ただの傭兵ではありません。回廊を読む眼が、桁違いです」。アマーリアは港を見渡し、温かく笑った。「なら、なおさら迎えましょう。この港は、才ある者を拒みません」。

中立を貫く港が、強大な諸侯に呑まれぬのは、武だけでは足りない。アマーリアの盾とセリーヌの目が、寄る辺ない者たちに足場を与え、四囲の大義を天秤にかけて独立を保つ。ミレイアの旗が辺境から銀河の中心へ伸びていく、その最初の拠りどころは、月神の名を負う港の、この温かな中立だった。
