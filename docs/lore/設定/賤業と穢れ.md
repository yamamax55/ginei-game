# 賤業と穢れ（せんぎょうとけがれ）＝社会が押しつける見えない烙印

> 「死体を清め、革をなめし、罪人を裁く縄を結ぶ――誰かがやらにゃ世が回らねえ仕事だ。なのに、その手は『穢れてる』と言われる。世間ってのは、勝手なもんさ。」

## 核心（必要な仕事ほど、社会が穢れと烙印を押す）
[[身分]]の層のさらに底、あるいは外側に、社会が「**穢れ**」の烙印を押した**賤業**の人々がいる。死者を扱う者（→ [[葬礼]]）、革をなめす者、[[罪と罰|刑場]]の役を担う者、汚物を処理する者――いずれも世が回るのに不可欠でありながら、[[信仰|宗教]]的な不浄観や[[身分|身分秩序]]によって忌避され、定住・婚姻・[[名門校|学び]]を阻まれる。この差別は[[碧晶公国|身分制の濃い勢力]]ほど厳しく、[[黎明評議会|法の前の平等]]を掲げる勢力はこれを撤廃しようとする――賤業の扱いは、勢力の[[政体|理念]]を最も鋭く試す鏡である。

## 烙印のかたち（何が穢れとされるか）
- **死と血の業**――[[葬礼|葬送]]・解剖・と畜・なめし革。死と血に触れる仕事が不浄視される（→ [[信仰]]の死生観）。
- **罪と罰の役**――[[罪と罰|刑吏]]・牢番・処刑人。社会の暗部を担うがゆえに忌避される。
- **汚穢と再生**――汚物処理・掃除・[[鉱と採掘|坑道]]の最下層。都市の[[都市と港の日常|日常]]を支える見えぬ手。
- **越えられぬ壁**――賤業の家に生まれた子は職を世襲させられ、[[婚姻と家門|婚姻]]も居住も阻まれる。才あっても埋もれる（→ [[孤児と里子]]）。

## 賤業をめぐる物語
- **不可欠ゆえの力**――忌避されつつも、その業を握る者は社会の急所を握る。葬送・処刑・なめし革の独占は隠れた力（→ [[俠気と無頼]]）。
- **壁を越える者**――烙印を負った者が才で身を立てる物語。[[黎明評議会|平等]]の理念がそれを可能にする（→ [[身分]]の壁を越える痛快）。
- **穢れを使う差別**――政敵に「穢れた血」の烙印を着せて失脚させる謀略（→ [[流言]]・[[名誉と面子]]）。
- **言葉の刻印**――賤業を蔑む在来語の呼称と、それを口にせぬ宮廷の建前（→ [[言語]]）。

## 勢力ごとの扱い
- [[碧晶公国]]――穢れ観が制度に組み込まれ、賤業は身分の最底辺に固定される（→ [[身分]]・[[碧晶公国大憲章]]）。
- [[黎明評議会]]――賤業差別を法で撤廃し、万人の平等を掲げる。だが人々の心の偏見はなお残る（→ [[黎明評議会連邦憲章|法の前の平等]]）。
- [[鉄環兵団]]――出自を問わぬ実力主義ゆえ、賤業の出でも功で這い上がれる稀有な道（→ [[階級]]）。
- [[自由港同位体]]――商売に貴賤なしの建前。だが取引相手の出自は密かに値踏みされる（→ [[信用と証文]]）。
- [[灯心自由市ファロス]]――ギルドが賤業を都市機能として組み込み、忌避を実務で和らげる。

## NPC・クエストへの適用指針
- **賤業のNPC**（誇りと諦め）――「俺の仕事がなけりゃ、あんた方の死体は野晒しだ。それでも『穢れてる』と言うんなら……まあ、言わせておくさ。誰かがやらにゃならねえ。」
- **差別する側のNPC**――「あの者を要職に？　……血が穢れておる。家柄を、もう一度お調べになることだ。」（→ [[流言]]の中傷）
- **クエスト分岐**：才ある賤業出身者の登用を巡って → (a) **慣習に従い退ける**＝波風立たぬが有為の才を失う／(b) **抜擢する**＝才を得るが門閥の反発と[[名誉と面子|面子]]の摩擦（→ [[身分]]）／(c) **[[汚職とフィクサー|出自を裏で漂白]]して登用**＝才を活かすが偽装露見の火種。
