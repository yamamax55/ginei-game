# QAメニューのカテゴリー整理
Task: qa-menu-categories-20260910
関連: #2253（検証導線整備）
ユーザー依頼：増えたUnity QAをカテゴリーごとに整理する。

Ginei/QA の下に機能別サブメニューを統一する。候補：戦略マップ、軍団隊形、指揮権限、支援要請、敗走・総退却、入力・表示診断、要塞・回廊。既存のQA（Play中のみ・保存しない）配下も全件棚卸しし、機能に合わせて追加分類。項目を消さず、処理や前提条件は変更しない。
カテゴリー内は準備→操作・条件発生→状態・記録→解除・撤去の順。深すぎる階層は避ける。Play中限定や保存しない注意は適切に残す。MenuItem validationパス、ExecuteMenuItem参照、ダイアログ内案内も追従。過去の検証証跡は書き換えず、新旧パス対応表を docs/ops/qa-menu-guide.md に作成。
本依頼はQAの整理のみ。陣形本体の確定仕様は別タスクで、同時着手しない。進行中のQA検証はPlay OFFで停止済み。既存セーブ/v5/無関係変更を保護。commit/pushなし。
受入条件：全項目の移行漏れ・重複なし、古い直下QA項目が整理される、コンパイル、Play制約の維持、メニュー表示確認。低リスクのメニュー変更なので全件テストの反復は不要。結果を報告し編集停止、claude-status.jsonを本task_idで更新すること。
