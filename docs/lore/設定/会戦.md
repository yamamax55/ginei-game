# 会戦（かいせん）

> 本作の心臓＝リアルタイムの艦隊戦。提督の采配、陣形の駆け引き、寡兵の地の利――盤上で物語が動く瞬間。

## 部隊＝旗艦＋配下艦
会戦の単位は「**旗艦＋配下艦**」の部隊である。提督が[[遠隔座乗|遠隔に]]操る[[旗艦]]を中核に、多数の配下艦が[[陣形]]を組んで囲み、楯となる。攻撃対象は個々の艦艇で、選択・指揮・勝敗カウントは部隊（旗艦）単位。旗艦の艦艇数が尽きれば敗走の解決へ向かう（[[旗幟|捨てがまり]]か撃墜）。提督は根拠地の[[遠隔座乗|感応座]]から艦を指揮するため、**旗艦を撃墜されても提督は死なず前線を退く**（提督の身が真に危ういのは、艦ではなく[[遠隔座乗|根拠地]]を落とされたとき＝撤退/死亡/捕縛）。

## 勝敗を分けるもの
- **[[陣形]]**――攻守機動のトレードオフと相性。
- **[[士気]]・[[練度]]**――数では測れぬ質。
- **提督の能力**――[[提督|攻撃・防御・機動・統率]]が実効値で効く。
- **局所の火力集中**――単純な総数でなく、一定範囲の局所優勢が二乗で効く（ランチェスターの法則）。寡兵が地の利と集中で大軍を破る所以。

## 勝利条件
会戦には目的がある：**殲滅／時間防衛／旗艦撃破／護衛／要塞攻略／要塞防衛**（→ [[要塞]]）。条件次第で最適な戦い方が変わり、殲滅を避けて時を稼ぐ、VIPだけを狙う、といった駆け引きが生まれる。

## 戦略との接続
会戦は[[戦争]]の一場面。観戦せぬ会戦は抽象解決され（同じ game-time を消費）、潜行すれば手動で采配できる。勝敗は版図と[[兵站|補給]]に跳ね返り、戦略を動かす。

## ゲームデータ参照
- 進行は `BattleManager`（全滅・勝利条件判定）、配置は `BattleSetup`＋`ScenarioData`（`VictoryCondition`）。攻撃ロジックは `ShipCombat`（射界・ダメージ・ランチェスター集中 `LanchesterRules`）、部隊は `FleetStrength`（旗艦）＋`EscortShip`（配下艦）。自動解決は `AutoBattleSim`。
