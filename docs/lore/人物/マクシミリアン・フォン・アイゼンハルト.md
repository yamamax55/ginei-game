# マクシミリアン・フォン・アイゼンハルト

> 「算盤侍」――清廉の士。碧晶公国太政官に在って、内政・統括を司る。

## 概要
[[碧晶公国]]の[[官僚|文官]]。32歳。**太政官**（内政・統括）に属し、官職は**宰相府大丞**、位階は**正六位上**。文才（運営・情報）を本領とし、旧連合貴族の世襲公領。古い官制と門閥の格式が政務を律するなかで実務の屋台骨を担う。

## 容姿
白髪まじりの実直な風貌、書類の束を手放さない。碧晶公国の文官正装に正六位上の位色をまとう。32歳。

## 来歴
- 碧晶公国の門閥に連なる家に生まれ、大学を上位で卒え碧晶公国太政官に配され頭角を現した。
- 考課を重ねて正六位上に叙され、現在は宰相府大丞として内政・統括にあたる。

## 性格・信条
- 事なかれを嫌い、必要とあれば上官にも諫言する。
- 信条は**門閥主義**。碧晶公国の理念「正統なる権威による統一の再建」との距離が、時に去就を左右する。

## 関係
- 所属：[[碧晶公国]]
- 配属：碧晶公国太政官（内政・統括）
