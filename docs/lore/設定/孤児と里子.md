# 孤児と里子（こじとさとご）＝戦が遺した子らの行方

> 「戦のたびに、親を失くした子が湧く。そいつらをどう育てるかで、二十年後の国が決まるんだ。誰も、そこまで見ちゃいねえがな。」

## 核心（戦が絶えず孤児を生み、その育ちが次代を作る）
[[戦争]]と[[難民と漂流民|大解体の流亡]]は、絶えず**親を失った子ら**を生む。孤児をどう育てるか――見捨てて[[遊興|底辺]]へ沈めるか、[[植民|入植]]や[[工房と職人|徒弟]]へ繋ぐか、養子・里子として家門に迎えるか――は、その勢力の[[民心|懐の深さ]]と、二十年後の人材の質を静かに決める。孤児院、里親、養子縁組は[[人口]]と[[名門校|人材]]の隠れた供給源であり、英雄の出自にも、無頼の温床にもなる。

## 子らの行方（誰が育てるか）
- **孤児院と慈善**――[[信仰|教会]]・都市・篤志家が孤児を養う。教育まで届けば人材、放置すれば[[遊興|無頼]]の予備軍（→ [[俠気と無頼]]）。
- **里子と養子**――子なき家門が養子を迎え継承に充てる（→ [[世代と継承]]・[[婚姻と家門]]）。身分を越える稀な上昇の道。
- **徒弟と年季**――孤児を[[工房と職人|工房]]や軍に入れ、技と糧を与える（→ [[学びと識字]]・[[労働]]）。無給労働の温床にも。
- **拾われた英雄**――名もなき孤児が才を見出され将や宰相に。群像劇の定番の出自（→ [[身分]]の壁を越える物語・[[名と諱]]）。

## 勢力ごとの育ち
- [[碧晶公国]]――孤児は身分の底。教会の孤児院が細々と養うが、上昇の道は狭い。稀に養子で門閥に入る（→ [[身分]]）。
- [[黎明評議会]]――公の養育と教育を理念とし、戦災孤児を市民として育てる（→ [[黎明評議会連邦憲章|市民の権利]]・[[学びと識字]]）。
- [[鉄環兵団]]――孤児を兵に育てる。幼少から鍛え、出自を問わぬ純粋な実力主義の苗床（→ [[階級]]）。
- [[自由港同位体]]――孤児を労働力・徒弟として引き取る。情より実利だが糧は与える（→ [[商人]]）。
- [[灯心自由市ファロス]]――ギルドと市が孤児を徒弟に充て、市民へ育てる都市の慈善（→ [[工房と職人]]）。

## NPC・クエストへの適用指針
- **孤児院の世話役NPC**（細る慈善）――「この子らに罪はねえ。だが養う銭が足りねえ。育てきれずに通りへ出す子も……いる。お上は、こういう所には金を回さねえのさ。」
- **拾われ育ちの将NPC**――「俺は名も知らぬ星の孤児だった。拾ってくれた親方がいなけりゃ、今ごろ場末の賭場で野垂れ死んでる。恩は、戦果で返すしかねえ。」（→ [[名誉と面子]]）
- **クエスト分岐**：戦災孤児の群れの処遇 → (a) **孤児院・教育に投資**＝[[財政|金]]はかかるが二十年後の人材になる／(b) **見捨てる/底辺労働へ**＝安いが[[俠気と無頼|無頼]]・[[難民と漂流民|流民]]の温床に／(c) **才ある子を選んで引き立てる**＝有望株を得るが選に漏れた子の恨み。
