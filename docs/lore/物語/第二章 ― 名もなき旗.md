# 第二章 ―― 名もなき旗

物語は、銀河の片隅、痩せた辺境星域から始まる。そこに掲げられた一本の、まだ名もなき旗から。

旗の主は、[[黎明評議会]]の士官学校を出たばかりの新任少尉、[[ミレイア・セルウィン]]という。辺境の植民星に技師の娘として生まれ、血統も後ろ盾も持たぬ彼女が頼れるのは、学校を**首席**で修めた才ひとつ。ずば抜けた武はない。だが[[回廊]]の地形を読む眼と、寡兵を捌く陣形の妙にかけては、誰も彼女に及ばなかった。預けられた船はわずか。評議会の威令もろくに届かぬ前線で、隣接する[[回廊|要衝]]はことごとく、はるかに強大な諸侯の手にある。最初の戦いは、栄光のためではなく、ただ生き延びるための戦いだった。通商破壊から痩せた交易船団を守り、回廊の細い分岐を縫って追手をまき、自分より数倍も大きな敵艦隊を、地の利と読みだけで出し抜く。一度の判断の誤りが、艦隊の全滅を意味した。彼女の旗艦の名は〈[[グリニッジ]]〉――失われた故郷の、航海の基準点に因む。星を読んで己の位置を定めるその名は、まるで彼女の才そのものだった。

ミレイアは独りではなかった。傍らには、学校の同期にして無二の親友、[[アウレリア・ファルケンハイト]]がいる。旧連合の名門貴族の令嬢でありながら、連合崩壊で家が没落すると、彼女は家名から貴族の証「フォン」を自ら外し、血統の通じぬ評議会へ身を投じた**元貴族**だ。卒業席次は次席――首席のミレイアの、すぐ後ろ。慎重で守勢のミレイアとは正反対に、アウレリアは先んじて斬り込む猛攻の将で、その旗艦は大時鐘の名を負う〈[[ビッグベン]]〉。標準時の[[グリニッジ]]が刻を読み、大時鐘のビッグベンが刻を告げて斬り込む。「お前が読み、わたしが斬る」――生まれも気質も正反対の二人は、攻守の対をなして戦場を渡った。

勝てば兵が増え、要衝をひとつ奪えば次の戦への足がかりができる。二人は小さな勝利を積み重ねた。寄る辺ない艦隊が身を寄せたのは、いずれの諸侯にも属さぬ[[都市国家|自由市]]――月神の名を負う港〈[[灯心自由市ファロス]]〉だった。武装中立のその港を足場に、傭兵まがいの戦で禄を食み、近隣の小勢力を従え、あるいは降し、ミレイアの旗の下にしだいに人が集まりはじめる。滅んだ家から流れてきた老練な参謀。功を立てても血統ゆえに重用されなかった猛将。理想に倦んで議会を去った若い戦術家。敵だったはずが、ミレイアの采配に惚れ込んで降ってきた者すらいた。だが、来る者があれば、去る者もある。恩賞に不満を抱いた将が、より大きな禄を約束する隣国へ寝返り、昨日まで味方だった配置の弱点を敵に売る。ミレイアは、戦場の采配だけでなく、人の心の[[旗幟]]をも読み、繋ぎとめねばならなかった。武で奪った版図は、信なくしては一夜で瓦解する。それを、彼女は幾度もの裏切りを通して学んでいく。

辺境にも、噂は届く。――近ごろ、各地の戦の様相が、根本から変わってきた、と。ある諸侯が、停止していたはずの[[灯台|地方灯台]]を再起動させ、これまで死んでいた回廊を「**開いた**」というのだ。死んだ航路を生き返らせる力は、すなわち戦略地図そのものを書き換える力である。それを持つ者は、誰も予期せぬ方角から艦隊を送り込み、難攻不落とされた要衝を、まるで裏口から入るように背後から衝ける。逆に、生きた回廊を「**閉じて**」敵の補給線を断ち、無傷のまま一国を飢えさせることすらできる。

[[灯台]]を制する技術――それは失われた[[大環状連合|連合]]の遺産であり、断片化した銀河を再び一つに束ねうる、唯一の鍵だった。そして今、その断片が、諸侯たちの争奪の的となりつつあった。辺境の小勢力にすぎなかったミレイアとアウレリアもまた、否応なくその奔流へと巻き込まれていく。名もなき旗が、やがて銀河の旗幟そのものを揺るがすことに、まだ二人は気づいていない。
