# セニュレー財団

> [[灯心自由市ファロス]]の金融（銀行・両替）。金融家[[ガスパール・セニュレー]]が率いる。

## 概要
[[灯心自由市ファロス]]を本拠とする**金融（銀行・両替）**。金融家の[[ガスパール・セニュレー]]が興した商会で、財力は**新興**と目される。預金と貸出で信用を回し、灯心自由市ファロスの経済を裏から支える。

## 事業・経営
- 主力＝金融（銀行・両替）。財産は**投資**で運用。利潤は法人税ぶん国庫へ（私有企業）。

## 関係
