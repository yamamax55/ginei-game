# 黎明評議会（れいめいひょうぎかい）

> 植民星の民が選んだ議会の連邦。

## 概要
「支配ではなく自治を、血統ではなく合意を」と唱える植民星の民選議会連邦。寄せ集めで足並みの揃わぬ艦隊を、巧みな連携と土地勘で操り、強大な敵に幾度も土をつける。

## 大義と瑕
- **理**：理想は高い（自治・合意・反専制）。
- **瑕**：合議は遅く、内輪の対立は絶えず、決断の遅れが幾人もの将を死なせる。

## 首都
**オオクニヌシ**（[[星系名|アコンカグア]]星系）。新大陸の最高峰の名を負う星系の、国造り・国譲りの神の名を冠する惑星＝開拓と合議で築いた連邦の議事府。植民星の民選議会が集う。

## 戦術
連携火力・包囲。推奨陣形＝鶴翼陣（攻撃↑↑・中央薄い）。
