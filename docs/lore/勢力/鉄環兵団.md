# 鉄環兵団（てっかんへいだん）

> 連合崩壊の混乱からのし上がった、傭兵あがりの軍閥。

## 概要
血統も理念も持たず、ただ実力のみを是とし、速攻と奇襲で諸侯を次々と呑み込んでいった新興勢力。

## 大義と瑕
- **理**：澱んだ序列を破壊する。功さえ立てれば誰でも将になれる。
- **瑕**：力こそ正義の世を招く。敗れた将に明日はない。

## 首都
**スサノオ**（[[星系名|マッターホルン]]星系）。鋭く天を衝く名峰の星系の、暴風の戦神の名を負う惑星＝武力で奪い取った軍閥の本営。血統でなく実力でのし上がる者たちの牙城。

## 戦術
速攻・奇襲。推奨陣形＝紡錘陣／横陣（最大火力・脆い）。
