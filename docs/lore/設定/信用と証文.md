# 信用と証文（しんよう・しょうもん）＝紙が運ぶ約束

> 「金貨は重いし、回廊で奪われる。だが俺の名を記したこの一枚は――名のある港なら、どこでも金に化ける。信用ってのは、そういうことさ。」

## 核心（中央銀行なき世界で、信用が貨幣を補う）
[[環暦|大解体]]で銀河規模の決済網が砕け、勢力ごとに[[通貨]]が乱立した（→ [[金融]]）。重い金貨を[[回廊]]越しに運ぶのは危険（→ [[通商破壊]]）で、遠隔の商いには**証文＝信用で動く紙**が要る。手形・為替・借券は、振出人の[[名誉と面子|顔]]と[[商社]]の与信を担保に、金貨の代わりに約束を運ぶ。信用は、公権力の保証なき世界で取引を成立させる**もう一つの貨幣**であり、その毀損は破産と[[金融|信用恐慌]]を招く。

## 紙の信用の仕組み（何が約束を支えるか）
- **手形と為替**――遠隔地払いの約束。[[商社]]の支店網が振出と取立を繋ぎ、金貨の輸送を省く（→ [[商人]]）。
- **与信と人脈**――誰の証文が通るかは[[名誉と面子|顔]]次第。信用ある者の紙は金、無名の紙はただの紙（→ [[流言]]の評判）。
- **借券と利息**――先の[[財政|歳入]]や交易益を担保に金を借りる。[[金融]]の国債・銀行貸出と地続き。
- **不渡りと連鎖破綻**――一枚の証文が焦げ付けば信用が崩れ、[[金融|取り付け]]と連鎖破綻を招く。信用は脆い（→ [[金融]]）。

## 信用をめぐる物語
- **信用の偽造**――偽手形・空証文で詐取する。露見すれば[[名誉と面子|面子]]の完全な失墜と[[法廷と裁き|断罪]]。
- **借金のカタ**――返せぬ証文は人を縛る。艦も忠誠も身柄も担保に（→ [[遊興]]の賭博負債・[[旗幟|寝返り]]）。
- **フィクサーの保証**――無名の者の証文を、[[汚職とフィクサー|フィクサー]]が名義を貸して「通る紙」に変える（与信の代行）。

## 勢力ごとの信用
- [[碧晶公国]]――家門の信用が証文の格を決める。門閥の紙は厚く通り、平民の紙は割り引かれる（→ [[身分]]）。
- [[黎明評議会]]――制度的な信用網（公的銀行・登記）を育てるが、辺境までは届かない（→ [[政体]]・[[財政]]）。
- [[鉄環兵団]]――信用より現物。証文を嫌い、略奪と現金で動く軍閥経済（→ [[通商破壊]]）。
- [[自由港同位体]]――信用経済の中枢。手形・為替・与信を束ね、紙の信用で銀河の商いを回す（→ [[商社]]・[[金融]]）。
- [[灯心自由市ファロス]]――ギルドの相互保証で市民の信用を支える都市型金融。

## NPC・クエストへの適用指針
- **両替商・金融NPC**（信用を値踏み）――「あんたの証文ねえ……失礼だが、お名前を存じ上げない。額面の七掛けでなら、引き受けてもいいが？」
- **信用を盾にするNPC**――「現金は無い。だが俺の名がある。この港で俺の証文が通らなかったことは、一度もないぜ。」
- **クエスト分岐**：大金が要る場面で → (a) **現金を運ぶ**＝確実だが重く[[通商破壊|奪われる]]危険／(b) **自分の証文で借りる**＝身軽だが[[名誉と面子|信用]]を賭け、不渡りで破滅／(c) **[[汚職とフィクサー|フィクサー]]に与信を借りる**＝高い手数料だが無名でも紙が通る。

## ゲームデータ参照
- 信用・証文そのものに専用機構はない（ナラティブ層）。担保する[[金融]]は銀行・国債・信用創造（`Bank`/`BankRules`／`BondMarketRules`／`SovereignBondRules`）、与信は[[商社]]（`TradingHouse` の与信）。信用毀損・連鎖破綻は[[金融]]（取り付け・債務超過＝`BankRules`）。証文の通用力は[[名誉と面子]]・[[流言]]（評判）、偽造は[[法廷と裁き]]・[[汚職とフィクサー]]（`HiddenTraitRules`）。
