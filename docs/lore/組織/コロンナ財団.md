# コロンナ財団

> [[自由港同位体]]の金融（銀行・両替）。金融家[[グリエルモ・コロンナ]]が率いる。

## 概要
[[自由港同位体]]を本拠とする**金融（銀行・両替）**。金融家の[[グリエルモ・コロンナ]]が興した商会で、財力は**新興**と目される。預金と貸出で信用を回し、自由港同位体の経済を裏から支える。

## 事業・経営
- 主力＝金融（銀行・両替）。財産は**貯金**で運用。利潤は法人税ぶん国庫へ（私有企業）。

## 関係
- 本拠勢力：[[自由港同位体]]
- 主・創業者：[[グリエルモ・コロンナ]]（金融家）
