# 捕虜と亡命（ほりょとぼうめい）

> 敗れた将は、必ずしも死なない。捕らわれ、寝返り、亡命する――敗北のあとの処遇が、次の戦の駒を決める。

## 敗将のゆくえ
会戦で敗れた提督の運命はさまざまだ。配下に守られて退却する者（[[旗幟|捨てがまり]]）、討たれる者、そして**捕虜**となる者。捕らわれた将は処遇次第で――厚遇されて寝返るか、交換で戻るか、獄に朽ちるか――その後の戦力地図を左右する。行方不明のまま消える者もいる。

## 亡命と請求権
主家に容れられぬ者、滅びゆく国を捨てる者は、他勢力へ**亡命**する。亡命者は内情を手土産にし、時に旧主への請求権（正統な継承者だという主張）を携えて、受け入れ国の内政干渉のカードとなる。人材は国境を越えて流動し、敵将が明日の味方になる――それがこの乱世の常である（→ [[旗幟]]）。

## 処遇という政治
捕虜・亡命者をどう扱うかは政治である。寛大に遇せば人望を集め寝返りを誘えるが、危険な才を生かすことにもなる。冷酷に処せば見せしめになるが、降伏の芽を摘み徹底抗戦を招く。名君ほど、敗者の処遇に器量が表れる。
