# ゲルトルート・クヴェルフルト

> 机上で会戦の勝敗を分ける男。鉄環兵団式部省に在って、人事・選叙を司る。

## 概要
[[鉄環兵団]]の[[官僚|文官]]。31歳。**式部省**（人事・選叙）に属し、官職は**式部卿**、位階は**従四位下**。文才（運営・情報）を本領とし、傭兵あがりの軍閥。兵站と金庫を握る者が実権を持つ叩き上げの官房なかで実務の屋台骨を担う。

## 容姿
落ち着いた佇まいに理知的な眼差し。鉄環兵団の文官正装に従四位下の位色をまとう。31歳。

## 来歴
- 鉄環兵団の市井に生まれ、地方の書記から叩き上げ下級官から累進して鉄環兵団式部省に入った。
- 考課を重ねて従四位下に叙され、現在は式部卿として人事・選叙にあたる。

## 性格・信条
- 事なかれを嫌い、必要とあれば上官にも諫言する。
- 信条は**能力主義**。鉄環兵団の理念「実力主義の征服」との距離が、時に去就を左右する。
