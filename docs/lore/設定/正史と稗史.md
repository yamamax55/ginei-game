# 正史と稗史（せいしとはいし）

> 同じ会戦も、勝者の[[年表|正史]]と市井の[[群像劇の構成|稗史]]では別の貌を持つ。歴史は事実でなく、**誰が書くか**で決まる。

## 正史（公の記録）
各勢力は自らの正統を語る**正史**を編む。建国を聖戦と讃え、敗者を逆賊と記し、都合の悪い事実は削られる。[[碧晶公国]]の正史は血統の連続を、[[黎明評議会]]のそれは自治の勝利を語る――同じ[[ダーダネルス回廊の会戦]]さえ、勝者と敗者で英雄と悪役が入れ替わる（羅生門のごとく）。[[年表]]は諸勢力の正史を突き合わせた骨組みにすぎない。

## 稗史（市井の語り）
正史がこぼした真実は、**稗史**＝噂・講談・列伝に生き残る。名もなき兵の見た戦場、敗将の最期の言葉、宮廷の秘め事――本作が**[[群像劇の構成|オムニバス群像劇]]**を採るのは、唯一の正史でなく、立場の異なる多くの[[群像劇の構成|列伝]]を束ねることでしか、この時代の全体は見えないからだ。

## 秘史の開示
封じられた事実は、時に思わぬ形で世に出る。亡命者の証言、押収された書簡、内通の発覚――一片の開示が、磨かれた正史を一夜で崩すこともある。歴史は確定でなく、**たえず書き換えられる係争地**である。

## ゲームデータ参照
- 公の記録の骨組みは[[年表]]、群像の語りは[[群像劇の構成]]。秘された事実の暴露は `DisclosureRules`/`DisclosureLedger`（開示エンジン）、事象の観測は `ChronicleObserverOverlay`（Alt+D）。正史そのものはフレーバーで、数値は持たない。
