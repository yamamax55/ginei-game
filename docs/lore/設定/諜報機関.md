# 諜報機関（ちょうほうきかん）

> 戦端を開く前に勝つ目と耳。**何を、誰に隠すか**が、その勢力の体制の本性を露わにする。

## 各勢力の影
| 勢力 | 機関 | 性格 |
|---|---|---|
| [[碧晶公国]] | 宮廷諜報院 | 門閥の影。政敵の醜聞を握り、血の秩序を陰で守る |
| [[黎明評議会]] | （常設の秘密警察を持たない） | **法の支配ゆえ監視は限定**。令状と適正手続でしか暴けない（→ [[黎明評議会連邦憲章#第二章　連邦市民の権利|適正手続]]） |
| [[自由港同位体]] | 商会連絡網 | 交易こそ情報。港々の帳簿と噂が世界一の情報源 |
| [[鉄環兵団]] | 憲兵・密偵 | 暴力的で粗い。裏切りの芽を恐怖で摘む（→ [[旗幟]]） |
| [[灯心自由市ファロス]] | 港の盾と目 | [[セリーヌ・マルロー]]が率いる中立都市の諜報網。武を持たぬ街が滅びぬ理由 |

## 港の盾と目
武装中立の[[灯心自由市ファロス]]を支えるのは艦隊でなく**情報**である。「港の盾と目」と呼ばれる諜報網は、[[アマーリア・ヴァレンティ|盾]]（守り）と[[セリーヌ・マルロー|目]]（諜報）の二人に象徴され、戦う前に企てを読み切ることで、剣を持たぬ街を大国の間に生かし続ける（→ [[列伝 ― 港の盾と目]]）。

## 監視と自由の綱引き
諜報は両刃である。[[黎明評議会|民主勢力]]は監視を法で縛り（自由を守るが裏をかかれやすい）、専制・軍閥は監視を強め（裏切りに強いが民心を蝕む）。情報公開と秘密政治のどちらに振るかが、体制の性格を決める。

## ゲームデータ参照
- 情報能力は `AdmiralData` の情報（`EffectiveIntelligence`）。秘された事実の露見は隠し特性（`HiddenTraitRules`＝観測側の情報力が高いほど露見）。情報公開／秘密政治は `DisclosureRules`・秘密警察 `SecurityRules`（監視上限は `RuleOfLawRules` の法の支配で制約）。観測＝Alt+D（事象）。
