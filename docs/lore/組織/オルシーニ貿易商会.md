# オルシーニ貿易商会

> [[自由港同位体]]の総合商社・交易。仲買人[[マルコ・オルシーニ]]が率いる。

## 概要
[[自由港同位体]]を本拠とする**総合商社・交易**。仲買人の[[マルコ・オルシーニ]]が興した商会で、財力は**富裕**と目される。交易と相場で身代を回し、自由港同位体の経済を裏から支える。

## 事業・経営
- 主力＝総合商社・交易。財産は**投資**で運用。利潤は法人税ぶん国庫へ（私有企業）。

## 関係
