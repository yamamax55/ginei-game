# マッターホルン星系

> 鋭峰の名を継ぐ、傭兵軍閥の根城――[[鉄環兵団]]の首都。

## 概要
峻険な〈マッターホルン〉の名を冠する星系。[[鉄環兵団]]の首都星系で、傭兵あがりの軍閥の本拠。首星[[惑星名|スサノオ]]――猛々しい荒ぶる神の名のとおり、実力主義の征服を掲げる兵団の牙城。兵站と金庫を握る者が実権を持つ、叩き上げの軍政が支配する。

## 地理・接続
- 隣接回廊：[[回廊]]（速攻・奇襲の出撃線。→ 名前付き回廊の整備待ち）
- 主要惑星：**スサノオ**（首星・兵団本営／日本神話の荒ぶる神＝[[惑星名]]）

## 産業・資源
- 兵器・調達と略奪／戦費で回る戦時経済。死の商人と調達商が暗躍する。

## 帰属・歴史
- 現支配：[[鉄環兵団]]（新興軍閥・legacyFaction なし）
- 過去の領有：旧[[大環状連合]]の駐留宙域。灯台沈黙の混乱に乗じ、傭兵団が武力で割拠。
