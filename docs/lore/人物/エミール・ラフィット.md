# エミール・ラフィット

> 几帳面な記録官。灯心自由市ファロス民部省に在って、内政・戸籍を司る。

## 概要
[[灯心自由市ファロス]]の[[官僚|文官]]。38歳。**民部省**（内政・戸籍）に属し、官職は**民部少輔**、位階は**正六位上**。文才（運営・情報）を本領とし、都市国家。市民自治のもと、港と財庫を回す実務官僚が屋台骨なかで実務の屋台骨を担う。

## 容姿
細身で姿勢正しく、感情を表に出さない。灯心自由市ファロスの文官正装に正六位上の位色をまとう。38歳。

## 来歴
- 灯心自由市ファロスの市井に生まれ、科挙の殿試に次席で及第し進士となり下級官から累進して灯心自由市ファロス民部省に入った。
- 考課を重ねて正六位上に叙され、現在は民部少輔として内政・戸籍にあたる。

## 性格・信条
- 改革志向で硬直した官制に苛立ち、新制度を持ち込もうとする。
- 信条は**能力主義**。灯心自由市ファロスの理念「武装中立・市民自治（都市国家）」との距離が、時に去就を左右する。
