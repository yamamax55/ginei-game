# ツクヨミ

> 高峰の星系に灯る月神の惑星。生きた灯台を抱く、暗夜の自由市（惑星名は日本神話 → [[惑星名]]）。

## 概要
[[灯心自由市ファロス]]の首星にして全土。高峰の名を負う[[カンチェンジュンガ星系]]の第二惑星で、暗夜を照らす月神ツクヨミの名を冠する＝**灯台都市**の象徴。版図を広げず、ただ一個の星系を自ら治める[[都市国家]]で、いまなお**生きた[[灯台]]**を抱くがゆえに、武を持たずとも大国の間に独立を保つ。

## 地誌・軌道
- 所属星系：[[カンチェンジュンガ星系]]（→ [[星系名|名峰]]）
- 軌道：第2惑星（要衝回廊の関を扼す立地）
- 首星：true（参事会と港湾・灯台管制塔が置かれる＝市の全機能が一星に集約）

## 内政（`Province`）
- 市民自治憲章のもと商法・市民法で公正を保つ（→ [[灯心自由市ファロスの法令]]）。信用が独立の盾。
- 住民の思想は中立・自治・実利。武装は最小で、傭兵契約と[[諜報機関|港の盾と目]]が守りを補う。

## 防衛・攻城（`Planet`／`PlanetSiegeRules`）
- 生きた[[灯台]]で航路の開閉を握り、寄せ手の補給線を細らせる。最良の[[水先案内人]]を擁し、地の利で時を稼ぐ。
- 一星に全機能が集中するため、陥ちれば即・滅亡＝守りに必死で、外交と信用で攻囲を解くのが常道。

## 帰属・歴史
- 現支配：[[灯心自由市ファロス]]
- 独立：[[ツクヨミ自由市防衛戦]]（環暦9年）で攻囲を耐え、星都が自治を宣言した。
