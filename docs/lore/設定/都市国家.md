# 都市国家（としこっか）

> [[封土]]を構えず、ただ一個の星系を自ら治める自治都市。諸侯にも大義にも属さない第三の極。

## 概要
[[第一章 ― 諸侯の時代|諸侯]]が[[回廊|要衝]]を押さえて周辺の星々を[[封土]]として囲い込んだのに対し、**周辺を併呑せず、自らの星系ひとつだけを自治の府として守り抜いた**勢力がある。これが**都市国家（自由市）**である。諸侯が「領を広げて旗を立てる」垂直の権力なら、都市国家は「一個の星に深く根を張る」凝集の権力だ。

灯が消えた直後、生きた[[回廊]]の交点に位置した豊かな星系のいくつかは、難民・船・資本を吸い寄せて一夜にして膨れ上がった。だがそれらの市民は、近隣の[[大環状連合|連合]]貴族や軍閥に[[封土|叙任]]されて頭を垂れることを拒み、商工ギルドと船長たちの**評議会**を立てて自治を宣言した。彼らは版図ではなく**港・市場・金融**を武器とし、武力で領土を奪う代わりに、四囲の諸侯を天秤にかけて生き延びる道を選んだ。

## 諸侯との違い
| | 諸侯（封土勢力） | 都市国家（自由市） |
|---|---|---|
| 規模 | 複数星系を併呑した版図 | 単一の要衝星系のみ |
| 正統の根拠 | 血統・大義・武力（[[封土|叙任]]） | 市民の合意・富・中立 |
| 統治 | 公・議会・商会・軍閥の首長 | 商工ギルドと船長の**市政評議会** |
| 拡張 | 領土を奪い旗を立てる | 領土を取らず港と市場で稼ぐ |
| 軍 | 国力相応の常備艦隊 | 少数精鋭の機動防衛＋傭兵 |
| 生存戦略 | 要衝の支配・会戦・同盟 | 武装中立・通行料・諸侯の相互牽制 |

## 統治
都市国家を治めるのは特定の公や将ではなく、**有力ギルドと船主の合議体＝市政評議会**である。評議会は任期つきの**市政長**を互選し、軍は文民たる評議会に従う（将が市を私する＝[[旗幟|簒奪]]を制度的に嫌う）。寡頭的だが世襲ではなく、富と実績が席を決める。中央に仰ぐ主君を持たない＝**自治度は最大、上納先はない**。

## 生存戦略
- **武装中立**：いずれの大義にも与せず、四囲の諸侯と個別に[[旗幟|不可侵]]を結んで相互に牽制させる。どこか一国が呑もうとすれば、均衡を崩される他の諸侯が裏で都市を支える。
- **通行料**：生きた[[回廊]]の関を握り、安全な航路を切り売りして稼ぐ。富が城壁となる。
- **少数精鋭＋傭兵**：版図を持たぬぶん常備艦隊は小さいが、機動防衛と雇われ提督で本拠星系を要塞化する。
- **避難所**：戦火を逃れた民・船・資本の受け皿となり、人口と富が雪だるま式に集まる（定住魅力が高い）。

## 大義と瑕
- **理**：戦乱のただ中に、力でなく信用で成り立つ秩序の島を保つ。難民の駆け込み寺であり、敵味方を問わぬ市場として銀河の血を巡らせる。
- **瑕**：拠るべき大義を持たぬ＝富と中立だけが支え。均衡が崩れれば一国に呑まれ、誇り高き自由市はあっけなく諸侯の**[[旗幟|属国（属領）]]**へ転落する。内では寡頭の派閥争いが絶えない。

## プレイヤー体験での役割
- **始まりの足場**：版図を持たぬ弱小プレイヤーが身を寄せ、傭兵として禄を食み、機動戦で名を上げる出発点（[[第二章 ― 名もなき旗]]の「小から大へ」）。
- **第五の旗**：四つの大義のいずれにも与せず、自ら独立を保つ道（[[第三章 ― 四つの大義]]）の制度的な受け皿。諸侯になるか、自由市のまま終わるかはプレイヤー次第。
- **流動の結節点**：同盟・裏切り・通行料・亡命がここで渦巻く。固定の主敵を置かない多極構造の潤滑油。

## ゲーム実装との対応
> ※数値の正はアセット／Core 側。ここは「どの実装に乗るか」の見取り図。設計段階のものは（設計）と付す。

| 設定 | 実装 |
|---|---|
| 単一星系の自治府 | `StarSystem` 1ノード＋その `Planet`／`Province`（版図を広げない＝周辺 `Province` を併呑しない） |
| 中立の勢力 | `FactionData`（`legacyFaction` なし＝中立・`nonHostileFactions` を広く取る）。3勢力目以降はアセット追加のみで増える |
| 少数精鋭＋傭兵 | 小さな `FleetPool`／`FleetRoster`。提督は[[封土|叙任]]の家臣でなく雇われ＝`AdmiralData`＋`CommandCapacityRules`。新設・解隊は `FleetEstablishmentRules` |
| 本拠星系の防衛 | `ZoneOfControl`（自系内は固いが外への投射は小さい）・要塞化＝`PlanetSiegeRules` |
| 武装中立・不可侵 | `DiplomacySession`／`DiplomacyState`（外交状態 平時／同盟／**不可侵**／**属国**／交戦）。複数勢力と不可侵を張り相互牽制。呑まれる＝属国へ遷移（`DiplomacyRules`） |
| 通行料・市場 | 要衝の関＝`CommerceRaidingRules`／通行料、`ResourceStockpile`／`SupplyRules`／`LogisticsRules.CohesionFactor` |
| 市政評議会・文民統制 | `CouncilRules`／`ElectoralSystemRules`／`PartyRules`（`Premier`＝市政長）・`CivilianControlRules`（軍が市を私さない） |
| 自治度・上納先なし | `RegionalGovernor`／`DevolutionRules`（自治度≈1・中央上納なし）・`GubernatorialRules`（応答先＝市民）（設計：`local-autonomy-design`） |
| 都市の富 | `MarketRules`・`Bank`／`BankRules`（金融都市）・`RealEstateCompany`（地価）・`TradingHouse`（総合商社） |
| 人口の凝集・避難所 | `DemographicsRules`／`PopulationDynamicsRules`、`PopulationMigrationRules.Attractiveness`（高い定住魅力＝難民が集まる） |
| 旗幟・調略 | `loyalty`／`intrigue`、外交 opinion（諸侯を天秤にかける） |

## 実例
- [[灯心自由市ファロス]] … 生きた[[灯台|地方灯台]]を抱く要衝の自由市。武装中立と通行料で栄える金融都市。都市国家の代表例。
