# 火と灯り（ひとあかり）＝艦と暮らしを動かす力

> 「灯台の光が消えた夜、人は改めて気づいたのさ。光ってのは、ただそこにあるもんじゃない。誰かが、何かを燃やして、保ってるもんだとな。」

## 核心（動力と燃料が、艦も都市も暮らしも支える）
[[灯台]]が銀河に光を配っていた時代、人は動力を当然のものとしていた。その沈黙（→ [[環暦|大解体]]）で、艦の機関も都市の灯も暮らしの火も、**自ら燃料を確保して保つ**ものになった。艦隊の[[兵站|燃料]]は[[回廊]]を渡る生命線であり、都市の灯と熱は[[都市と港の日常|暮らし]]の土台、工房の火は[[工房と職人|生産]]の源である。燃料の枯渇は艦隊を宙で立ち往生させ（→ [[兵站]]の滅びの時計）、都市を闇と寒さに沈める。動力を制する者が、戦も暮らしも制する。

## 力の源（何が燃え、何を動かすか）
- **艦の燃料**――艦隊機関を動かす戦略物資。[[兵站]]の三資源（物資/弾薬/燃料）の一。枯れれば精鋭も漂流物に（→ [[鉱と採掘|燃料鉱]]）。
- **都市の灯と熱**――[[都市と港の日常|都市]]の照明・暖房・調理の火。途絶は民の困窮と[[民心]]の冷えに直結。
- **工房の火**――精錬・鍛造・[[建艦|建造]]を支える熱源（→ [[工房と職人]]・[[技術]]）。
- **灯台の遺産**――旧[[大環状連合|連合]]の動力技術。動く[[灯台]]・[[義肢と人造|自動機関]]は今や再現困難な遺産（→ [[灯心自由市ファロス|生きた灯台]]）。

## 力をめぐる物語
- **燃料の枯渇**――補給線を断たれた艦隊が燃料切れで立ち往生。[[通商破壊|燃料輸送]]の攻防が会戦の帰趨を決める（→ [[兵站]]）。
- **灯の象徴**――灯は[[信仰]]の象徴でもある。灯を絶やさぬことが秩序と希望の証（→ [[巡礼と聖地]]・[[祝祭|聖灯節]]）。
- **動力の独占**――希少な燃料鉱・旧連合の動力源を握る者の優位（→ [[鉱と採掘]]・[[戦争]]の資源目標）。
- **闇という武器**――敵都市の動力を断ち、闇と寒さで屈服させる兵糧攻めの変奏（→ [[要塞|封鎖]]・[[罪と罰|見せしめの停灯]]）。

## 勢力ごとの動力
- [[碧晶公国]]――旧連合の動力技術を宮廷が秘蔵。宮廷の灯は絢爛、辺境は乏しい[[身分|格差]]（→ [[義肢と人造]]）。
- [[黎明評議会]]――万人への動力供給を理念とし、辺境まで灯を届けようとする（→ [[黎明評議会連邦憲章]]・[[財政]]）。
- [[鉄環兵団]]――軍用燃料を最優先で確保。民生の灯は後回しの軍事優先（→ [[兵站]]）。
- [[自由港同位体]]――燃料交易の中枢。三資源を売買し、燃料の相場を握る（→ [[商社]]・[[度量衡と地域差]]）。
- [[灯心自由市ファロス]]――**生きた[[灯台]]**を抱える稀有な都市。動力と灯の知に長け、それが都市の誇りと生命線（→ [[都市国家]]）。

## NPC・クエストへの適用指針
- **補給将校NPC**（燃料に泣く）――「弾はまだある。だが燃料が、あと三日分だ。補給が来なけりゃ、この艦隊はただの的になる。……宙で燃料切れほど、惨めな死に方はねえぞ。」
- **灯守のNPC**（灯を絶やさぬ務め）――「この灯を絶やしちゃならねえ。港の連中が、これを頼りに帰ってくるんだ。燃料が尽きかけても……灯だけは、最後まで守るのさ。」（→ [[巡礼と聖地]]）
- **クエスト分岐**：燃料・動力の危機の場面で → (a) **正規の補給線を確保/待つ**＝確実だが遅く断たれる危険（→ [[兵站]]）／(b) **闇市・略奪で燃料を奪う**＝速いが高くつき恨みを買う（→ [[通商破壊]]・[[汚職とフィクサー]]）／(c) **旧連合の動力源を探索/接収**＝一発逆転だが[[義肢と人造|遺産]]の争奪と罠。
