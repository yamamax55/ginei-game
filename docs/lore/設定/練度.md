# 練度（れんど）

> 場数が艦隊を変える。新兵の群れと古参の精鋭は、同じ数でも別物。生き延びた者だけが強くなる。

## 段階
| 段階 | 像 |
|---|---|
| 新兵 | 練度なし。数は揃うが脆く、崩れやすい |
| 一般 | 一通りの経験を積んだ平均的な艦隊 |
| 精鋭 | 多くの会戦を生き延びた手練 |
| 古参 | 戦場の理を知り尽くした最精鋭。寡兵でも侮れない |

会戦をくぐり経験（XP）を積むほど段階が上がり、戦闘に倍率として効く。逆に消耗し補充ばかりになれば練度は薄まる。

## 練度の戦略
- **古参**は数では測れぬ価値を持つ＝失えば取り返しがつかない。名将は古参を死なせぬよう温存し、決定的な局面で投じる。
- [[鉄環兵団|軍閥]]は「[[名門校|戦場が学校]]」＝実戦で叩き上げ、生き残りが精鋭化する。脆い新兵を使い潰す消耗戦は、長期では練度を枯らす。

## ゲームデータ参照
- 正は `VeterancyRules`（新兵／一般／精鋭／古参・平均XP→会戦の係数 `CombatModifiers`#106 へ倍率）。練度は[[士気]]・提督能力と別軸で、艦隊の質を底上げする。観測＝Alt+V（軍動態）。
