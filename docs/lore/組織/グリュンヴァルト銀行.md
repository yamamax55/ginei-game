# グリュンヴァルト銀行

> [[碧晶公国]]の金融（銀行・両替）。金融家[[エルフリーデ・フォン・グリュンヴァルト]]が率いる。

## 概要
[[碧晶公国]]を本拠とする**金融（銀行・両替）**。金融家の[[エルフリーデ・フォン・グリュンヴァルト]]が興した商会で、財力は**中堅**と目される。預金と貸出で信用を回し、碧晶公国の経済を裏から支える。

## 事業・経営
- 主力＝金融（銀行・両替）。財産は**貯金**で運用。利潤は法人税ぶん国庫へ（私有企業）。
