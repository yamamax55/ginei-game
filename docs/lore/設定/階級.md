# 階級（かいきゅう）

> 「指揮できる規模」を定める序列。兵力は人でなく艦隊が持ち、人は階級で**どれだけの艦隊を委ねられるか**を持つ。

## 共通ラダー（序列 tier）
| tier | 階級 | 備考 |
|---|---|---|
| 5 | 准将 | 将官の入口 |
| 6 | 少将 | |
| 7 | 中将 | |
| 8 | 大将 | |
| 9 | 上級大将 | [[碧晶公国|帝国系]]のみ（欠番の勢力もある） |
| 10 | 元帥 | 最高位 |

> 兵卒・下士官・尉官・佐官を経て将官（准将〜元帥）に至る。各勢力は固有の階級名を持つが、**序列（tier）が同じなら同列**とみなす。

## 階級が決めるもの
- **指揮兵力**：高い階級ほど大艦隊を率いる。過大な兵力に下位階級を据えると指揮が破綻する（適任なしは空席）。
- **[[封土|叙任]]**：[[封土]]が艦隊指揮を授けるとき、規模は階級で決まる。
- **栄誉と呼称**：[[勲章|敬称]]は階級名の前後に置かれ、[[提督]]の頭上に階級＋名で表示される。

## 勢力をまたぐ同列
[[碧晶公国|公国]]の中将と[[黎明評議会|連邦]]の中将は、名は違えど**同じ tier 7**＝同列。寝返り・捕虜交換・連合艦隊で勢力を越えるとき、この同列判定が物を言う（欠番の階級はその勢力の直近 tier へ丸める）。

## ゲームデータ参照
- 序列・同列判定・昇進の唯一の窓口は `RankSystem`（`AreEquivalent`/`Compare`/`NextRankTier`/`ResolveTier`）。指揮規模は `CommandCapacityRules`（`CanCommand`）。人物の階級は `AdmiralData.rankTier`、勢力の階級名は `FactionData.ranks`（tier＋名）。既定ラダー＝准将5/少将6/中将7/大将8/上級大将9/元帥10。
