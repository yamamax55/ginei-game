# 史実人物録（archetype 参照プール）

> Ginei の人物設計を支える参考資料。**各時代の著名人物を抽出した人物プール**で、Ginei 人物の frontmatter `archetype:` がここの人物を参照する（「この提督は戦国の○○型／WWII の△△型」）。
> **10時代 × 各約100人 ＝ 総勢1000人**を目標に、時代ごとのページに人物表として集約する。

## 使い方（Ginei 人物のプロパティ）
- Ginei 人物ノートの frontmatter `archetype:` に、ここの人物名を記す（複数可）。例：`archetype: ハンニバル / 真田幸村`。
- 各時代ページは**人物表**（名前・生没年・役割・資質）。資質タグで横断的に近い型を探せる。

## 各ページの体裁
- frontmatter：`type: 史実人物録`／`era: <時代名>`／`tags: [史実人物, <時代名>]`。
- 本文に**人物表**：`| 人物 | 生没年 | 役割・立場 | 資質・アーキタイプ |`。
- 著名人物を優先（武将・君主・宰相・軍師・提督など）。実在／伝説上の人物名のみ（Ginei 固有名は持ち込まない）。
- アーサー王時代は半伝説のため伝説上の人物・ローマ系ブリトン人で可。
