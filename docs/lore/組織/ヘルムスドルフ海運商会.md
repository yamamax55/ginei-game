# ヘルムスドルフ海運商会

> [[鉄環兵団]]の海運。大商人[[ゾフィー・ヘルムスドルフ]]が率いる。

## 概要
[[鉄環兵団]]を本拠とする**海運**。大商人の[[ゾフィー・ヘルムスドルフ]]が興した商会で、財力は**中堅**と目される。港と航路を回し、鉄環兵団の経済を裏から支える。

## 事業・経営
- 主力＝海運。財産は**投資**で運用。利潤は法人税ぶん国庫へ（私有企業）。

## 関係
