# 技術（ぎじゅつ）

> 旧[[大環状連合]]の叡智の多くは失われた。残った種火を継ぎ、新たに解禁する技術が、艦の質と国の地力を底上げする。

## 技術の樹
技術は軍事・生産・情報・社会の分野に分かれ、前提を満たすほど次が解禁される依存の樹を成す。研究を進めれば、より強い艦、より厚い生産、より鋭い諜報、より巧い統治が開ける。集約された技術水準は[[艦級|建艦]]と戦力の質に直結する。

## 研究力
技術は祈っても進まない。**研究予算×働き手の技能**（→ [[労働]]・[[名門校]]）が研究力を生み、前提を一つずつ積み上げて解禁に至る。政体の得意分野が優先され、[[黎明評議会|民主勢力]]は社会・情報に、[[鉄環兵団|軍閥]]は軍事に傾く――技術の樹の伸び方が、勢力の性格を映す。

## 失われた叡智
最先端は、いまだ旧連合の遺産に及ばない。死んだ[[灯台]]の管制技術、[[マゼラン回廊|首座灯]]の制御――それらを解き直すことは、再統一の鍵を握ることに等しい（→ [[終章 ― 鍵の行方]]）。
