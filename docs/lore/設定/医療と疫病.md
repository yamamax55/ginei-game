# 医療と疫病（いりょう・えきびょう）＝癒やしと滅びの境

> 「砲弾で死ぬ兵より、傷の膿と熱で死ぬ兵のほうが多い。戦を決めるのは、しばしば医者の数なのさ。」

## 核心（医の届く範囲が、生死と国力を分ける）
[[環暦|大解体]]で旧[[大環状連合]]の高度な医療網が砕け、医の知と薬は各地に偏在する。中央の届かぬ辺境では、傷も病も[[汚職とフィクサー|システムの末端]]同様に放置され、回廊の途絶（→ [[兵站]]）が薬を断てば疫病が燎原の火となる。医療は[[人口]]の増減と[[士気]]・[[民心]]を左右する静かな戦力であり、軍医の数と薬の備蓄は、砲門の数と同じほど会戦の帰趨を決める。

## 医のかたち（誰が癒やすか）
- **軍医と野戦医療**――会戦の傷者をどれだけ救えるかは[[兵站]]・[[練度]]に直結。医のない軍は、勝っても消耗で痩せ細る。
- **疫病という盤外の敵**――補給線の途絶、人口の密集、難民の流入が疫病を呼ぶ。疫病は[[人口]]を削り[[民心]]を崩し、[[戦争]]の帰趨すら覆す（滅びの時計＝[[兵站]]の延長）。
- **薬と利権**――希少な薬種は[[商社]]・[[汚職とフィクサー|裏経済]]の太い柱。買い占めと密売、偽薬が横行し、[[遊興|嗜好薬種]]とも地続き。
- **医の身分差**――宮廷医は貴族を、町医者は平民を診る。植民星には医すら届かぬ（→ [[身分]]・[[言語]]の宮廷語/在来語）。

## 勢力ごとの医療
- [[碧晶公国]]――宮廷医学が高度だが門閥に偏る。平民・植民星の医療は薄く、[[身分]]の壁が生死を分ける。
- [[黎明評議会]]――公衆衛生と万人への医療を理念に掲げる（→ [[黎明評議会連邦憲章|市民の権利]]）。だが辺境まで届かせる財政が常に課題（→ [[財政]]）。
- [[鉄環兵団]]――軍医優先の実利。戦力にならぬ病者は切り捨てる冷徹さ。だが腕利きの軍医は将軍並みに重んじる。
- [[自由港同位体]]――薬の交易で栄える。良薬も偽薬も流れ、医療は商品（→ [[商社]]）。
- [[灯心自由市ファロス]]――市の医院ギルドが公衆衛生を担う都市型医療。検疫で疫病を水際で止める。

## NPC・クエストへの適用指針
- **宮廷医NPC**（身分医療）――「公爵家の御典医がなぜ植民の兵を診ねばならぬ？　……礼を尽くされるなら、考えぬでもないが。」
- **野戦医NPC**（修羅場の現実）――「薬が足りねえ。あと十人は救えたんだ、補給さえ間に合えば。……戦果報告にゃ、こいつらの名は載らねえがな。」
- **クエスト分岐**：疫病/負傷で部隊が危機の場面で → (a) **正規の補給を待つ**＝届けば救えるが遅延で全滅も（→ [[兵站]]）／(b) **闇市で薬を買う**＝高額・偽薬の博打（→ [[汚職とフィクサー]]・[[遊興]]）／(c) **見捨てて進軍**＝戦力は保つが[[士気]]・[[民心]]が崩れる。
