# 財政（ざいせい）

> 国庫は戦の燃料であり、民心の人質でもある。税を取れば軍は肥え、民は痩せる――その綱引きが勢力を生かし殺す。

## 税と支持の綱引き
勢力の歳入は版図への課税から生まれる。税率を上げれば軍と建艦に金が回るが、高すぎる税は民の不満を募らせ、支持を蝕む（→ [[政体]]）。**税収↔支持**の綱引きこそ内政の核で、版図の一体化（統合度）が高いほど効率よく富を吸い上げられる。

## 歳出と予算
歳出は軍事・建艦・行政・福祉などへ配分される。限られた国庫をどこに振るかが勢力の性格を映す――[[鉄環兵団|軍閥]]は軍事に偏らせ、[[黎明評議会|民主勢力]]は福祉と教育にも割く。配分の歪みは、いずれ前線か民心のどこかに皺寄せする。

## 債務スパイラル
不足は[[金融|国債]]で埋めるが、借金が金利を呼び、金利が借金を呼ぶ悪循環に落ちれば、財政は通貨と信認を道連れに傾く（→ [[通貨]]）。健全財政と戦時拡張の両立は、あらゆる勢力の宿題である。

## ゲームデータ参照
- 課税ベースは `CampaignRules.EconomyBase`／税収は `FiscalRules.TaxRevenue`（日次 `TickEconomyDay`）。歳入歳出・国債・債務スパイラル・金利は `FiscalRules`、予算配分は `BudgetRules`（分野別 `Share`）、税構造は `TaxStructure`／再分配 `RedistributionRules`。版図一体化は `LogisticsRules.CohesionFactor`。観測＝E（経済）／Alt+F（財政詳）。
