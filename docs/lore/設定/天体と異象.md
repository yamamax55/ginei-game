# 天体と異象（てんたいといしょう）＝宙に潜む難所と畏れ

> 「回廊を外れた宙は、地図に『ここに怪物あり』とだけ書いてある。冗談だと思うか？　……戻ってきた船乗りに、聞いてみるんだな。戻ってこられりゃ、の話だが。」

## 核心（宙そのものが、航路と会戦の地形になる）
[[回廊]]という重力潮流が唯一の高速航路なら、その外には星雲・暗礁宙域・[[星系名|恒星]]・崩れた天体といった**宙の難所**が広がる。これらは[[会戦]]の地形であり、[[水先案内人]]が読むべき脅威であり、[[占いと予兆|畏れ]]の源でもある。星雲は索敵を阻み（→ [[諜報機関]]）、重力の淵は艦を呑み、漂流する旧[[大環状連合|連合]]の残骸は宝にも罠にもなる。宙の異象は、人智を超えた[[環暦|大解体]]の傷跡として、航海者の信仰と恐怖に深く刻まれている。

## 宙の難所（何が潜むか）
- **星雲と暗礁宙域**――索敵と通信を阻む濃霧の宙。伏兵に最適、遭難の罠（→ [[会戦]]の地形・[[通信と急使]]）。
- **重力の淵（崩れた天体）**――艦を呑む宙の渦。盤面の障害物として戦術を縛る（→ ブラックホール演出＝盤上の難所）。
- **漂流する連合の残骸**――旧連合の沈んだ大艦・[[灯台]]の残骸。[[義肢と人造|機巧]]や[[正史と稗史|失われた記録]]が眠る宝の島であり、亡霊の噂の源（→ [[流言]]）。
- **異象と畏れ**――説明のつかぬ宙の現象。[[信仰|故地回帰派]]は「故郷の徴」と説き、船乗りは[[占いと予兆|凶兆]]として畏れる。

## 宙が動かす物語
- **難所を使う戦術**――星雲に隠れ、重力の淵を背に布陣する。地の利が寡兵に勝機を与える（→ [[陣形]]・[[要塞|地形を扼す砦]]）。
- **遭難と漂流**――難所に呑まれた船は[[難民と漂流民|漂流船団]]に。生還の物語、亡霊船の[[流言|噂]]。
- **残骸の探索**――沈んだ連合の艦に眠る技術と財宝を巡る冒険（→ [[義肢と人造]]・[[工房と職人]]）。[[植民|探検家・開拓者]]の領分。
- **首座灯への道**――[[灯台|首座灯]]へ通じる[[マゼラン回廊|死んだ大回廊]]は、最大の異象にして物語の核（→ [[終章 ― 鍵の行方]]）。

## 勢力ごとの宙の難所
- [[碧晶公国]]――宮廷占星術が宙の異象を読み解く伝統。難所を畏れ、迂回を旨とする（→ [[占いと予兆]]）。
- [[黎明評議会]]――難所を科学で踏破しようとする。[[名門校|探査技術]]で残骸を調査（→ [[技術]]）。
- [[鉄環兵団]]――難所を戦術に使う猛者。星雲の伏兵、重力の淵を背にした死守。
- [[自由港同位体]]――[[水先案内人]]を擁し難所を抜ける航路を握る。残骸の宝も商品（→ [[商社]]）。
- [[灯心自由市ファロス]]――灯と航路の知に長け、難所の案内を生業とする（→ [[旅と宿駅]]）。

## NPC・クエストへの適用指針
- **古参の水先案内人NPC**――「この星雲の中は、地図が役に立たねえ。頼れるのは、潮の匂いと、勘だけだ。……怖いか？　怖くねえ奴は、とっくに宙の藻屑さ。」
- **残骸を漁る探検家NPC**――「沈んだ連合の旗艦が、あの淵の底にあるって噂だ。中にゃ失われた技術が眠ってる。……まあ、入った奴は誰も帰っちゃいねえがな。」（→ [[流言]]）
- **クエスト分岐**：宙の難所を越える/使う場面で → (a) **熟練の[[水先案内人]]を雇い慎重に抜ける**＝安全だが高く遅い／(b) **難所に乗じて伏兵・奇襲**＝地の利の博打（読み違えれば自滅）／(c) **残骸を探索して旧技術を狙う**＝一攫千金だが遭難と亡霊の罠。
