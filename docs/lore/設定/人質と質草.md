# 人質と質草（ひとじちとしちぐさ）＝人を担保にする縛り

> 「証文は破れる、誓いも破れる。だが、息子を預けてみろ。裏切れば、その首が落ちる――人ってのは、いちばん重くて、いちばん残酷な担保さ。」

## 核心（公権力なき世界で、人そのものが約束の担保になる）
[[信用と証文|証文]]も[[誓いと契り|誓い]]も破られ得る世界で、最も確実に約束を縛るのは**人質＝人を担保に取ること**である。[[婚姻と家門|縁組]]に名を借りた質子、[[降伏と開城|開城]]の証としての身柄、[[条約|盟約]]の保証としての交換人質――裏切れば預けた者の命が落ちる以上、血と命が約束を不可逆にする。[[環暦|大解体]]で裁定権が消えた諸侯の世界では、人質は[[外交]]と[[旗幟|忠誠]]を縛る最も生々しい手段であり、その授受・厚遇・処刑が、群像劇の非情と人情を最も鋭く描き出す。

## 人を担保にする作法（誰を、いかに預けるか）
- **質子と縁組**――有力者の子弟を相手方に預ける。[[婚姻と家門|政略結婚]]も実質は相互人質（→ [[婚姻と家門]]）。
- **降伏の証**――[[降伏と開城|開城]]の保証として差し出す身柄。約定遵守の担保（→ [[誓いと契り]]）。
- **身代金と質草**――捕えた[[捕虜と亡命|捕虜]]を金品と引き換えに返す。人が交易の質草になる（→ [[信用と証文]]・[[商社]]）。
- **人質の厚遇と処刑**――預かった人質を厚遇すれば信を、裏切られて処刑すれば恐怖を生む。預けた側の裏切りを抑止する刃（→ [[名誉と面子]]）。

## 人質が動かす物語
- **預けられた子の運命**――幼くして敵地へ送られた質子。厚遇されて育つか、政変で命を落とすか。引き裂かれる忠と情（→ [[孤児と里子]]・[[世代と継承]]）。
- **人質を盾にした駆け引き**――肉親を握られて動けぬ将。裏切りたくとも裏切れぬ縛り（→ [[旗幟]]）。
- **人質の処刑という決断**――裏切られた側が人質を斬るか赦すか。斬れば抑止力を、赦せば[[名誉と面子|度量]]を示す（→ [[罪と罰]]）。
- **身代金の交渉**――名のある[[捕虜と亡命|捕虜]]の身代金を巡る駆け引き。[[商社|仲介]]と[[諜報機関|裏交渉]]の場（→ [[降伏と開城]]）。

## 勢力ごとの人質観
- [[碧晶公国]]――質子の制度が[[婚姻と家門|家門政治]]に組み込まれ、人質の[[身分|家格]]が盟約の重みを決める（→ [[礼儀と作法]]）。
- [[黎明評議会]]――人質を前時代的とし、制度的保証（条約・登記）で代えようとする。だが有力者の縁組はなお質的（→ [[黎明評議会連邦憲章]]）。
- [[鉄環兵団]]――人質を実利の担保として扱う。裏切れば容赦なく処刑する非情が抑止力（→ [[階級]]）。
- [[自由港同位体]]――人質を身代金と[[信用と証文|証文]]で扱う商取引。最も洗練された質草の市場（→ [[商社]]）。
- [[灯心自由市ファロス]]――都市の信用を盾に、預かった人質を律儀に厚遇する（→ [[都市国家]]）。

## NPC・クエストへの適用指針
- **人質に取られた子の親NPC**（縛られる側）――「裏切りたいさ。だが、息子があの城にいる。俺が旗を変えた瞬間、あの子の首が飛ぶ。……忠義じゃねえ。これは、ただの鎖だ。」（→ [[旗幟]]）
- **質子を厚遇する領主NPC**――「預かった御子は、我が子同然に育てよう。それが、両家の盟約への誠意だ。……無論、貴公が約を違えねば、の話だがな。」（宮廷語の慇懃＝→ [[言語]]）
- **クエスト分岐**：人質を巡る局面で → (a) **正規に質子・交換人質を立てて盟約を結ぶ**＝確実だが肉親を危険に晒し縛られる／(b) **人質を見捨てて裏切る/強行する**＝自由を得るが預けた者の命と[[名誉と面子|信]]を失う博打／(c) **[[汚職とフィクサー|仲介人]]に身代金・密かな奪還を手配させる**＝高くつくが角を立てず人質を取り戻す。

## ゲームデータ参照
- 人質・質草そのものに専用機構はない（ナラティブ層）。人質は[[捕虜と亡命]]（`CaptiveStatus`／`PersonFate`／身柄の処遇）・[[婚姻と家門]]（縁組＝`PersonMarriageRules`／`HeredityRules`）・[[誓いと契り]]（盟約の担保）。縛りの効果は[[旗幟]]（`loyalty`/`intrigue`＝裏切り抑止）・[[外交]]（`DiplomacyState`＝条約の保証）。身代金は[[信用と証文]]・[[商社]]（`TradingHouse`）、処刑/厚遇の波及は[[名誉と面子]]・[[民心]]・[[罪と罰]]。
