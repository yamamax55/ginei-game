# 封土（ほうど）と叙任

> 艦隊を保有する単位＝領。提督はその艦隊を「叙任」されて指揮する。

## 封土
[[回廊]]の[[回廊|要衝]]を押さえた者が、周辺の星々を「封土」として囲い込み、自らの旗を立てた。艦隊は個人ではなく**封土（領）が保有**する。封土はその国力に応じて艦隊を保有する。

## 叙任
提督は階級に応じた規模の艦隊を「**叙任**」されて指揮する。功を立てれば**昇叙**し、より大きな艦隊を預けられる。敗れれば領は召し上げられ、提督は浪々の身となって次の主を探す（→[[旗幟]]）。

## 諸侯
封土を構える地方勢力の総称が**諸侯**。旧連合貴族・植民星の議会・交易商人・職を失った軍人など出自はさまざまで、互いに等しく「正統」を主張する（[[第一章 ― 諸侯の時代]]）。

## ゲーム実装
`FleetPool`（封土の保有艦艇）／`FleetRoster`（艦隊台帳）／階級による指揮可能規模＝`CommandCapacityRules` に対応。
