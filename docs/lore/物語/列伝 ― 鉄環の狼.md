# 列伝 ―― 鉄環の狼

> 視点：[[ヴォルフ・アッカーマン]]（[[鉄環兵団]]・鉄狼）。中核の幹との交点＝「速さ」と「読み」の衝突。

血筋がなんだ。功を立てた者が、将になる。辺境の農夫の子[[ヴォルフ・アッカーマン|ヴォルフ・アッカーマン]]は、ただ戦場の武功だけで[[鉄環兵団]]の将官まで駆け上がった。胸を飾る鉄十字は、すべて自らの剣で勝ち取ったもの。速攻と奇襲で諸侯を呑む兵団にあって、彼の突撃はいっとう速く、いっとう鋭い。

ある会戦で、鉄狼の速度が初めて空を切った。正面の敵が、退くと見せて退かず、進むと見せて進まない。掴もうとした横腹は、掴んだ先で消えている。[[回廊]]の流れそのものが、敵に味方しているかのようだった。「小細工を」と吐き捨てた瞬間、別働隊が死んだ回廊から現れ、ヴォルフの伸びきった先鋒を逆しまに刈り取った。生まれて初めて、彼は「速さ」が「読み」に負ける目を見た。

退き上げる艦橋で、ヴォルフは血の滲む唇を噛み、しかし――笑った。あの采配、[[ミレイア・セルウィン|ミレイア・セルウィン]]とかいう名もなき女の。いつか必ず、あれを上回る。誇り高く、野心は誰よりも熱い。彼の牙が狙うのは、目の前の敵だけではない。規律ある冷静さの裏に、いずれ[[鉄環兵団|兵団]]そのものを呑む牙を隠したまま、若き狼はまた前線へ駆けていく。
