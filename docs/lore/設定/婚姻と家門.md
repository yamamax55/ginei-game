# 婚姻と家門（こんいん・かもん）＝血で結ぶ同盟

> 「条約は紙きれ一枚で破れる。だが血の縁は、孫子の代まで切れない――だからこそ、最も高くつく約束なのさ。」

## 核心（血の縁が、紙の条約より固い盟約になる）
公権力の裁定が消えた世界（→ [[環暦|大解体]]）では、[[条約]]を保証する上位者がいない。ゆえに最も確かな盟約は**婚姻＝血の同盟**である。家門と家門が世継ぎを交わせば、裏切りは一族への裏切りとなり、[[名誉と面子|面子]]と血が二重に縛る。婚姻は[[外交]]の最も重い手段であり、[[旗幟|忠誠]]を血で固定し、[[諸侯|諸侯]]の勢力図を一代で塗り替える。だが世継ぎをめぐる相続争いは、同じ血ゆえに最も惨い内紛を生む。

## 血の政治（縁組が動かすもの）
- **政略結婚＝外交**――敵対を婚姻で和らげ、同盟を血で不可逆にする（→ [[外交]]・[[条約]]）。人質的な意味も帯びる。
- **相続と世継ぎ**――家門の継承は王朝の正統性（`DynastyRules`）の核。世継ぎなき家門は断絶・併合の的（→ [[政体]]）。
- **庶子と正嫡**――血筋の正統をめぐる争いは内紛の火種。[[身分]]・[[名誉と面子]]が絡み、相続戦争にすら発展。
- **身分違いの恋**――[[身分]]の壁を越える縁は禁忌であり物語の動力。門閥の娘と植民星の将――引き裂かれるか、壁を壊すか（→ [[言語]]の階級・[[黎明評議会|法の前の平等]]）。

## 勢力ごとの婚姻
- [[碧晶公国]]――家門政治の本場。婚姻が外交と権力闘争の主戦場で、血統が全てを決める（→ [[碧晶公国大憲章|門閥の特権]]・[[服飾と紋章|家門の紋]]）。
- [[黎明評議会]]――政略結婚を前時代的とし、婚姻は個人の自由。だが有力者の縁組はなお政治的影響を持つ（→ [[黎明評議会連邦憲章]]）。
- [[鉄環兵団]]――血統より功。婚姻も同盟の道具だが、世継ぎより後継指名（実力者）を重んじる（→ [[階級]]・[[政体]]）。
- [[自由港同位体]]――商家同士の縁組＝事業の合併。血の同盟は資本と販路の統合（→ [[商社]]）。
- [[灯心自由市ファロス]]――市民の婚姻は私事だが、ギルド家系の縁組は都市の勢力均衡に響く。

## NPC・クエストへの適用指針
- **家門の長NPC**（血で計算する）――「貴公の武勲は認めよう。だが我が娘を娶るには――家格が足りぬ。血は、功では購えぬのだ。」
- **政略結婚の当事者NPC**（縛られる側）――「会ったこともない相手と添う。それで二国が血を流さずに済むなら……私の心など、安いものでしょう。」
- **クエスト分岐**：縁組の打診を受けた場面で → (a) **受ける**＝強固な同盟を得るが家門に縛られ自由を失う／(b) **断る**＝独立を保つが相手の[[名誉と面子|面子]]を潰し敵に回す／(c) **[[汚職とフィクサー|仲介人]]を立てて条件を詰める**＝双方の顔を立てる金と駆け引きの和解。

## ゲームデータ参照
- 婚姻・相続そのものに専用機構はない（ナラティブ層）。血縁・継承は人物の血統（`HeredityRules`／`PersonMarriageRules`／`ChildbirthRules`／世代＝`GenerationTickRules`）・[[政体|王朝]]（`DynastyRules`＝正統性）。婚姻同盟は[[外交]]（`DiplomacyState`＝同盟/不可侵）・[[条約]]（`TreatyRules`）へ接続、相続争いは[[旗幟]]（`loyalty`/`intrigue`）・[[名誉と面子]]・[[身分]]（`SocialOriginRules`）。
