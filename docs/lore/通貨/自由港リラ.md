# 自由港リラ

> どの旗の下でも通用する、交易の血。

## 概要
[[自由港同位体]]が発行する交易の基軸通貨。武装中立を貫く商業ギルド連合の信用に支えられ、勢力の別なく広く受け取られる「銀河の決済通貨」。祖国はなくとも、帳簿はどこでも通じる。

## 価値の裏付け
- 銀本位かつギルドの信用。`silverContent` と `publicTrust` の双方が高く、中立ゆえ誰からも信頼される。

## 為替・物価
- 為替は安定（基軸通貨）。流量の多い[[回廊]]交易が需要を支え、物価も安定。戦乱でも避難先通貨として買われる。

## 発行と政策
- ギルド連合の発券銀行が慎重に発行。準備率を厚く保ち、信認を何より優先する（増発を嫌う規律）。

## 関係
- 発行勢力：[[自由港同位体]]
- 発行体：商業ギルド連合の発券銀行
