# 競技と武芸（きょうぎとぶげい）＝血を流さず腕を競う

> 「真剣勝負は一度きり、死ねば終わりだ。だが試合なら、何度でも腕を磨ける。……まあ、たまに本気で殺し合う阿呆もいるがな。」

## 核心（平時の腕試しが、武人の格と娯楽を形づくる）
戦のない時、武人は**競技と武芸**で腕を磨き、格を競う。御前試合、闘技、模擬艦隊戦、各種の技比べ――これらは[[練度|鍛錬]]の場であると同時に、[[名誉と面子|格]]を懸けた[[遊興|興行]]であり、[[民心|民衆]]の熱狂する娯楽でもある。勝者は名声と[[勲章|栄誉]]を、敗者は雪辱を期す。競技は[[名と諱|異名]]を生み、[[賭博|賭け]]を呼び、政治の駆け引きの舞台にもなる。血を流さずに優劣を示すこの場は、武の文化が最も華やぐ瞬間である。

## 競技の諸相（何を競うか）
- **御前試合と武芸大会**――君主の前で腕を競う栄誉の場。勝者は引き立てられ、出世の好機（→ [[階級]]・[[親征|君主の臨席]]）。
- **模擬艦隊戦**――実戦さながらの演習。[[練度]]を高め[[陣形]]を試す軍事訓練にして見世物。
- **闘技と見世物**――民衆向けの興行。[[遊興|賭け]]と八百長が絡み、[[俠気と無頼|顔役]]が仕切る（→ [[音楽と芸能]]）。
- **技比べ**――武芸に限らず、[[水先案内人|操船]]・射撃・[[工房と職人|技]]の競い。各分野の腕自慢の祭典（→ [[祝祭]]）。

## 競技が動かすもの
- **格と出世**――試合の勝敗が武人の[[名誉と面子|面子]]と[[名と諱|異名]]を決める。御前試合の勝利は抜擢の道（→ [[身分]]の壁を越える稀路）。
- **代理戦争**――勢力間の威信を、戦の代わりに競技でぶつける。負ければ[[外交|外交]]的失点（→ [[名誉と面子]]）。
- **賭けと興行の経済**――闘技場は[[遊興|賭博]]と[[流言|噂]]の渦。八百長と借金が物語を生む。
- **私闘への転化**――試合の遺恨が真剣の[[名誉と面子|決闘]]に発展する危うさ（→ [[罪と罰]]）。

## 勢力ごとの競技
- [[碧晶公国]]――宮廷の華麗な御前試合と馬上槍。[[身分]]ある者の格式高い武芸（→ [[服飾と紋章]]）。
- [[黎明評議会]]――万人に開かれた競技会。出自を問わぬ実力の祭典で、市民が熱狂（→ [[黎明評議会連邦憲章]]）。
- [[鉄環兵団]]――実戦的な武芸大会こそ序列の試金石。勝者がそのまま昇進する苛烈な腕試し（→ [[階級]]）。
- [[自由港同位体]]――闘技興行で稼ぐ。賭けの胴元と八百長が渦巻く商売の場（→ [[商社]]・[[遊興]]）。
- [[灯心自由市ファロス]]――市の祝祭に競技を組み込み、ギルド対抗の技比べで賑わう（→ [[工房と職人]]）。

## NPC・クエストへの適用指針
- **武芸者NPC**（腕に生きる）――「御前試合で勝てば、殿のお目に留まる。植民星の出の俺が成り上がるにゃ、これしか道はねえ。一発、賭けてみるさ。」（→ [[身分]]）
- **闘技場の胴元NPC**――「次の試合、どっちに賭ける？　……ああ、結果が知りてえか？　なら、もう少し色をつけてくれりゃ、いい話も聞かせられるぜ。」（→ [[遊興]]の八百長）
- **クエスト分岐**：競技で名を上げたい/勝たせたい場面で → (a) **正々堂々と腕で勝つ**＝名声は本物だが実力次第の博打／(b) **八百長・賭けで操作**＝確実だが露見で[[名誉と面子|面子]]失墜（→ [[俠気と無頼]]）／(c) **[[汚職とフィクサー|裏で]]組み合わせや審判を動かす**＝高くつくが勝ちを買える。
