# 条約（じょうやく）

> 紙に書かれた約束。だが守るも破るも勢力次第――条約の信頼は、積み重ねた誠実でしか担保されない。

## 条約の種類
- **同盟**――共に戦う盟約。理念で結ぶ（[[黎明評議会]]）か、損得で結ぶ（[[自由港同位体]]）かで強度が違う。
- **不可侵**――矛を向けぬ約束。多極の牽制の主役で、中立勢力が広く張りめぐらす。
- **通商・通行**――交易と[[回廊]]通過の取り決め。商業国家の生命線。
- **属国（保護国）**――一方が他方の保護下に入る。[[黎明評議会連邦憲章|自治の理念]]からは結ばれない型。

## 約束を守る勢力・破る勢力
条約は破られうる。隙を見て同盟を裏切る者、機を見て不可侵を反故にする者――だが破棄は**誓約の信頼**を損ね、以後の外交コストとして長く尾を引く。誠実を積む勢力は安く同盟を組め、裏切りを重ねる勢力は誰にも信じられなくなる（→ [[旗幟]]）。

## ゲームデータ参照
- 締結中条約の台帳は `ActiveTreaty`/`TreatyLedger`/`TreatyManagementRules`（`Sign`／`ExpireDue`＝失効で平時へ）。opinion 効果は `TreatyRules`、外交状態への写像は `DiplomacyRules`。破棄の信頼減衰は `TreatyCredibilityRules`。属国は `ProtectorateRules`。観測＝Y（外交）。
