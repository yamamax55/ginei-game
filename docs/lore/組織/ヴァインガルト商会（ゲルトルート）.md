# ヴァインガルト商会

> [[碧晶公国]]の総合商社・交易。商会主[[ゲルトルート・ヴァインガルト]]が率いる。

## 概要
[[碧晶公国]]を本拠とする**総合商社・交易**。商会主の[[ゲルトルート・ヴァインガルト]]が興した商会で、財力は**新興**と目される。交易と相場で身代を回し、碧晶公国の経済を裏から支える。

## 事業・経営
- 主力＝総合商社・交易。財産は**投資**で運用。利潤は法人税ぶん国庫へ（私有企業）。
