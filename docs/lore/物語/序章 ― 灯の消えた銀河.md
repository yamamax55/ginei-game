# 序章 ―― 灯の消えた銀河

かつて銀河には、一千年にわたって星々を一つに束ねた超国家があった。人々はそれを「[[大環状連合]]（グレート・コンコルド）」と呼んだ。連合の力の源は、武力でも血統でもなく、恒星間を結ぶ自然の重力潮流――「[[回廊]]（コリドー）」を完全に管制する技術にあった。回廊は宇宙に走る見えざる河であり、そこを通るときだけ船は星から星へと安全に渡れる。逆らえば船は潮にもまれて散り、二度と戻らない。その流れを読み、束ね、誰にどの航路を、いつ開くかを差配したのが、連合の各所に建てられた管制中枢〈[[灯台]]（ラントゥル）〉であった。

灯台が灯っているかぎり、銀河は一つだった。交易は滞りなく流れ、辺境の植民星にも食糧と医薬が届き、艦隊はひと月で銀河を横断した。富は中心から末端まで巡り、人々は飢えと隔絶の恐怖を忘れた。やがて戦争の作法そのものが過去の遺物となり、提督という官職は、観艦式で礼砲を撃つためだけの儀礼の飾りに成り果てていた。連合の繁栄は永遠だと、誰もが信じて疑わなかった。

破局は、一夜にして訪れたわけではない。連合の中央では数世代にわたって統治の弛緩が進み、灯台の維持を担う技術者の系譜は痩せ細っていた。回廊を読む秘伝は世襲の家に囲い込まれ、やがて家ごと衰え、誰も全体を把握できなくなっていた。そしてある年――後に[[環暦|環暦元年（CE1）]]と数えられる年――銀河の中心に据えられた最大の灯台〈[[灯台|首座灯]]（だいいちとう）〉が、原因不明の停止に陥る。連鎖するように各地の灯台が次々と沈黙し、回廊の管制は失われた。河はなお流れていた。だが、もはや誰もその全貌を読めなくなった。

航路を失った星系は、たちまち孤立した。隣の星まで安全に渡る術を失い、補給は途絶え、交易は凍りついた。豊かだった工業星は資源の輸入が止まって機能を停め、人口を養えなくなった農業星では暴動が起きた。中央から派遣されていた総督たちは本国の指令を受け取れなくなり、各地の艦隊は宙に浮いた。命令を待つうちに兵糧は尽き、提督たちは否応なく自らの判断で動かざるをえなくなる。秩序は、中心から外へと崩れていった。

最初の数年は、ただ生き延びることがすべてだった。生きた回廊を一本でも握る星系は、孤立した近隣の星から逃れてきた難民と、職を失った軍人と、行き場のない船を吸い寄せた。やがて、それらを束ねて新たな秩序を打ち立てる者が現れる。ある者は民を飢えから救う恩人として、ある者は力で従える征服者として。連合という大樹が倒れた跡地に、無数の若木が我先にと枝を伸ばしはじめたのだ。後の世の年代記は、この混沌の十年を「大解体」と呼ぶことになる。
