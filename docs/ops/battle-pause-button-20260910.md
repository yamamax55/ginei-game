# 戦術画面の停止／再開ボタン
Task: battle-pause-button-20260910

ユーザー承認：戦術画面に一時停止/再開ボタンを目立たないように配置する。
Unity Play OFFをChatGPTが確認済み。プログラム実装はClaude Code。

## 確定仕様
- 戦術画面の上端、既存の時間表示付近に小さな「停止」／「再開」ボタン。濃い半透明背景、落ち着いた文字色、ホバー時だけ少し強調。文字は読め、クリック範囲は小さすぎない（目安96x28）。艦隊HUD・戦況バー・操作対象に重ねない。
- 実行中は「停止」、一時停止中は「再開」。Spaceと同じPauseManagerの状態・TogglePause/Resumeへ接続し、Time.timeScale直操作の別経路は作らない。
- 再開時は直前の速度を保持。停止中も通常のアクティブポーズ命令が可能。Space/メニューからの状態変更もボタン表示に同期。
- モーダル・艦隊詳細・編制画面の停止維持は既存仕様を守り、ボタンがその上から解除しない。
- ボタンクリックは盤面の選択/移動命令へ透過させない。二重生成・リスナー重複・再入場時の残留を防ぐ。既存の巨大なPAUSE表示がボタンを隠さない。
- ブラウザ版、特殊な画面比率別版は不要。既存セーブと無関係な変更を保護。commit/push不要。

## 検証・引き継ぎ
コンパイルと必要な確認後に編集停止し、変更箇所とUnityでの確認手順を報告。ChatGPTがクリックで停止→再開→停止、時刻/移動の変化、支援要請の返事・実移動を検証する。実機未確認を合格扱いしない。
