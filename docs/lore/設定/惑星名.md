# 惑星名（わくせいめい）

> 星系の惑星には、失われた故郷の**古き神話の神々**の名を冠する。日本神話に由来する命名体系。

## 概要
星系を構成する惑星には、人類が散らばる以前の故地――**揺籃の星々（旧き故郷）に伝わる古い神話**の神々や神話的存在の名が与えられる。〈アマテラス〉〈スサノオ〉〈オオクニヌシ〉〈イザナギ〉〈ツクヨミ〉――いずれも、もはや誰も帰り着けぬ遠い故郷で語り継がれた、創世と自然の神々の名だ。

[[旗艦]]が故郷の**世界遺産・自然遺産**（土地の名）を継ぐのに対し、惑星は故郷の**神話**（神々の名）を継ぐ。大拓殖の時代、新たに人の住まう天体が見いだされるたび、開拓者たちは故郷の神話から名を採って星に冠した――足下の土を踏みしめ、空を仰ぎ、そこに故郷の神を見いだそうとするように。命名の体系は**日本神話**に基づく。

## 命名の作法
- **神話由来**：惑星名は日本神話の神名・神話的存在のプール（約50）から採られる。
- **星系内で重複なし**：ひとつの星系の中では、惑星ごとに異なる神の名が宿る（第一惑星・第二惑星…と軌道順に割り当て）。
- **決定論**：同じ星系の同じ軌道なら、いつ見ても必ず同じ名。星系が違えば名の並びもずれ、別の神々が住まう。
- **星系名との別**：[[回廊|要衝]]として語られる「星系」の呼称と、その星系に属する個々の「惑星」の神話名は別物。会戦や封土の話題で出る地名の多くは星系名、星の地表（攻城・内政）で現れるのが惑星名。

## ゲーム実装との対応
> ※名簿・割当の正は Core 側。ここは「どの実装に乗るか」の見取り図。

| 設定 | 実装 |
|---|---|
| 日本神話の神名プール（約50・重複なし） | `MythicPlanetNames.Names`（差し替えれば命名体系ごと変わる単一の源） |
| 星系×軌道から決定論で払い出し | `MythicPlanetNames.For(systemId, orbitIndex)`（星系ごとに開始オフセットを散らす） |
| 星系内は軌道順に重複しない | `For` の `orbitIndex` 連番（プール件数＞惑星数が前提） |
| i 番目の名（巡回） | `MythicPlanetNames.At(i)` |
| 惑星の器 | `Planet`／`StarSystem`（軌道に並ぶ惑星） |
