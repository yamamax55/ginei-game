# 労働（ろうどう）

> 人が働き、所得を得て、消費し、暮らしが立つ。この地味な循環の健やかさが、勢力の体力そのものである。

## 働く人々
[[人口]]は職業に分かれて働く――農・工・商・官・軍。職業構成と就業率が、産出と税源と徴募源を決める。働き手の**技能**が高いほど生産は厚く、研究も進む（→ [[名門校|教育]]が技能を育てる）。

## 暮らしの循環
労働は所得を生み、所得は消費を生み、消費が暮らしを立てる。この循環が回れば**生活水準**が上がり[[民心]]が安定するが、賃金が痩せ食が不足すれば**飢餓**が忍び寄り、不満と移住（→ [[人口]]）を招く。戦争で[[回廊|交易路]]が断たれれば、まず賃金と食卓が痩せる（→ [[食]]・[[兵站]]）。

## 勢力ごとの労働
[[自由港同位体]]は商と海運に人が厚く、[[黎明評議会]]は植民の労に支えられ、[[碧晶公国]]は身分が職を縛る（→ [[身分]]）。働き手をどう活かすかが、地力の差となって表れる。

## ゲームデータ参照
- 職業構成は `OccupationRules`（農工商官軍）、労働技能・賃金・生活水準・飢餓は `PopLaborTickRules`（`OverallSkill`／`Province.wageIndex`／`livingStandard`／`foodShortage`＝年次）。消費財需要は `ConsumerDemandRules`（→ [[食]]）。観測＝X（労働）。集約は勢力×惑星（個体に降りない）。
