# 第三章 ―― 四つの大義

[[ミレイア・セルウィン|ミレイア]]と[[アウレリア・ファルケンハイト|アウレリア]]が頭角を現すころ、銀河の無数の勢力は、大きく四つの極へと収斂しつつあった。

ひとつは、旧連合貴族の末裔が束ねる、秩序の再建者たち（→[[碧晶公国]]）。太陽神の名を負う公都〈[[惑星名|アマテラス]]〉（[[星系名|エベレスト]]星系）に宮廷を構え、「失われた統一を、正統なる権威のもとに取り戻すのだ」と説く。由緒ある艦隊の伝統と、圧倒的な物量、そして重厚で崩れぬ布陣で版図を広げた。その秩序は美しく、そして冷たい。血統を持たぬ者に、彼らの世界での出世はない。

ひとつは、交易こそが銀河を生かす血であると信じる、商人たちの連合（→[[自由港同位体]]）。海神の名を負う自由港〈[[惑星名|ワタツミ]]〉（[[星系名|モンブラン]]星系）を中枢に、どの大義にも与せず武装中立を掲げ、[[回廊|生きた回廊]]の通行料で莫大な富を蓄え、神出鬼没の機動艦隊で利権を守った。彼らに祖国はない。あるのは損得の帳簿だけだ。だが、その帳簿こそが、飢えた星々に食糧を運ぶ唯一の命綱でもあった。

ひとつは、植民星の民が選んだ議会の連邦（→[[黎明評議会]]）――ミレイアとアウレリアの故郷。国造りの神の名を負う議事府〈[[惑星名|オオクニヌシ]]〉（[[星系名|アコンカグア]]星系）に民選の代表が集い、「支配ではなく自治を、血統ではなく合意を」と唱える。寄せ集めで足並みの揃わぬ艦隊を、巧みな連携と土地勘で操り、強大な敵に幾度も土をつけた。理想は高い。だが合議は遅く、内輪の対立は絶えず、決断の遅れが幾人もの将を死なせた。

そして最後に、連合崩壊の混乱からのし上がった、傭兵あがりの軍閥（→[[鉄環兵団]]）。暴風の戦神の名を負う本営〈[[惑星名|スサノオ]]〉（[[星系名|マッターホルン]]星系）から、血統も理念も持たず、ただ実力のみを是とし、速攻と奇襲で諸侯を次々と呑み込んでいった。彼らの下では、功さえ立てれば誰でも将になれる。だが、敗れた将に明日はない。

四つの極は、互いに同盟を結んでは裏切り、要衝を奪っては奪い返した。どの大義にも理があり、どの大義にも拭えぬ瑕（きず）があった。秩序の再建者は安定をもたらすが、自由を圧する。交易の徒は富を巡らせるが、義を持たぬ。議会の連邦は理想を掲げるが、決断が遅い。軍閥は澱んだ序列を破壊するが、力こそ正義の世を招く。正義はどこにもなく、また、どこにでもあった。

四つの極のはざまには、いずれにも呑まれまいとする無数の[[都市国家]]（自由市）が、なお灯をともしていた。版図を持たず、港と信用と武装中立だけを盾に、四囲の大義を天秤にかけて独立を保つ星都たち――月神の名を負う〈[[惑星名|ツクヨミ]]〉の港、[[灯心自由市ファロス]]もそのひとつだ。それは、どの大義にも与しない者が身を寄せる足場であり、第五の旗を掲げる者の最初の拠りどころでもあった。

この渦のただ中で、二人の友は繰り返し選択を迫られる。母国たる議会の理想に殉じるのか。より大きな禄や大義を掲げる極へ与するのか。諸侯のあいだを巧みに渡り歩き、自由市の盾として独立を保つのか。それとも――いずれにも与せず、自ら第五の旗を高く掲げるのか。元貴族のアウレリアにとって、旧き身分の世界たる[[碧晶公国]]は、ことに鋭い問いとなった。選んだ道によって、味方は敵となり、昨日の敵は手を結ぶ相手となる。一人の提督の去就（→[[旗幟]]）が、星域ひとつの勢力図を塗り替える。盤上には、定まった結末などない。どの旗を掲げるかは、その手綱を握る者が決める。
