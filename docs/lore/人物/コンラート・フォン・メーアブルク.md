# コンラート・フォン・メーアブルク（Konrad von Meerburg）

> 鷲の徽章を戴く、碧海の守将。「秩序とは、美しくあらねばならぬ」――[[碧晶公国]]の理想と冷たさを、そのまま体現する男。

## 概要
[[碧晶公国]]の名門メーアブルク家に生まれた貴族士官。31歳・大佐。由緒ある艦隊の伝統を重んじ、重厚で崩れぬ布陣をもって守勢を完璧に固める「碧海の守将」。功を焦らず、規律と格式を何より尊ぶ。血統を持たぬ者を見下しはしないが、彼らが己の世界の作法を解さぬことを、静かに憐れんでいる。

## 容姿
短く整えた栗色の髪に、落ち着いた琥珀色の瞳。鷲と錨をあしらった金の徽章を戴く白の制帽と、紺地に金の装飾を施した正装の士官服を、一分の隙もなく着こなす。表情は終始おだやかで、声を荒げることはない。その静けさが、かえって近寄りがたい格を生む。

## 来歴
- 旧連合以来の海軍貴族メーアブルク家の嫡子として生まれ、公国の士官学校を優秀な成績で修める。
- 由緒と規律を重んじる気風のなか、若くして守勢の名手として頭角を現し、大佐に列する。
- 同じ貴族の世界に生まれながら、家名から「フォン」を外して[[黎明評議会]]へ奔った[[アウレリア・ファルケンハイト]]を、かつて知る。彼女の選択を「裏切り」と断じきれぬまま、戦場で相対する日を予感している。

## 性格・信条
- 沈着冷静。声を荒げず、盤面を一手ずつ確実に詰める。守ってこそ攻めが生きる、という信念。
- 規律・格式・名誉を重んじる。私心や功名のために兵を損なうことを最も嫌う（功名心は高くない）。
- 血統の秩序を信じるが、暴君ではない。徳をもって兵を遇し、敗者にも礼を尽くす――それゆえ[[碧晶公国]]の「美しく冷たい秩序」の、最も良き面を体現する。

## 関係
- 所属：[[碧晶公国]]（首都〈[[惑星名|アマテラス]]〉）
- 因縁：[[アウレリア・ファルケンハイト]]（PER-002）――貴族の世界に留まった者と、捨てた者。対の選択。
- 対する者：[[ミレイア・セルウィン]]（PER-001）――読みと機動の知将。守将コンラートにとって最も厄介な相手。

## 物語上の役割
[[碧晶公国]]という大義――秩序と正統――の、最も誠実な代弁者。善悪ではなく「理ある敵」として主人公たちの前に立ちはだかる。とりわけ、貴族の身分を捨てたアウレリアにとって、彼は「もし留まっていたら自分はどうなっていたか」を映す鏡であり、剣を交える相手であり、否定しきれぬ過去そのものでもある。
