# 碧晶公国（へきしょうこうこく）

> 旧連合貴族の世襲公領。秩序の再建者。

## 概要
[[大環状連合]]の貴族の末裔が束ねる、秩序の再建者たち。「失われた統一を、正統なる権威のもとに取り戻すのだ」と説き、由緒ある艦隊の伝統と、圧倒的な物量、そして重厚で崩れぬ布陣で版図を広げる。

## 大義と瑕
- **理**：安定と秩序をもたらす。
- **瑕**：その秩序は美しく、そして冷たい。血統を持たぬ者に、彼らの世界での出世はない（自由を圧する）。

## 戦術
重厚・物量・正面決戦。推奨陣形＝方陣／円陣（堅く崩れぬ布陣）。
