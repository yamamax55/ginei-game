# 工房と職人（こうぼう・しょくにん）＝手が伝える技

> 「設計図だけありゃ船が造れると思ってる連中は、船を造ったことがねえのさ。技ってのは、親方の手から弟子の手へ、汗で伝わるもんだ。」

## 核心（失われた大技術を、手仕事が細々と繋ぐ）
旧[[大環状連合]]の高度な工業は[[環暦|大解体]]で大半が失われ、[[技術]]の多くは図面でなく**職人の手と勘**に宿って細々と受け継がれた。艦の建造（→ [[建艦]]）、武具、精密機器――それらは親方から徒弟へ、長い年季を経て伝わる。工房とギルドは[[生産]]の現場であると同時に、技を独占し[[身分|職分]]を世襲する閉じた社会でもある。腕利きの職人は将軍に劣らぬ富と敬意を集め、その引き抜きや離反は一国の技術力を左右する。

## 手仕事の世界（技は誰のものか）
- **親方と徒弟**――技は年季奉公で伝わる。徒弟は無給同然で働き、一人前になって初めて報われる（→ [[労働]]・[[徴税と賦役|賦役]]に近い従属）。
- **ギルドの独占**――工房は同業ギルドを組み、技と価格を統制。新参を阻み、秘伝を守る（→ [[名誉と面子]]の職人の誇り）。
- **名工という資産**――稀代の職人は[[建艦|名艦]]や名器を生む国宝級の存在。引き抜き・庇護・拉致の的（→ [[捕虜と亡命]]・[[諜報機関]]）。
- **失われた技の探索**――旧連合の超技術を再現できる職人や図面は垂涎の的。[[正史と稗史|秘伝]]と[[流言]]が絡む宝探し。

## 勢力ごとの工房
- [[碧晶公国]]――宮廷工房が最高の名工を抱える。御用達ギルドは特権を持ち、技は門閥の威信を飾る（→ [[服飾と紋章]]・[[身分]]）。
- [[黎明評議会]]――ギルドの独占を緩め、技術の公開と職業教育を進める（→ [[名門校]]の技術者養成・[[黎明評議会連邦憲章]]）。
- [[鉄環兵団]]――軍需工房に特化。武具と艦の量産を急ぎ、装飾より実用（→ [[建艦]]の軍産）。
- [[自由港同位体]]――各地の名工と技を買い集める交易の技術ハブ。技も商品（→ [[商社]]）。
- [[灯心自由市ファロス]]――ギルド都市。職人組合が市政を担い、徽章が腕の証（→ [[服飾と紋章|ギルド徽章]]）。

## NPC・クエストへの適用指針
- **頑固な親方NPC**（手の誇り）――「図面寄越せだと？　笑わせる。この技は俺の手の中にしかねえ。欲しけりゃ、十年弟子入りするんだな。」
- **引き抜かれる名工NPC**――「公領は俺を飾りにしか使わねえ。あんたが本当に俺の船を必要としてるってんなら……話を聞こうじゃないか。」
- **クエスト分岐**：名工の技が欲しい場面で → (a) **正規に雇う/弟子入り**＝時間と礼を尽くせば確実だが遅い／(b) **引き抜く/拉致する**＝速いが[[名誉と面子|義理]]を欠き恨みと報復を招く（→ [[捕虜と亡命]]）／(c) **[[汚職とフィクサー|仲介人]]に庇護ごと斡旋させる**＝高くつくが角が立たない。
