# 科学者・技術者 ― 著名人物録
> Ginei 人物の archetype 参照用の人物プール（**非軍事の職能＝科学者・技術者・発明家**）。武将中心の各時代ページ・[[商人・経営者]]（豪商/財閥）に対し、本ページは古代〜現代の**自然哲学者・数学者・科学者・技師・発明家**を集約する。
> [[人物/_技術者テンプレート|技術者テンプレート]]の `archetype:`（研究/工学/企画/生産）が主にここを参照する。実在の人物名のみ（Ginei 固有名は持ち込まない）。
