# 個人武装と白兵（こじんぶそうとはくへい）＝艦を離れた手の中の戦い

> 「艦隊戦は宙の華さ。だが艦が横付けされて、甲板で刃を交える段になりゃ、頼れるのは自分の手だけだ。誉れの佩剣も、現場の鉈も、突き立てりゃ同じ赤が出る。」

## 核心（艦隊の盤面の外で、個人の武装が生死を分ける）
[[会戦]]の主役は艦隊だが、その隙間には**個人の武装と白兵戦**の世界がある。接舷しての斬り込み、要塞内の通路戦、暗殺と護身、[[競技と武芸|決闘]]――艦の砲門が届かぬ間合いでは、佩剣・短銃・鉈が生死を分ける。個人武装は[[身分]]と[[名誉と面子|格]]の象徴でもあり、貴族の優美な佩剣（宮廷語「[[名と諱|宝剣]]」）と、労働者の無骨な得物（在来語「叩き斧」）は、同じ刃でありながら別の名で呼ばれる（→ [[言語]]の二重構造）。腕の白兵は[[練度]]と[[競技と武芸|武芸]]の結晶であり、乱世の個人の生存術である。

## 手の中の戦い（何が間合いを制すか）
- **接舷と斬り込み**――艦を横付けし甲板へ斬り込む白兵。[[会戦]]の決着をつける最後の間合い（→ [[要塞|通路戦]]）。
- **佩剣と短銃**――携行武装。格式の佩剣（[[服飾と紋章|礼装の一部]]）と実用の短銃。武装の格が[[身分]]を示す（→ [[名誉と面子]]）。
- **護身と暗殺**――要人の警護と、闇に潜む刺客。[[諜報機関|暗殺]]・[[俠気と無頼|用心棒]]の領分。
- **武具の格差**――名工の業物（→ [[工房と職人]]）と粗末な得物。[[鉱と採掘|鋼]]の質と職人の技が刃を分ける。

## 白兵が動かす物語
- **決闘の作法**――[[名誉と面子|面子]]を懸けた一対一。佩剣を交える儀礼と死（→ [[競技と武芸]]・[[礼儀と作法]]）。
- **斬り込み隊の武勇**――接舷戦の英雄。艦隊の質を超えて勝敗を覆す白兵の達人（→ [[練度]]・[[語録]]）。
- **暗殺と護衛の影**――要人を狙う刺客と、それを阻む護衛。[[誓いと契り|忠誠]]の試される現場（→ [[諜報機関]]）。
- **武装解除という屈服**――佩剣を取り上げることは[[名誉と面子|誇り]]を奪うこと。降伏と捕囚の象徴（→ [[捕虜と亡命]]）。

## 勢力ごとの個人武装
- [[碧晶公国]]――格式ある佩剣文化。貴族の宝剣は家門の誇りで、白兵にも作法と美が求められる（→ [[服飾と紋章]]・[[名と諱]]）。
- [[黎明評議会]]――実用本位の市民武装。華美を排し、護身と接舷の実技を重んじる（→ [[黎明評議会連邦憲章]]）。
- [[鉄環兵団]]――白兵こそ真骨頂。叩き上げの斬り込みと近接戦が軍閥の強みで、武勇が序列を決める（→ [[階級]]・[[練度]]）。
- [[自由港同位体]]――護身と用心棒の文化。商人も[[俠気と無頼|顔役]]も携行武装を欠かさぬ物騒な港（→ [[遊興]]）。
- [[灯心自由市ファロス]]――市民兵とギルドの護衛。[[工房と職人|武具職人]]の業物を産む都市（→ [[都市国家]]）。

## NPC・クエストへの適用指針
- **斬り込み隊長NPC**（白兵の達人）――「艦砲がどうの陣形がどうのと、上は言うがな。最後に甲板で物を言うのは、この一振りだ。砲弾は外せても、間合いに入った刃は外せねえ。」
- **佩剣を誇る貴族NPC**――「この宝剣は、曾祖父が叙任の折に賜ったものだ。貴公ごとき成り上がりの鉈とは、格が違う。……抜くか？　なら、作法に則ってもらおう。」（→ [[名誉と面子]]・[[言語]]）
- **クエスト分岐**：白兵・武装が要る局面で → (a) **正規に名工へ業物を誂える/腕を磨く**＝確実だが時間と[[財政|金]]（→ [[工房と職人]]・[[競技と武芸]]）／(b) **粗末な得物で力押し**＝速いが腕と運次第の博打／(c) **[[汚職とフィクサー|闇市]]で禁制の武装や凄腕の用心棒を雇う**＝高くつくが即戦力（→ [[俠気と無頼]]）。
