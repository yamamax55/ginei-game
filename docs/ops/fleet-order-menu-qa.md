# 艦隊メニューへの移動命令集約 ＋ 戦略MAPの移動表示 QA 手順

対象：通常PC の Unity 版のみ。Windows 出力は **v6**（`Ginei-Strategy-Map-v6/Ginei.exe`）。**v5 は上書きしない**。
役割：実機操作・GitHub 更新は ChatGPT。プログラムは Claude。
前提：**既存セーブは変更しない**。

**変更の要点**
- 戦略的な移動命令の入口は **艦隊メニュー**（上段「艦隊」ボタン／盤面の右クリック／Alt+A）に一本化。
- **戦略MAPの右クリックでは移動しない**（艦隊メニューが開くだけ）。選択・詳細・カメラ操作は従来どおり。
- MAP は移動中の艦隊について「どこからどこへ／どちら向きに／どういう状態か」を表示する。
- **戦術マップ（Battle シーン）の艦艇操作は一切変更していない。**

---

## A. 旧導線が無効になっている

1. 戦略マップで自軍の艦隊を左クリックして選択する。**期待**：従来どおり選択される。
2. 別の星系を**右クリック**する。
3. **期待**：**艦隊は動かない**。代わりに艦隊メニューが開く。
4. 回廊の線の上を右クリックする。**期待**：回廊上での停止保持も発令されない。
5. 敵艦隊の上を右クリックする。**期待**：自軍の選択が敵艦隊に置き換わらない（敵は選択対象にしない）。
6. カメラ操作（ホイールのズーム、左ドラッグ、中ボタンドラッグ、WASD、F、全体ボタン）が従来どおり効く。
7. 星系のダブルクリック（システムビュー）、交戦回廊のダブルクリック（潜行）が従来どおり効く。

---

## B. 艦隊メニューから移動を出す

1. 上段の **「艦隊」** ボタンを押す（盤面の空きを右クリックでも開く）。
   **期待**：MAP の左上に「艦隊メニュー（移動命令）」が開く。ディマーは掛からず盤面は見えたまま。
2. **期待**：自軍の艦隊が一覧に出る。各行に艦隊名・**艦艇数（隻）**・状態・現在地→行先が出ている。
   規模の欄は艦艇数だけで「兵力」は出さない。桁が省略記号で落ちていないこと。
   要塞に駐留している艦隊は状態が `駐留 (要塞名)` になる。
3. **期待**：**敵軍の艦隊は一覧に出ない**。
4. 行を押して1隊を選ぶ。**期待**：MAP 上でもその艦隊が選択表示になる。
5. **「② 移動」** を押す。**期待**：③に目的星系の一覧が出る。**MAP をクリックしなくても選べる**。
   絞り込み欄に星系名の一部を入れると一覧が絞られ、消すと全件に戻る（日本語が豆腐にならないこと）。
6. 目的星系の行に、星系名・所有勢力・ホップ数・発令できない場合の理由が出ている。
7. 到達できる星系（緑の「発令できます」）を選び **「この星系へ移動」** を押す。
8. **期待**：最下段に「〇〇へ n 隊に発令」と出て、通知に `第n艦隊に ○○ への移動を命じました`。
   MAP でその艦隊が動き出し、①の状態が「移動中」、行先欄が「A → B」に変わる。
9. メニューを閉じずに続けて別の艦隊にも命令できる。

### B-2. 複数選択
1. ①の行をクリックしてトグル選択する（青くハイライト）。複数隊を選ぶ。
   **期待**：上段に「選択中 n 隊」と出て、MAP 上でも同じ艦隊が選択表示になる。
2. 目的星系を選んで実行する。**期待**：選んだ艦隊がすべて同じ目的地へ向かう。

## C. 出せない理由が表示される

1. 敵軍の艦隊は一覧に出ないことを確認する（＝発令不可）。
2. **交戦中**の自軍艦隊を選ぶ。**期待**：理由に「交戦中」が出て発令できない。
3. **増援航行中**（#38 で派遣済み）の艦隊を選ぶ。**期待**：理由に「増援航行中」が出て発令できない。
4. 回廊で繋がっていない星系の行を見る。**期待**：灰色で押せず「そこへ至る経路がありません」。
5. 現在地と同じ星系の行を見る。**期待**：灰色で押せず「すでにその星系に停泊しています」。
6. **敵の要塞に封鎖された先**の星系を選ぶ（迂回路が無い状況）。
   **期待**：**黄色の警告**で表示されるが**押せて発令できる**（行って制圧するのは正当な選択のため）。
   実行すると通知に理由が併記される。

## D. MAP の移動表示

1. 数隊を別々の目的地へ動かす。
2. **期待**：移動中の各艦隊について、**出発星系から目的星系までの線**が引かれる。
3. **期待**：進行方向に**矢じり**が出て、どちら向きに動いているか分かる。
4. **期待**：線のそばに「出発星系 → 目的星系」と**状態**（移動中／停泊中／交戦中／要塞に足止め／増援航行中）が出る。
5. **複数ホップ**の移動を出す（遠くの星系を目的地にする）。
   **期待**：いま渡っている区間と、その先の最終目的地までが繋がって描かれ、ラベルに経由数が出る。
6. 到着させる。**期待**：到着した艦隊の線と矢じりが消える。
7. 途中で別の目的地へ**再指示**する。**期待**：表示が新しい経路へ更新される。
8. 回廊の途中で停止させる状況を作る（要塞封鎖など）。**期待**：状態表示が変わる。

### D-2. 異なる経路を1つにまとめない
1. 同じ星系から**別々の目的地**へ2隊を出す。
2. **期待**：線とラベルが**2本**に分かれる。1本にまとめられていないこと。
3. 同じ出発・同じ目的地へ2隊を出す。
4. **期待**：1本にまとまり、ラベルに `×2` が出る。

### D-3. 密集時
1. 同じ星系に多数の艦隊を集める。
2. **期待**：既存の集約バッジ（「n艦隊 m,mmm隻」＝艦艇数のみ・「兵力」は出さない）がこれまでどおり出る。
3. バッジを押す。**期待**：既存の艦隊一覧が開き、個別に選べる。
4. 一覧から1隊を選ぶ。**期待**：MAP でその艦隊の経路と矢印が**強調**され、他は薄いまま。

## E. 援軍（#38）もメニューから

1. 交戦中の戦場を作る。
2. 艦隊メニューを開き、後方の艦隊を選ぶ。
3. **「② 援軍を送る」** を押す。**期待**：③が「A － B」の交戦中の戦場一覧に変わり、絞り込み欄が消え、
   実行ボタンが「この戦場へ援軍を送る」になる（MAP クリック不要）。
4. 戦場を選んで実行する。**期待**：到着予定つきの派遣通知が出る。
5. **Alt+A** を押す。**期待**：艦隊メニューが援軍モードで開く。
   カーソルが交戦中の回廊の上なら、その戦場が選ばれた状態で開く。
6. 派遣した艦隊の状態が「増援航行中」になり、移動命令が出せなくなる。

## E-2. 駐留・出撃（#40 駐留艦隊・**2026-09-10 追加**）

②の操作ボタンは**2行・計5つ**。上段＝`② 移動`／`② 援軍を送る`／`② 駐留`、
下段＝`② 出撃（駐留解除）`／`② 選択解除`。1行に詰めて文字を縮めていないこと。

1. `② 駐留` を押す。**期待**：③が「駐留先の要塞」の一覧に変わり、絞り込み欄が消え、
   実行ボタンが「この要塞へ駐留」になる。
2. 一覧の列＝**要塞名／所属／駐留／可否**。「駐留」は `2隊 8,000隻` または `駐留なし`。
   可否は短い理由（`敵の要塞`／`航行中`／`交戦中`／`回廊外`／`満員` 等）で、桁や語尾が切れていないこと。
3. 要塞の行を選ぶ。**期待**：③の見出しに `選択：(要塞名)（(勢力)）　守備力 nnnn　駐留 …` が出る。
4. 実行する。**期待**：駐留の通知が出て、①の状態が `駐留 (要塞名)` に変わる。
5. `② 出撃（駐留解除）` は**駐留中の艦隊を選んでいるときだけ押せる**。押すと名簿から外れる。
6. 詳しい確認手順は [fortress-corridor-qa.md](fortress-corridor-qa.md) の **L 節**。

## F. 既存機能を壊していない

1. **#40 回廊要塞**：要塞に足止めされる／通知のダブルクリックで要塞戦へ入れる／制圧して回廊が開く。
2. **#38 援軍**：時間差でワープインする／戦闘終了で帰投する。
3. **軍団隊形**：Battle シーンで A軍団=横陣・B軍団=方陣を同時維持できる。
4. **戦術マップの艦艇操作**：会戦での艦隊選択・移動・攻撃目標指定・陣形変更が従来どおり。
   **右クリックでの移動発令が会戦側では生きていること**（変更したのは戦略MAPだけ）。
5. 艦隊集約バッジ・3D恒星モデル・要塞モデル・星系名の表示が v5 と同じ。
6. **Escape** で艦隊メニューが1枚閉じる（システムメニューが被さらない）。
   もう一度 Escape で選択解除、さらに Escape でシステムメニュー、の順になること。
7. タイトルバーをドラッグして窓を動かせる。× で閉じられる。
8. 解像度を 1024x768／900x1200（縦長）／2560x1080（21:9）に切り替えて開き直す。
   **期待**：文字が潰れず（実測14px以上）、MAP の縦幅に収まり、右カラム（決裁デスク等）と重ならず、
   最終行までスクロールで到達できる。

## G. セーブ互換

> **重要：このゲームのセーブは1枠だけ**（`campaign_save.json`）。「新しいセーブ枠」は作れず、
> セーブすると既存の戦役データを上書きします。**必ず先に退避してから**試してください。
>
> 退避（PowerShell）：
> ```
> Copy-Item "$env:USERPROFILE\AppData\LocalLow\DefaultCompany\My project\campaign_save.json" "$env:USERPROFILE\Desktop\campaign_save.backup.json"
> ```
> 復元（QA を終えたら必ず実行）：
> ```
> Copy-Item "$env:USERPROFILE\Desktop\campaign_save.backup.json" "$env:USERPROFILE\AppData\LocalLow\DefaultCompany\My project\campaign_save.json" -Force
> ```


1. 移動中の艦隊がいる状態でセーブする。上の手順で**先に退避しておくこと**。
2. 再開する。**期待**：移動が続き、MAP の経路表示も復元される。
3. **旧セーブ**を再開する。**期待**：エラーにならず、ファイル内容が書き換わっていない。

## 既知の制約（設計上の選択）

- **回廊上での停止保持（旧・回廊線の右クリック）は操作から外した**。艦隊メニューは星系を目的地に取るため、
  回廊の途中で止める指示は現在出せない。内部機能としては残っている。
- **目的星系の一覧は全星系**を対象にし、到達可否は行ごとの理由表示で示す。
  未探索の概念は導入していない（既存仕様どおり全星系が見える）。
- **要塞封鎖は発令を止めない**。回り道が無いだけで、向かって制圧するのは正当な選択と扱う。

## 付録：軍団隊形（2軍団）の検証準備

通常の会戦（アムリッツァ等）は味方が3隊しかおらず、2軍団（各2隊以上）を作れません。
次のどちらかで **Play 中だけ** 4隊以上を用意します。**シーン・アセット・セーブには何も書きません。**

### 方法1（推奨）：検証用の会戦を開始する
1. Play 中に `Ginei > QA: 軍団隊形 検証用の会戦を開始（Play中）` を実行。
2. **期待**：味方6隊・敵3隊の会戦が始まる（既存の複数艦隊会戦の経路をそのまま使用）。
3. そのまま「QA: 軍団隊形テストを仕込む」へ進む。
4. **期待**：`QA-A軍団 = 3 隊 / QA-B軍団 = 3 隊` と出る。

### 方法2：いまの会戦に艦隊を足す
1. 会戦中に `Ginei > QA: 軍団隊形 検証用の艦隊を一時生成（Play中）` を実行。
2. **期待**：既存艦隊を複製して合計6隊になる。
3. **重要**：Unity エディタのポーズ中は複製した艦隊がレジストリに登録されません。
   **一度ポーズを解除して1フレーム進めてから**「仕込む」を実行してください。
4. 検証後は `Ginei > QA: 軍団隊形テストを撤去（Play中）` を実行。
   **期待**：一時生成した艦隊だけが消え、元からいた艦隊は残る。

### 続けて確認すること
1. `QA: 軍団隊形 A=横陣・B=方陣 を発令` → **期待**：A が横一列、B が格子状に組む。
2. **10秒以上放置**（AI の解決周期が10回以上回る）→ **期待**：A は横陣、B は方陣のまま。
   `QA: 軍団隊形の状態を出力` が `手動・完了` になっていること（`自動` に戻っていたら不合格）。
3. `QA: 軍団隊形 A だけ円陣へ再命令` → **期待**：A だけ組み替わり、**B は方陣のまま動かない**。
4. `QA: 軍団隊形 A だけ前列交代` → **期待**：A の前列だけ入れ替わり、**B の隊列は不動**。
5. B の軍団長を選んで遠方へ移動させる → **期待**：B の隷下が方陣を保ったまま追従する。
6. B の軍団長を右クリック → `軍団 ▸` に `QA-B軍団：方陣（手動・完了）` が出る →
   「軍団指定を解除」 → **期待**：B だけ AI 隊形へ戻り、A は円陣のまま。
