# 商人・経営者 ― 著名人物録
> Ginei 人物の archetype 参照用の人物プール（**非軍事の職能＝商人・経営者**）。武将中心の各時代ページに対し、本ページは古代〜現代の**豪商・財閥創業者・金融家・産業資本・投資家・起業家**を集約する。
> [[人物/_商人テンプレート|商人テンプレート]]の `archetype:`（商才・財産・事業）が主にここを参照する（「この商人は財閥の○○型／投資家の△△型」）。実在の人物名のみ（Ginei 固有名は持ち込まない）。
