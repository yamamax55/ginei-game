# ハラリ『サピエンス全史』参考設計（EPIC #1660）

> 参照元：ユヴァル・ノア・ハラリ著『サピエンス全史』。認知革命・農業革命・科学革命を経た人類史の俯瞰。
> 「虚構を信じることで見知らぬ者どうしが大規模に協力できる」——この認知的跳躍が帝国・貨幣・宗教・法律を同型の「想像上の秩序」として生み出す。
> 本ドキュメントは、当プロジェクト（Ginei＝銀英伝風の星間国家戦略＋既に豊富な制度純ロジック層）にとって**役に立つ視点**だけを抽出し、EPIC `#1660` として issue 化する提案。
> 著作権注意：固有名・文章・著者固有の用語は流用せず、**「虚構が大規模協力を生む」という構造パターン／メカニクスのみ**を参考にする。

## 0. なぜ『サピエンス全史』が本システムに役立つか

当プロジェクトは制度を扱う純ロジックを**大量に保有**している（[CLAUDE.md] 参照）：

| 既存（制度ロジック・抽象） | カバー範囲 |
|---|---|
| `DynastyRules`/`Regime`（#867） | 正統性・腐敗・天命喪失・易姓革命 |
| `ReligionRules`（#172-175） | 改宗圧力・異端・聖戦・社会効果 |
| `FiscalRules`/`FiscalState`（#161） | 国債/金利/為替・信用 |
| `Organization`/`SuccessionRules`（#812） | カリスマの日常化・継承・結束 |
| `Polity`/`ConsentRules`（#836） | 協力の撤回・非協力・統治不能 |
| `LoyaltyRules`/`BattleAllegianceRules`（#817） | 寝返りカスケード・関ヶ原型不動点 |
| `DisclosureLedger`（FND-4 #495） | 秘史開示チェーン |
| `CultureRules`/`Culture`（#194） | 同化・分離独立・ナショナリズム |
| `ColonizationRules`（#129） | 入植・惑星拡張 |
| `DemographicsRules`（#153） | 人口ボーナス/オーナス |

**しかし、これらは各制度を独立した純ロジックとして扱っており**、サピエンス全史が固有に示す以下が**欠けている**：

| サピエンス全史が固有に持つ視点 | 当プロジェクトでの欠落 |
|---|---|
| **虚構の共有が協力規模の上限を決める（ダンバー突破）** | 協力は `Polity.ControlStrength` や `Organization.Cohesion` で計るが、**信じる人数に比例して協力が延伸する梃子**が無い |
| **正統性・信仰・貨幣は同型の「想像上の秩序」** | 三者は別々のモジュール。**一つが崩れると同型の隣接制度へ波及する共鳴回路**が無い |
| **貨幣の信認次元**（数量でなく信頼の崩壊） | `FiscalRules.ExchangeRateFactor` はマクロ財政連動。**共同主観的信認の崩壊→ハイパーインフレ/物々交換回帰**の閾値が無い |
| **信念の相転移**（皆が「もう誰も信じていない」と気づいた瞬間に崩れる） | `DynastyRules.MandateLost` は線形衰退。**閾値での雪崩的崩壊**という相転移が無い |
| **物語の能動生産**（儀礼・教育・プロパガンダで虚構を補修する） | 正統性を上げる能動的手段として改革はあるが、**遅効・逓減・バックファイアを伴う虚構生産の高位レバー**が無い |
| **不可逆な転換と両義的進歩**（農業革命の罠：マクロ増・ミクロ後退・後戻り不能） | 入植や拡張は単純に「善」として扱われている。**拡張のコスト（自由度低下・不可逆性）**が無い |

**結論**：サピエンス全史は既存の制度ロジックに**「制度を横断する共有信念スカラ」という縦通し軸**と、①**協力の規模梃子** ②**制度横断の共鳴・崩壊** ③**信認の相転移** ④**物語の能動生産** ⑤**不可逆な転換の両義性**という5つの欠落軸を与える。武力でなく**共有された物語で銀河を束ねる**という王道路線の**理論的背骨**になる。

## 1. 役に立つ視点（要約）

サピエンス全史の構造を、**本システムに効く形**で1行ずつ：

1. **「虚構を共有できる認知能力」が協力の規模上限を決める**。小集団の信頼（ダンバー数上限）に、共有された信念が梃子をかけることで国家・帝国・銀河連邦が成立する。→ 当プロジェクトの**大規模勢力の統治原理**の理論的基盤。
2. **正統性・信仰・貨幣は「みんなが信じているから機能する」という同型の構造**を持つ。一つが崩れると隣接する他の虚構へ共鳴波及する。→ `DynastyRules`/`ReligionRules`/`FiscalRules` を**横断する単一スカラ**の起点。
3. **貨幣の価値は信認であり、数量でなく信頼が崩れると非線形に暴落する**（ハイパーインフレ＝物々交換回帰）。→ `FiscalRules.ExchangeRateFactor` に**共同主観の崩壊次元**を追加。狼と香辛料SAW-1の正貨品位と一対の"心理面"。
4. **信念は臨界まで緩やかに減衰し、閾値で雪崩的に無効化される（相転移）**。「もう誰も信じていない」と皆が知った瞬間に崩れる。→ `LoyaltyRules.ResolveCascade`（不動点反復）を**信念崩壊に転用**。
5. **為政者は儀礼・教育・プロパガンダで虚構を能動的に補修・生産できる**が、効果は遅効・逓減し、露骨な捏造はバックファイアする。→ 「高位の決断→エンジン駆動」のタイクン回避構造と整合。
6. **大きな転換（農業革命・定住化・帝国化）はマクロ指標を上げながらミクロの自由度を下げ、後戻りできない（ratchet）**。拡張は単純善でない。→ `ColonizationRules`/`DemographicsRules` に**両義的進歩の係数**を追加。

## 2. 取り入れるべきメカニクス（優先度つき・既存への接続）

> 大原則：**`DynastyRules`#867／`ReligionRules`#172／`FiscalRules`#161／`Polity`#836／`Organization`#812／`DisclosureLedger`#495 を作り直さない**。SAPIはそれらに**欠落軸を横断接続**するだけ（additive）。

### ★★★ 最優先（真の欠落・サピエンス全史の signature）

#### SAPI 共有された虚構と協力の規模上限（ダンバー突破）
- **`SharedFictionRules`**（static・test-first）＋**`ImaginedOrder`**（純データ）：勢力/組織の**協力可能規模**を「素の信頼（小集団上限）×虚構の共有度で梃子をかけた値」として算出。信じる者が多く・虚構が強いほど大規模協力が解ける。
- 接続：`Polity`協力#836（協力の規模天井と梃子）・`Organization`結束#812・`FactionState`。

#### SAPI 想像上の秩序スタック＝制度横断の信認（正統性/信仰/貨幣の同型合成）
- **`ImaginedOrderRules`**（static）：正統性（`DynastyRules`）・信仰（`ReligionRules`）・貨幣信認（`FiscalRules`）を**同一の"共有信念"スカラへ写像して合成**。一つの虚構の信認が落ちると同型の制度へ部分波及（共鳴）。`CombatModifiers`#106 が係数を一元化したのと同型の**信念版**。
- 接続：`DynastyRules`正統性#867・`ReligionRules`#172・`FiscalRules`#161・`FactionStateRules`。

### ★★ 高（信認崩壊・相転移・物語生産）

#### SAPI 貨幣の信認次元とハイパーインフレ（SAW-1と相補）
- **`MoneyTrustRules`**（static）：貨幣価値を「財政健全性（既存）×**共同主観的信認**」へ分解。信認低下で実効購買力が非線形に低下→閾値割れでハイパーインフレ／物々交換回帰。狼と香辛料SAW-1（正貨の品位＝物理面）と一対の"信認＝心理面"＝重複でなく相補。
- 接続：`FiscalRules.ExchangeRateFactor`#161（信認次元を足す）・`BankRules`取付け#186。

#### SAPI 信念の相転移（関ヶ原カスケードの信念版）
- **`BeliefCascadeRules`**（static）：共有信念が**閾値まではゆっくり減衰し、臨界で雪崩的に無効化**（連続でなく相転移）。関ヶ原#817の寝返りカスケード（`LoyaltyRules.ResolveCascade`）を「制度への信認」へ一般化。
- 接続：`LoyaltyRules.ResolveCascade`#817（不動点反復を委譲・重複新設しない）・`FactionStateRules.IsCollapsing`・`DynastyRules.MandateLost`#867。

#### SAPI 物語の生産（儀礼/教育/プロパガンダで虚構を能動生産）
- **`MythMakingRules`**（static）：為政者が**儀礼/教育/プロパガンダ/記念で共有信念を能動的に生産・補修**する（`ImaginedOrder` の強度・浸透度を上げる）。効果は遅効・逓減・反発（露骨な捏造はバックファイア）＝タイクン回避の高位レバー。
- 接続：`DynastyRules.Reform`#867・支持#113・`DisclosureLedger`#495・`NonviolenceRules`可視化#831。

### ★ 中（不可逆な転換・lore）

#### SAPI 不可逆な転換と両義的進歩（農業革命の罠）
- **`IrreversibleTransitionRules`**（static）：大きな社会転換（定住/拡張/制度化）は**マクロ指標（人口/産出）を上げるが、ミクロ（個の自由度/生活の質）を下げ、後戻りできない**（ratchet）。`ColonizationRules`#129・`DemographicsRules`#153 に両義性を足す（拡張＝単純善でない）。
- 接続：`ColonizationRules`#129・`DemographicsRules`人口#153・`GovernanceRules`安定#109・`DisclosureLedger`（進歩の代償 lore）。

#### SAPI（lore）統一の普遍力と虚構の世界観データ
- 「貨幣圏・帝国理念・宗教圏という非軍事の統合力が版図を一体化する」「神は信じられている限り実在する」型の世界観lore。`LogisticsRules`版図一体化#844 に非軍事統合の係数を薄く接続。
- 接続：**コード新設せず** `DisclosureLedger`（FND-4）への lore データ入力・`LogisticsRules`#844。

### ❌ 不採用（重複・既存で十分）

| 不採用 | 理由 |
|---|---|
| 宗教システムそのもの（改宗/異端/聖戦） | **`ReligionRules`#172-175 がカバー**。SAPIは接続のみ |
| 正統性・王朝サイクルそのもの | **`DynastyRules`/`Regime`#867 がカバー** |
| 貨幣の数量・需給・為替・信用創造 | **`FiscalRules`/`MarketRules`/`BankRules`#161/#179/#186 がカバー** |
| 正貨の品位・改鋳・改鋳投機（物理面） | **SAW-1/2 がカバー**（SAPIは心理面・相補であり重複しない） |
| カリスマからの正統性創出・宗教の創始 | **PRPH-1/2 啓示的カリスマがカバー** |
| 文化同化・ナショナリズム・分離独立 | **`CultureRules`#194 がカバー** |
| 認知バイアス・個人の非合理決断 | **`KahnemanRules`系がカバー**（SAPIの共同主観とは別物） |
| 進化史・人類学の年表再現 | タイクン化＝lore に退避 |

`SAPI-1 → SAPI-2`（共有虚構の基盤データ構造＋横断窓口を先に固める）→ `SAPI-3 → SAPI-4`（崩壊面＝信認崩壊とカスケードを連鎖）→ `SAPI-5`（能動生産レバー）→ `SAPI-6`（拡張の両義性）→ `SAPI-7`（lore 入力・コード新設なし）。
