# 建艦（けんかん）

> 失った艦は補わねば戦えない。造船所の槌音こそ、勢力の戦争継続能力そのものである。

## 造船から就役へ
星系の造船所は建艦オーダーを抱え、生産力（安定度に比例）に応じて艦を組み上げる。完成した艦は勢力の**艦艇プール**へ就役し、総保有を増やす――会戦で失う盤面の戦力とは別に、プールは建艦でのみ増える。建艦のパイプラインが太い勢力ほど、消耗を恐れず戦える。

## 軍産複合体
建艦は利権を生む。造船所の数と軍事省益が結びつけば、建艦補助金（建艦を加速）や調達腐敗（国庫漏れ）、さらには**戦争バイアス**（外交を好戦的に傾ける）が育つ。平時には複合体が民心を翳らせる――武器を作る力は、それ自体が政治を歪める力でもある。

## 編成への供給
就役した艦は、艦隊の設立・補充へ配分される（→ [[稟議|編制の稟議]]）。建艦で増えた余剰が新艦隊を生み、空になった艦隊は解かれてプールへ戻る――総保有と盤面戦力を分けることで、損耗が即・国力崩壊にならぬよう設計されている。

## ゲームデータ参照
- 造船は `ShipyardRules`（造船所・`BuildOrder`・完成→`FleetPool` 就役／`CommissionToPool`）。生産力は `ProductionFactor`（安定度比例）。軍産複合体は `MilitaryIndustrialRules`（造船利権→建艦補助金/調達腐敗/戦争バイアス）。編成は `FleetRoster`/`FleetEstablishmentRules`。観測＝Alt+B（造船）。
