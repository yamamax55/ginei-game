# 星系名（せいけいめい）

> 星系には、世界の**名峰**の名をカタカナで冠する。ただし日本の名峰は除く。

## 概要
[[回廊]]の交点に栄える**星系**には、固有の名が与えられる。その名の出どころは、人類が散らばる以前の故地――**揺籃の星々（旧き故郷）に聳えた名高い山々**である。〈エベレスト〉〈モンブラン〉〈アコンカグア〉〈マッターホルン〉〈エルブルス〉――いずれも、雲を貫き天に最も近づいた、故郷の屋根の名だ。

天の高みを衝く山の名を、宙に浮かぶ星系へ冠する――それは、回廊の海に隔てられてなお高みを目指す者たちの矜持であり、いずこの旗の下にあっても揺るがぬ大地の象徴でもある。命名は**世界の名峰**から採り、すべて**カタカナ**で表す。**日本の名峰は星系名には用いない**（→ 日本神話は[[惑星名]]が、故郷の土地は[[旗艦]]＝艦名がそれぞれ担い、命名の領分を分ける）。

## 命名の作法
- **名峰由来**：星系名は世界の名峰（ヒマラヤ・カラコルム・アルプス・アンデス・コーカサスほか）から採る。
- **カタカナ表記**：原語を問わずカタカナで統一する。
- **日本の名峰は除外**：富士・槍ヶ岳・穂高などは星系名に使わない（領分の分離）。
- **重複なし**：戦役の銀河ではプールをシャッフルし、星系名が重ならないよう引く。プールを使い切れば連番でフォールバックして命名は止まらない。

## 四つの命名体系（領分）
| 対象 | 名の出どころ | 実装 |
|---|---|---|
| **星系** | 世界の名峰（カタカナ・日本除く） | `MountainSystemNames` |
| **惑星** | 日本神話の神々 | `MythicPlanetNames` → [[惑星名]] |
| **旗艦** | 世界遺産・自然遺産（土地の名） | `HeritageShipNames` → [[旗艦]] |
| **回廊** | 世界の名高い海峡・水道・運河 | `Corridor` → [[回廊名]] |

## ゲーム実装との対応
> ※名簿の正は Core 側。ここは「どの実装に乗るか」の見取り図。

| 設定 | 実装 |
|---|---|
| 世界の名峰の名プール（カタカナ・日本除く・重複なし） | `MountainSystemNames.Names`（差し替えれば星系の命名規則ごと変わる単一の源） |
| i 番目の名（巡回） | `MountainSystemNames.At(i)` |
| 戦役生成でシャッフルして重複なく払い出し | `GalaxyView` の星系名プール（`MountainSystemNames.Names` をシャッフル） |
| 星系の器 | `StarSystem`／`GalaxyMap`（[[回廊]]の交点） |
