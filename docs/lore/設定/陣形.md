# 陣形（じんけい）

> 艦隊の組み方。攻めに尖るか、守りに固めるか――会戦の駆け引きの核。[[提督]]には[[#得意陣形|得意陣形]]がある。

## 概要
艦隊は旗艦を中心に、左右対称・旗艦の向きに追従して隊列を組む。陣形は史実の会戦陣形にならった**戦術特性**を持ち、攻撃・被害・機動のトレードオフを生む。状況に応じて切り替え、相性で優劣がつく。

## 五つの陣形（戦術特性）
| 陣形 | 特性 | 向く局面 |
|---|---|---|
| 紡錘陣 | 攻撃・機動↑／脆い | 突破・追撃（既定） |
| 鶴翼陣 | 攻撃↑↑／中央薄く鈍い | 包囲・寡兵での連携火力 |
| 円陣 | 堅い／火力・機動↓ | 守勢・退却 |
| 横陣 | 最大火力／脆く回頭鈍い | 正面の撃ち合い |
| 方陣 | 堅い／火力控えめ鈍重 | 重厚な正面決戦 |

## 得意陣形
名のある[[提督]]は得意とする陣形を持ち、部隊の現在陣形が一致する間だけ移動・防御にボーナスを得る。攻撃型＝紡錘陣／機動型＝鶴翼陣／防御型＝円陣・方陣。勢力の戦術傾向も陣形に表れる（[[碧晶公国]]＝方陣・円陣／[[黎明評議会]]＝鶴翼陣 など）。

## ゲームデータ参照
- 正は `Formation`（enum＝紡錘陣/鶴翼陣/円陣/横陣/方陣）＋`FormationTraitRules`（攻撃/被害/機動の倍率）＋`FormationDoctrineRules`（AI自動切替）。提督の得意陣形は `AdmiralData.preferredFormation`。陣形変更は `FleetCommander.ChangeFormation`。
