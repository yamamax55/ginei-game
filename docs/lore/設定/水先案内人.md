# 水先案内人（みずさきあんないにん）

> [[灯台]]が沈黙したいま、[[回廊]]の潮を読むのは機械でなく**人の勘**。一隻の水先が、艦隊の生死を分ける。

## 灯の消えた海で
[[大環状連合]]の時代、回廊の管制は[[灯台]]が一手に担い、誰でも安全に星を渡れた。だが[[環暦|首座灯の停止]]で大半の灯台が死に、いまや回廊の潮目を読むのは、経験を積んだ**水先案内人**の技と勘だけである。彼らは星々の流れを覚え、いつ・どの潮が開くかを察し、艦隊を隘路へ導く――誤れば船は潮にもまれて散り、二度と還らない。

## 水先の格
- **熟練の水先**は宝として奪い合われ、敵の水先を引き抜くことが一会戦の勝敗を左右する。
- 最高位の才が[[ミレイア・セルウィン]]の「**[[回廊]]を読む眼**」――潮の先を読み、寡兵を地の利で捌くその力は、もはや一個の水先を超えた天稟とされる。
- 死んだ回廊（[[マゼラン回廊]]）すら読み開きうる者がいれば、それは[[終章 ― 鍵の行方|銀河の鍵]]に手をかける者である。

## 制度と所属
水先は[[自由港同位体|交易国家]]では組合を成し、軍では参謀格として遇される。中立都市[[灯心自由市ファロス]]は、生きた[[灯台]]を抱くがゆえに最良の水先を擁し、それが武を持たぬ街の隠れた力となっている。

## ゲームデータ参照
- 航路解決は `GalaxyPathfinder`（[[回廊]]＝`Corridor`/`GalaxyMap`）、死んだ回廊の開削・探査は `ExplorationRules`。水先の才は `AdmiralData` の機動（`EffectiveMobility`）と情報（`EffectiveIntelligence`）に接続。回廊管制の本来の担い手は[[灯台]]（`Corridor` と連動）。
