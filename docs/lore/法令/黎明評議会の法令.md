# 黎明評議会の法令

> 反専制を法に刻んだ成文憲法を持つ。主権在民・三権分立・基本的人権を掲げ、権力者にも法が及ぶ法の支配の国。観測＝L。

## 憲法（最高法規）
- **成文憲法あり**＝**連邦憲章**。政体固有（民主＝`LawCatalog` "民主"）：
  - **主権在民・三権分立**（主権は市民、立法・行政・司法を分立）
  - **基本的人権の保障**（言論・信教・結社の自由と適正手続）
  - **文民統制条項**（軍は文民政府に服す）／**専制への抵抗権**を前文にうたう
- 共通法「宇宙航行の自由」も併せ持つ。

## 法律
- 共通法：刑法／民法／通商航行法／兵役法。
- 民主固有：**情報公開法**（政府情報の開示義務）／**公職選挙法**（評議会・公職の選出手続）。

## 政令
- **戒厳令は議会の承認を要する**（行政の濫用を防ぐ）。物資統制令も時限・議会統制下。

## 法の支配
- **法の支配が強い**（`RuleOfLawRules.RuleOfLawIndex` 高＝権力者にも法が及ぶ）。治安は合意と適正手続で保つが、合議ゆえ立法は遅い。

## 勢力固有の法の特色
- 反専制・自治を法の根幹に据える。恣意を許さない反面、合議の遅さが非常時の足枷となる（決断の遅れ）。
