# モリーニ商会

> [[自由港同位体]]の総合商社・交易。商会主[[カテリーナ・モリーニ]]が率いる。

## 概要
[[自由港同位体]]を本拠とする**総合商社・交易**。商会主の[[カテリーナ・モリーニ]]が興した商会で、財力は**新興**と目される。交易と相場で身代を回し、自由港同位体の経済を裏から支える。

## 事業・経営
- 主力＝総合商社・交易。財産は**投資**で運用。利潤は法人税ぶん国庫へ（私有企業）。

## 関係
- 本拠勢力：[[自由港同位体]]
- 主・創業者：[[カテリーナ・モリーニ]]（商会主）
