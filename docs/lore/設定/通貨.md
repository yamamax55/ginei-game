# 通貨（つうか）

> 銀河に一つの貨幣はない。勢力ごとの硬貨の強弱が、そのまま国力と信認の通信簿となる。

## 五つの貨幣
| 勢力 | 通貨 | 性格 |
|---|---|---|
| [[碧晶公国]] | [[公領マルク\|マルク]] | 銀本位の安定硬貨（伝統が裏打ち） |
| [[自由港同位体]] | [[自由港リラ\|リラ]] | 交易の基軸通貨 |
| [[黎明評議会]] | [[連邦ポンド\|ポンド]] | 管理通貨・インフレ寄り |
| [[鉄環兵団]] | [[兵団ルーブル\|ルーブル]] | 戦時インフレで弱体 |
| [[灯心自由市ファロス]] | [[灯心フラン\|フラン]] | 最強硬貨・銀河の基軸 |

## 強い通貨・弱い通貨
通貨の価値は信認で決まる。戦に明け暮れ国庫を空にすれば貨幣は刷られ、インフレで紙くずへ近づく（[[鉄環兵団|ルーブル]]）。逆に、武でなく信用で立つ[[灯心自由市ファロス|フラン]]は乱世でこそ価値を増し、銀河の基軸として選ばれる――「灯は買えぬが、航路は買える」（→ [[語録]]）。為替の高下は、勢力の盛衰を金融市場から映し出す。

## ゲームデータ参照
- 正は `CurrencyState`（固有名・為替・インフレ・信認）＋`CurrencyRules`（為替・物価）＋`CurrencyNames`（呼称）。財政との連動は `FiscalRules`（国庫が空けばインフレ）。観測＝Alt+F（財政詳）。各通貨ノート（CUR）が個別の正。
