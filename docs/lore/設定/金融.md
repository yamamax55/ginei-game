# 金融（きんゆう）

> 銭が銭を生む層。預金と貸付、国債と株、信用の膨張と崩壊――戦費を裏で支え、時に国を傾ける。

## 銀行と信用創造
両替商から育った銀行（→ [[商人|金融家]]）は、預金を元手に貸し出し、信用を膨らませて経済を回す。だが信認が崩れれば**取り付け**が起き、貸し倒れが自己資本を食えば**債務超過**で破綻する。乱世の金融は、繁栄と恐慌の振り子の上にある。

## 国債と財政
勢力は[[財政|国庫]]の不足を**国債**で埋める。健全なうちは金利も低いが、借金が借金を呼ぶ**債務スパイラル**に陥れば金利が跳ね、通貨と信認を道連れに財政が傾く（→ [[通貨]]）。

## 株式市場
私有企業（→ [[商人|商会]]）は上場し、利潤が配当と株価に映る。指数と市場心理が日々揺れ、好況と恐慌が交互に訪れる。不動産や商社の評価が膨らみすぎれば**バブル**となり、弾ければ金融危機が銀行の担保を直撃する。

## ゲームデータ参照
