# 巡礼と聖地（じゅんれい・せいち）＝灯を慕う旅

> 「沈黙した灯台に、なぜ人は祈りに行くのか。――灯が消えたからこそ、人は灯を恋うのさ。」

## 核心（沈黙した灯台が、信仰の聖地になった）
かつて[[回廊]]を照らした[[灯台]]の多くは沈黙したが（→ [[環暦|大解体]]）、その威容は人々の畏れを集め、[[信仰]]の**聖地**へと変わった。とりわけ銀河中心の[[灯台|首座灯]]は、すべての信仰が「いつか灯がともる地」として仰ぐ最大の霊場である。巡礼は[[回廊]]を渡る信仰の旅であり、[[祝祭|聖灯節]]の参詣は人と富を動かす。聖地は祈りの場であると同時に、交易・諜報・政治が交錯する要衝でもある。

## 巡礼が動かすもの（祈りの裏の現実）
- **聖地経済**――巡礼者の落とす金が門前の街を潤す。宿・土産・喜捨が[[商人]]を呼び、聖地は交易の結節点に（→ [[商社]]）。
- **巡礼路の安全**――[[回廊]]の巡礼路は[[通商破壊|海賊]]の的でもあり、護衛と通行料が要る（→ [[兵站]]・[[徴税と賦役|通行税]]）。
- **聖地をめぐる係争**――聖地の支配は威信そのもの。要衝聖地の帰属は[[戦争]]の名分になり、占領は[[民心]]を大きく動かす。
- **巡礼に紛れる者**――巡礼者を装う[[諜報機関|間者]]・[[難民と漂流民|難民]]・亡命者。聖地は人の出入りが多く、最も[[流言]]の濃い場でもある。

## 勢力ごとの聖地
- [[碧晶公国]]――[[信仰|灯統教会]]の荘厳な大聖堂を擁し、巡礼を国威に組み込む。聖職と門閥が結びつく（→ [[身分]]）。
- [[黎明評議会]]――[[信仰|黎明福音派]]は聖地を「各人の胸」とし、壮麗な巡礼地より日々の信を尊ぶ（→ [[黎明評議会連邦憲章]]）。
- [[自由港同位体]]――[[信仰|環理の道]]の観想の地。巡礼路を交易路と重ね、聖地経済で潤う（→ [[商社]]）。
- [[鉄環兵団]]――信仰は二の次。だが聖地の支配がもたらす威信と税は利用する。
- [[灯心自由市ファロス]]――灯を扱う都市として聖灯の儀礼に縁深く、巡礼の玄関口を自任する。

## NPC・クエストへの適用指針
- **巡礼者NPC**（祈りに生きる）――「首座灯へ。生きて辿り着けるとは思っちゃいねえ。だが、灯を一目――それだけで、この旅は報われる。」
- **聖地の門番NPC**（祈りと商売の境）――「参詣は自由だ。ただし喜捨は『気持ち』でな。……気持ちの軽い者は、奥までは入れんよ。」
- **クエスト分岐**：聖地で目的を遂げたい場面で → (a) **正規の参詣手続き**＝敬虔だが時間と喜捨がかかる／(b) **巡礼者に紛れて潜入**＝[[諜報機関|間者]]的な博打（露見すれば不敬の重罪）／(c) **[[汚職とフィクサー|聖職者へ喜捨で]]便宜**＝聖地ですら金が道を開く（→ [[信仰]]の堕落）。
