# 世代と継承（せだいとけいしょう）＝時が人を入れ替える

> 「名将も老いる。問題はな、老いた名将が、次の名将に椅子を譲れるかどうかさ。たいていの国は、そこで躓くんだ。」

## 核心（人は老い、地位と技は次代へ受け継がれる）
[[環暦|大解体]]から幾年も経て、開戦の世代は老い、戦を知らぬ世代が育つ。**世代交代と継承**は、勢力の長期的な命運を静かに決める。名将・名宰相の老衰と死（→ [[葬礼]]・[[捕虜と亡命|人物動態]]）、その地位を継ぐ者の質、技と[[名と諱|名]]の襲名――これらが滞れば、いかに強大な勢力も一代で傾く。逆に若き俊才の登用と円滑な継承は、勢力に長い繁栄をもたらす。継承は[[婚姻と家門|血の継承]]だけでなく、地位・技・志の継承でもある。

## 受け継がれるもの（何が次代へ渡るか）
- **地位と官職**――[[官僚|官職]]・[[階級|指揮権]]・[[政体|王位]]の継承。世襲か、実力か、選挙か――継承の形が[[政体]]を映す。
- **技と知**――[[工房と職人|職人の技]]・[[名門校|学統]]・[[正史と稗史|秘伝]]は、継ぐ者なくば失われる（→ [[技術]]・[[学びと識字]]）。
- **名と志**――[[名と諱|襲名]]、英雄の遺志、[[旗幟|忠誠]]の世代を超えた継続（また断絶）。
- **老いと隠居**――老将の引退・後見・院政。権力を手放せぬ老人が次代を阻む悲喜劇（→ [[名誉と面子]]）。

## 世代がもたらす物語
- **世代の断絶**――開戦世代の死と共に、和睦の記憶も恩讐も薄れる。戦を知らぬ世代が安易に戦を始める皮肉。
- **後継者争い**――名将・君主の死後、後継を巡る内紛は同じ血ゆえに惨い（→ [[婚姻と家門]]・[[旗幟]]）。
- **老害と若き才**――地位に固執する老人と、阻まれる若才の相克。[[身分]]の壁と世代の壁が重なる。
- **遺志の継承**――倒れた英雄の志を継ぐ者の物語。群像劇の縦軸（→ [[語録]]・[[正史と稗史]]）。

## 勢力ごとの継承
- [[碧晶公国]]――世襲が骨格。地位も技も血で継ぎ、円滑だが停滞も招く。後継者争いは家門政治の華（→ [[婚姻と家門]]・[[身分]]）。
- [[黎明評議会]]――選挙と任期で地位を継ぐ。世襲を排すが、継承のたび政争で揺れる（→ [[政体]]・[[黎明評議会連邦憲章]]）。
- [[鉄環兵団]]――実力者の後継指名。血より功だが、強い首領の死後に分裂しやすい（→ [[階級]]）。
- [[自由港同位体]]――商家の代替わり。事業と信用を継ぐ者の質が商会の命運（→ [[信用と証文]]・[[商社]]）。
- [[灯心自由市ファロス]]――ギルドと市民選挙で職を継ぐ都市の流儀。

## NPC・クエストへの適用指針
- **老将NPC**（譲る時を悟る/悟れない）――「わしの代はもう長くない。問題は……この椅子を、誰に託すかだ。功で選べば角が立ち、血で選べば器が伴わぬ。難しいものだな。」
- **阻まれる若才NPC**――「実力は示した。だが上が詰まってる。あの老人たちが退かぬ限り、俺の出番は来ない。……待つか、押しのけるか、だ。」
- **クエスト分岐**：後継を巡る場面で → (a) **正統な継承を支える**＝秩序は保つが器量を欠く後継なら衰退／(b) **実力者を担いで継承を覆す**＝下剋上の博打（[[旗幟]]・[[名誉と面子]]を賭ける）／(c) **[[汚職とフィクサー|裏で根回し]]して継承を誘導**＝角を立てず望む後継を据える。
