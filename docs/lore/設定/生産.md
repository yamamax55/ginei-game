# 生産（せいさん）

> 原料から品へ、品から暮らしへ。投入が産出を生む工程の連なりが、勢力の物質的な厚みを成す。

## 工程の連なり
ものは段階を踏んで作られる。原料を加工し、部材を組み、最終の品（食品・衣類・住宅・兵器…）へ至る――この投入→産出の工程（レシピ）が連なって生産チェーンを成す。どこか一段でも詰まれば、最終の品が痩せる（最小律）。働き手（→ [[労働]]）と[[技術]]と原料が揃ってはじめて、生産は回る。

## 市場と企業
作られた品は市場で売買され、供給と需要から価格が創発する。企業はその価格を見て生産・雇用・投資を決め、利潤を蓄え、あるいは潰れる。消費財の需要は人々の暮らし（→ [[民心]]・[[食]]）から生まれ、生産がそれを満たせるかが生活水準を左右する。

## タイクンにしない設計
品目は少数に絞られる。全ての品を細かく追えば、終盤に計算が膨れて世界が重くなる――ゆえに代表的な品目とレシピに集約し、勢力・惑星の粒度で回す（個体に降りない）。realism より、回り続ける軽さを採る。

## ゲームデータ参照
- 汎用BOMは `BomProductionRules`（最小律）＋`CommodityCatalog`（品目）＋`RecipeBook`（レシピ）。消費財需要は `ConsumerDemandRules`、市場価格は `MarketRules`（供給/需要で創発）、企業は `ManufacturerRules`/`ConstructionRules`（利潤・価格）。住宅は消費財品目として扱う。観測＝Alt+P（生産）。品目は少数に集約（終盤ラグ回避）。
