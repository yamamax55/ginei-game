# 鉄環兵団の役職体系

> 傭兵あがりの軍閥＝**軍政一体・実力主義**。総統を頂点に、功を立てた者が将になる。文官は軍に従属する。在任は[[鉄環兵団#名鑑（所属の人物・組織）|名鑑]]・runtime で変動。

## 元首・統帥
- **総統**：兵団の最高指揮官（実力で就く・軍政一体）。在任例 → [[エーリヒ・グリュンヴァルト]]。

## 政府役職（文官・官職）
- 文官は独立した政府を持たず、**兵站・金庫・調達**を担う従属的な実務官（兵部相当）。
- **占領地行政官**：奪った星系（[[マッターホルン星系]] ほか）の徴発・統治を担う。

## 立法・評議
- **兵団評議会**：軍団長たちの合議（政党＝[[兵団評議会]]／[[主戦派]]／[[実利派]]）。理念より実力と実利で動く。

## 軍役職（階級＋指揮職）
- **軍団長**：最高指揮職。階級は功で昇り（家格・席次を問わぬ実力主義）、敗れた将に明日はない。
- **突撃隊司令**：速攻・奇襲の先鋒。
- 在任例 → [[ヴォルフ・アッカーマン]]（鉄狼・准将）／[[ディートリヒ・モーザー]]。

## 勢力固有の役職
- **兵団金庫長**（[[兵団ルーブル]]の発行・戦費調達）／**調達官**（武器・略奪正貨の管理）。
