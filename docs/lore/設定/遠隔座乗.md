# 遠隔座乗（えんかくざじょう）

> 提督は艦に乗らない。**根拠地の〈感応座〉から旗艦を遠隔に指揮する**――旧[[大環状連合]]の遺産技術。だから旗艦は沈んでも、提督は死なない。

## 概要
将は戦場に身を運ばない。提督は[[封土|根拠地]]に据えられた管制宝座〈**感応座（かんのうざ）**〉に就き、遥か前線の[[旗艦]]とその麾下の艦隊へ自らの意志と感覚を投射して、盤面を俯瞰しながら采配を下す。これが**遠隔座乗**――名のある旗艦に「提督が座乗する」とは、すなわち感応座を通じて遠隔に乗ることを指す。

技は提督一人のものではない。[[灯台]]が[[回廊]]を束ね銀河を一つにしていた頃、連合は人と艦の意識を遠く繋ぐ網を張りめぐらせた。[[環暦|大解体]]で銀河規模の網は死んだが、その断片――**根拠地の局所網**だけは今も生きている。ゆえに遠隔座乗は[[旗艦]]の命名同様、**勢力を問わぬ連合の遺産**。敵も味方も、失われた叡智の同じ恩恵に与って戦う（→ [[技術|失われた叡智]]）。

## 感応座からの采配
感応座は提督の感覚を前線へ余さず通わせる。将は俯瞰の視座から艦隊を動かし、[[士気|戦法・号令]]――突撃下令、斉射、回頭、必殺の一手――を**意のままに即座に放つ**。戦機を逃さぬこの速さこそ、遠隔座乗がもたらす采配の冴えである。

## 旗艦は沈んでも、提督は死なない
遠隔の身であるがゆえ、**旗艦撃沈は提督の死を意味しない**。沈んだ艦の名は[[旗艦|永久欠番]]として戦史に刻まれ二度と払い出されぬが、提督は感応座に在って無事。将は前線を退き（退避）、麾下の配下艦が殿（しんがり）を務める（[[旗幟|捨てがまり]]）あいだに、繋がりを切って生き延びる。

## 根拠地を喪えば、すべてを喪う
旗艦が沈んでも折れぬ将も、**感応座の在る根拠地を奪われれば終わる**。遠隔の繋がりは断たれ、前線の旗艦はただの抜け殻となり、何より――感応座に就いていた**提督その人の身柄が、敵手に晒される**。

根拠地陥落のとき、提督を待つのは三つの運命。**撤退**（からくも脱して再起を期す）／**死亡**（座を枕に果てる）／**捕縛**（生きて敵手に落ち、[[捕虜と亡命|捕虜]]となる）。いずれに転ぶかは、将の[[提督|統率]]と人柄、戦況、そして敵の追撃の苛烈さが決める。**「旗艦は幾度でも沈められるが、根拠地と提督の命はただ一つ」**――遠隔座乗の世がもたらす理である。
