# 降伏と開城（こうふくとかいじょう）＝矛を収める作法

> 「戦を始めるのは誰でもできる。難しいのは、いかに終わらせるかだ。降る側の面子を残しつつ、奪うものは奪う――その匙加減で、次の戦の芽が決まるのさ。」

## 核心（負けの収め方が、次の戦の芽を決める）
会戦も[[要塞|攻城]]も、すべてが全滅で終わるわけではない。多くは**降伏と開城＝矛を収める交渉**で決着する。降る側は[[名誉と面子|面子]]と助命を、攻める側は無用な損耗の回避と[[戦利品と分捕り|戦果]]を求め、両者の利が[[誓いと契り|降伏の誓い]]で釣り合う。だが降伏の作法は諸刃である。寛大な助命は降将を味方に変え（→ [[旗幟|寝返り]]）、苛烈な処断は次の城の死守を招く（「降れば殺される」と知れば誰も降らない）。負けの収め方こそが、勝者の器量と、次の戦の芽を決める。

## 矛の収め方（降りる作法と迎える作法）
- **開城交渉**――[[要塞|城]]・[[兵站|補給]]の尽きた側が条件を出して開く。助命・領地安堵・[[捕虜と亡命|身柄]]の保証が争点（→ [[誓いと契り]]）。
- **助命と処断**――降将を生かすか斬るか。寛大は信を、苛烈は恐怖を生む。器量が問われる選択（→ [[捕虜と亡命]]・[[罪と罰]]）。
- **降伏の儀礼**――[[個人武装と白兵|佩剣]]を捧げ、旗を降ろす作法。降る側の[[名誉と面子|面子]]をどう残すか（→ [[礼儀と作法]]・[[服飾と紋章]]）。
- **偽りの降伏**――降伏を装う罠、降伏後の謀殺。一度の裏切りが以後の全ての降伏を不可能にする（→ [[流言]]・[[誓いと契り]]）。

## 降伏が動かす物語
- **武士の情け**――降将を厚遇して味方に迎える美談。寛大が[[旗幟|忠誠]]を生む（→ [[名誉と面子]]・[[恩賞と論功行賞]]）。
- **死守か開城か**――降れば助かるが恥、戦えば誇りだが死。籠城する側の苦渋（→ [[戦傷と心]]・[[旗幟|殉節]]）。
- **降伏勧告と心理戦**――降伏を促す勧告、[[報道と宣伝|偽の戦況]]で戦意を挫く。盤外の攻防（→ [[流言]]）。
- **降伏の裏切り**――助命を約して斬る背信。短期の利と引き換えに、以後誰も降らなくなる長期の損（→ [[正史と稗史]]）。

## 勢力ごとの降伏観
- [[碧晶公国]]――格式ある開城儀礼。降将の[[身分|家格]]次第で処遇が分かれ、門閥には寛大、平民には苛烈（→ [[名誉と面子]]・[[礼儀と作法]]）。
- [[黎明評議会]]――助命と捕虜の人道的処遇を法で定める。降伏者の権利を保障（→ [[黎明評議会連邦憲章]]・[[捕虜と亡命]]）。
- [[鉄環兵団]]――降れば命は取らぬが、抗えば皆殺しの恐怖戦術。降伏勧告に従う限り寛大（→ [[階級]]）。
- [[自由港同位体]]――降伏を取引として扱う。身代金・[[信用と証文|証文]]での解決を好む実利（→ [[人質と質草]]）。
- [[灯心自由市ファロス]]――都市の信用を守るため、降伏の約定を厳守する律儀さ（→ [[都市国家]]）。

## NPC・クエストへの適用指針
- **開城を迫る攻め手NPC**――「城兵の命は助ける。佩剣を捧げ、城を明け渡せ。……無駄に死ぬな。あんたの忠義は、もう十分に示された。」（武士の情け＝→ [[名誉と面子]]）
- **死守を選ぶ守将NPC**――「降れば命は助かる、か。……だが、主君を見捨てて生きる命に、何の値打ちがある？　ここが、わしの死に場所だ。」（→ [[旗幟|殉節]]）
- **クエスト分岐**：降伏・開城の局面で → (a) **正規に条件を交渉し誓約を交わす**＝確実だが時間がかかり譲歩も要る（→ [[誓いと契り]]）／(b) **降伏を装う/苛烈に処断する**＝速いが信を失い以後の降伏を不可能にする博打／(c) **[[汚職とフィクサー|仲介人]]を介して裏で身代金・安堵を取り決める**＝高くつくが双方の[[名誉と面子|面子]]を立てて穏便に収める。
