# 碧晶公国の階級（rank ladder）

> 旧連合貴族の世襲公領＝**君主統帥**の正規軍。由緒ある艦隊伝統を重んじ、**家格（門閥）が昇進を左右する**。
> 重厚・物量・正面決戦のドクトリン（→ [[碧晶公国の軍編成]]）ゆえ、大艦隊を委ねる**将官の段が分厚い**――唯一 tier 9「上級大将」を常設する勢力。
> 数値・指揮限界の正は `CommandCapacityRules`、階級表は `FactionData.ranks`。

## 階級表（最も完備したラダー）
> 公国は **完全12段（tier 1〜12）を欠番なく**持つ唯一の勢力（古い建制を温存）。tier 11「上級大将」を擁し、将官の段が他勢力より一段深い。

## 軍編成との対応（重厚・物量を映す）
- **常設の天井**：元帥（12）。その上は[[碧晶公国の役職\|大公]]（元首＝君主統帥）。臨時・名誉位は置かず、由緒ある建制をそのまま温存する。
- **昇進の偏り**：**家格の壁が tier 7（准将）にある**。門閥子弟は准将から将官の階を駆け上がるが、平民は功を立てても tier 6（大佐）で頭打ちが慣例（紋章院が家格・叙位を管理）。これが「冷たい秩序」の正体で、有能な平民の不満＝物語の火種。
- **梯団との接続**：上級大将（11）が方面軍、大将（10）が主力艦隊を持つ厚い将官層が、堅い方陣・円陣の物量戦を支える。→ [[碧晶公国の軍編成]]

## 勢力固有の階級事情
- **名誉武官（顕職）**：大公家・上級門閥の当主は、実戦指揮を執らずとも儀礼上の高位（名誉大将など）を帯びることがある（実指揮は `FleetRoster` の配置が正）。
- **紋章院による家格管理**：将官（准将以上）の銓衡には紋章院総裁（→ [[碧晶公国の役職]]）の家格審査が絡む。実力主義の[[鉄環兵団の階級\|鉄環]]と対照をなす。
