# エミール・ボーフレモン

> 「赤筆」――人事を握る男。灯心自由市ファロス民部省に在って、内政・戸籍を司る。

## 概要
[[灯心自由市ファロス]]の[[官僚|文官]]。51歳。**民部省**（内政・戸籍）に属し、官職は**民部大丞**、位階は**従六位上**。文才（運営・情報）を本領とし、都市国家。市民自治のもと、港と財庫を回す実務官僚が屋台骨なかで実務の屋台骨を担う。

## 容姿
白髪まじりの実直な風貌、書類の束を手放さない。灯心自由市ファロスの文官正装に従六位上の位色をまとう。51歳。

## 来歴
- 灯心自由市ファロスの市井に生まれ、科挙の殿試に上位で及第し進士となり灯心自由市ファロス民部省に配され頭角を現した。
- 考課を重ねて従六位上に叙され、現在は民部大丞として内政・戸籍にあたる。

## 性格・信条
- 数字と前例に忠実な実務家。情よりも帳尻を重んじる。
- 信条は**能力主義**。灯心自由市ファロスの理念「武装中立・市民自治（都市国家）」との距離が、時に去就を左右する。
