# ヴァッセルマン銀行

> [[鉄環兵団]]の金融（銀行・両替）。両替商[[ラインホルト・ヴァッセルマン]]が率いる。

## 概要
[[鉄環兵団]]を本拠とする**金融（銀行・両替）**。両替商の[[ラインホルト・ヴァッセルマン]]が興した商会で、財力は**富裕**と目される。預金と貸出で信用を回し、鉄環兵団の経済を裏から支える。

## 事業・経営
- 主力＝金融（銀行・両替）。財産は**浪費**で運用。利潤は法人税ぶん国庫へ（私有企業）。
