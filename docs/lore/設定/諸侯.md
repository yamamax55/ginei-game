# 諸侯（しょこう）

> 中央が消えた銀河で割拠する、地方勢力の総称。本作の題『[[星骸の諸侯]]』の諸侯。

## 概要
[[大環状連合]]の崩壊と[[灯台\|首座灯]]の停止ののち、銀河は唯一の高速航路[[回廊]]を奪い合う**割拠の時代**に陥った。生き延びた者たちが[[回廊\|要衝星系]]を押さえ[[封土]]を囲い込み、それぞれの大義のもとに艦隊を養った――これが諸侯である。旧連合の貴族、植民星の議会、商人ギルド、傭兵あがりの軍閥など出自はさまざまで、互いに会戦・同盟・裏切りを繰り返す。

## 諸侯の四つの大義
| 勢力 | 出自 | 大義 |
|---|---|---|
| [[碧晶公国]] | 旧連合貴族の世襲公領 | 正統なる権威による統一の再建 |
| [[自由港同位体]] | 商業ギルド連合 | 交易の自由・武装中立 |
| [[黎明評議会]] | 植民星の民選議会連邦 | 自治と合意・反専制 |
| [[鉄環兵団]] | 傭兵あがりの軍閥 | 実力主義の征服 |

## 諸侯に与しない第三の極
[[封土]]を広げる諸侯に対し、ただ一個の[[回廊\|要衝星系]]を自ら治め、いずれの大義にも属さない[[都市国家]]（自由市）がある（[[灯心自由市ファロス]] ほか）。多極構造の潤滑油であり、弱小プレイヤーの足場となる。

## 揺れる旗のもとで
武で奪った[[封土]]は信なくしては瓦解する。諸侯のあいだを提督たちは[[旗幟]]を揺らして渡り歩き、寝返り・離反・殉節が時代の日常となる。諸侯の割拠が定着するさまは [[第一章 ― 諸侯の時代]] が描く。

## ゲームデータ参照
