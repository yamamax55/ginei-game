# 主人公（しゅじんこう）

> 群像の渦に置かれた、プレイヤーの分身。多くの旗のいずれかを握り、辺境の一艦隊から己の物語を編む者。

## 群像のなかの一人
本作は**[[群像劇の構成|オムニバス群像劇]]**であり、主役は一人ではない。だが縦糸として、辺境の名もなき一艦隊から[[終章 ― 鍵の行方|銀河の鍵]]に至る道を走る中核がいる――[[ミレイア・セルウィン]]。プレイヤーはこの群像のいずれかの旗を握り、群雄の渦のなかで自らの物語を紡ぐ。

## AIに乗っ取られぬ者
主人公は、たとえプレイヤーが直接操作していない局面でも、AIに勝手な行動を取らせない＝物語の主体として保護される。人望厚く有能な提督ほど、[[黎明評議会連邦憲章#第四章　軍と文民統制|文民統制]]の試練に立たされ、英雄であり続けるか僭主へ堕ちるかが問われる（→ [[ミレイア・セルウィン|ミレイア]]が「統べない」を選べるか）。

## 小から大へ
主人公の物語は成り上がりである。弱小の一艦隊から始め、会戦の地の利と[[外交]]で版図を拡げ、[[旗幟|人の心の旗]]を繋ぎとめながら、銀河の行く末を決める一手へと至る――カリスマでなく[[封土]]・[[回廊]]・制度を主役に据えた、その渦の中心に主人公は立つ。

## ゲームデータ参照
- 正は `ProtagonistRules`（`IsProtagonist`／`ShouldEnableAI`＝主人公はプレイヤー非操作でもAIに乗っ取られない）＋`AdmiralData.isProtagonist`（GON-6）。会戦の `FleetAI.enabled` をここで決める。
