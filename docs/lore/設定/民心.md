# 民心（みんしん）

> 版図は武で奪えても、民心は武では買えない。支持と安定の薄氷の上に、あらゆる勢力は立っている。

## 支持と安定
勢力の足元は**支持**（民が為政者を是とするか）と**安定**（秩序が保たれているか）で測られる。高ければ税も兵も円滑に集まり、低ければ反乱と離反の芽が育つ。重税は国庫を肥やす代わりに支持を削り（→ [[財政]]）、苛烈な統治は秩序を保つ代わりに民心を蝕む――どの勢力も、この綱引きの上で舵を取る。

## 統治の質
同じ版図でも、統治の巧拙で生かせる地力は変わる。安定度×統合度が高いほど産出と徴募が伸び、占領直後の未統合な星は不安定で実りが薄い。民心は[[人口]]・生活水準（→ [[労働]]）・[[身分|身分秩序]]・法の支配と絡み合い、一つが崩れれば連鎖して傾く。

## 政体による違い
[[黎明評議会|民主勢力]]は支持を選挙で問われ、失えば政権が替わる。[[碧晶公国|専制]]は身分秩序で安定を保つが平民に冷たく、[[鉄環兵団|軍閥]]は勝利が続くかぎり結束し大敗で瓦解する（→ [[政体]]）。
