# 食（しょく）

> 何を食べ、何を呑むか。乱世にあっても人は卓を囲む。食は勢力の暮らしと交易の写し絵。

## 各勢力の食と酒
| 勢力 | 食 | 酒・飲み物 |
|---|---|---|
| [[碧晶公国]] | 格式ばった宮廷料理。儀礼を伴う長い晩餐 | 古酒（年代を誇る貴族の銘酒） |
| [[自由港同位体]] | 五海の交易料理＝各地の香辛料が混ざる雑多な美食 | 各港の地酒を一杯ずつ呑み比べる |
| [[黎明評議会]] | 植民星の素朴な共同食。皆で同じ鍋を囲む | 手づくりの地酒（議会の夜は安酒で議論） |
| [[鉄環兵団]] | 戦場の携行食。簡素で腹に溜まる | 強い蒸留酒＝「戦友の酒」（戦死者に一杯空ける） |
| [[灯心自由市ファロス]] | 港の魚介・干物。倹約と新鮮の同居 | 灯明酒（灯台の夜に灯す琥珀色の酒） |

## 飢えの記憶
- [[環暦|大解体]]の十年、人々は**合成糧食**で飢えをしのいだ。味気ない携行糧は今も貧困と非常時の象徴で、これを卓に出すことは「[[回廊]]が細った」合図とされる（→ [[灯心自由市ファロス|港]]が閉じれば食が痩せる）。

## 交易と食卓
食は[[回廊]]の上を流れる。香辛料・酒・嗜好品は[[自由港同位体|交易民]]の利の源で、戦争で航路が断たれれば真っ先に卓から消える――民心の早期警報でもある。

## ゲームデータ参照
- 消費財の需給は `ConsumerDemandRules`（食品＝消費財品目）、暮らし向きは生活水準（`Province.livingStandard`）・飢餓（`foodShortage`）に接続。交易は[[回廊]]（`Corridor`）・供給配分。食そのものはフレーバーで、数値は内政・経済側へ委譲する。
