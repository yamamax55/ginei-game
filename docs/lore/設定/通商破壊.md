# 通商破壊（つうしょうはかい）

> 戦は前線だけにあらず。敵の[[回廊|交易路]]を断ち、補給を干上がらせる――盤外から勝敗を動かす私掠の戦い。

## 概要
正面の会戦を避け、敵の輸送船・交易船を襲って補給と富を断つのが**通商破壊**。逆にそれを防ぐのが**通商護衛**である。非戦闘艦（輸送艦）は撃ち返さず逃げるが**撃沈はされうる**ため、護衛と襲撃が成立する。[[回廊]]という唯一の高速航路は、扼せば富と兵の咽喉を握れる隘路＝格好の狩り場となる。

## 私掠という生業
- [[自由港同位体|交易国家]]や辺境には、国家公認で敵商船を襲う**私掠者**がいる。金で動き、戦況で旗を替えることも厭わない（→ [[旗幟]]）。
- その筆頭が「紅蓮の私掠」[[キアラ・ヴェントゥーラ]]――奇襲と機動で交易路を荒らす私掠のエース（→ [[列伝 ― 紅蓮の私掠]]）。「奪わぬ海賊は、ただの船乗りさ」。
- [[マラッカ回廊]]は私掠の常襲地で、襲撃と護衛がたえず衝突する。

## 戦略上の意味
通商破壊は、前線で勝てぬ側が大国を削る非対称の手であり、補給を断たれた艦隊は[[兵站|滅びの時計]]に追われる。商船一隻の喪失が、めぐって会戦の帰趨を変える。
