# 三国志大戦 参考設計（EPIC #SGT）

> 参照元：『三国志大戦』（セガ・アーケードの対戦型カードアクション）。武将カードを盤上で動かし、**時間で貯まる士気を計略（戦法）に注ぎ込み**、号令で全軍を一斉強化し、兵種相性・突撃・乱戦で押し合い、敵城（城門）を落とすリアルタイム合戦ゲーム。
> 本ドキュメントは、当プロジェクト（Ginei＝銀英伝風2D戦術艦隊戦）にとって**艦隊会戦に移植して映える「いいところ」だけ**を抽出し、EPIC `#SGT` として issue 化する提案。
> 著作権注意：固有名・カード・武将・文章・固有設定は流用せず、**合戦メカニクス／リソース駆け引きの構造パターンのみ**を参考にする。

## 0. なぜ「三国志大戦」が本システムに役立つか

当プロジェクトの会戦層は**戦術の純ロジックを既に多数保有**している（[CLAUDE.md] 参照）：

| 既存（会戦の駆け引き） | カバー範囲 |
|---|---|
| `ActiveCommandRules`（#2175） | 単艦の戦法（一斉砲撃/突撃/不退転）＝cooldown 制 |
| `TalentCatalog`（#特技）→`AdmiralSkillRules` | 提督のパッシブ特技 |
| `FormationTraitRules`/`FormationMatchupRules`（#72/#2177） | 陣形の特性＋陣形の三すくみ |
| `FormationAccessRules`（#軍神/#石兵八陣） | 伝説陣形の英傑ゲート |
| `FleetMorale`（士気） | 士気→能力補正・敗走 |
| `LanchesterRules`/`ShipCombat` | 局所火力集中・ダメージ式 |
| `ShipClass`（#80）/`CarrierRules` | 艦種の定義・空母 |
| 要塞（#76-78）/勝利条件`要塞攻略`/`要塞防衛` | 固定拠点の攻防 |

**しかし、これらは「単艦の戦法（cooldown）」「陣形の相性」どまり**であり、三国志大戦が固有に描く以下が**欠けている**：

| 三国志大戦が固有に持つ視点 | 当プロジェクトでの欠落 |
|---|---|
| **士気＝時間で貯まる共有リソースを計略に注ぐ経済** | 戦法は cooldown のみ＝「貯めて大技を撃つ／小技を回す」の**資源配分の駆け引き**が無い |
| **号令・采配＝全軍/範囲を一斉強化する大技** | 戦法は単艦のみ＝**全軍同時バフで一気に攻め込む**一手が無い |
| **知力が計略の威力/抵抗/成功率/効果時間を決める** | `EffectiveIntelligence` は会戦の**戦法威力・抵抗**にほぼ効いていない（知力の戦場での役割が薄い） |
| **兵種相性の三すくみ（艦種どうしのじゃんけん）** | 相性は**陣形**のみ（#2177）。**艦種（戦艦/巡航/駆逐…）間の相性**が無い |
| **突撃の助走ボーナス（運動量→大ダメージ・槍/障害で停止）** | 突撃は固定倍率＝**助走距離・速度で威力が変わる運動量**が無い |
| **乱戦＝至近の揉み合い（射界/陣形より兵力×武力・相互減速の押し引き）** | 戦闘は遠距離ビーム中心＝**接触して揉み合う近接戦**が無い |
| **コスト制の出撃編成（出撃ポイント予算で質×量を選ぶ）** | 編成は総プール配分（#148）＝**1会戦の出撃予算でデッキを組む**ドラフトが無い |

**結論**：三国志大戦は当プロジェクトの会戦に **①士気＝計略リソース経済 ②号令＝全軍同時強化 ③知力が効く戦場**という3本柱の駆け引きを与え、さらに**艦種相性・突撃運動量・乱戦・出撃コスト**という会戦を厚くする軸を供給する。いずれも既存の `ActiveCommandRules`/`FormationMatchupRules`/`TalentCatalog` を**作り直さず接続・拡張**する additive。

## 1. 役に立つ視点（要約）

三国志大戦の合戦観を、**本システムに効く形**で1行ずつ：

1. **士気は時間で貯まる有限資源で、いつ何に使うかが勝負**。小技で削るか、貯めて号令で一気に攻めるか。→ 会戦に**資源配分の駆け引き**を入れる（cooldown だけの戦法に「経済」を足す）。
2. **号令一つで戦況が反転する**。全軍同時のバフ＝攻め時の一手。→ 単艦戦法の上に**全軍/範囲の大技**を載せ、決断#502の会戦版に。
3. **知力は戦場の通貨**。計略の威力・抵抗・成功率を決め、頭脳が武力を覆す。→ 眠っている `EffectiveIntelligence` に**会戦での役割**を与える（軍師の価値）。
4. **じゃんけんがある＝相性で兵を当てる**。陣形だけでなく艦種にも三すくみ。→ `FormationMatchupRules` の**艦種版**で編成と布陣に意味を足す。
5. **突撃は助走で活きる**。勢いをつけた一撃は重いが、槍衾・障害・伏兵で止まる。→ 突撃に**運動量**を入れ、止める駆け引きを作る。
6. **ぶつかれば揉み合う**。至近の乱戦は射程も陣形も意味が薄れ、頭数と武力がものを言う。→ 遠距離戦に**近接の押し引き**を足す。
7. **デッキは予算内の取捨選択**。コストの中で精鋭少数か数の暴力かを選ぶ。→ 1会戦の**出撃コスト予算**で編成にトレードオフを足す。

## 2. 取り入れるべきメカニクス（優先度つき・既存への接続）

> 大原則：**`ActiveCommandRules`#2175／`FormationMatchupRules`#2177／`TalentCatalog`#特技／`FleetMorale`（士気）／要塞#76-78 を作り直さない**。SGT はそれらに**欠落軸を足し、接続する**だけ（additive）。三国志大戦の「士気」は本作の `FleetMorale`（＝士気・能力補正/敗走）と別概念なので、新リソースは **采配ゲージ（command gauge）** と命名して混同を避ける。

### ★★★ 最優先（真の欠落・三国志大戦の signature）

#### SGT 采配ゲージ＝時間で貯まる資源で戦法を撃つ経済
- **采配ゲージ**：会戦中、味方陣営に**時間で蓄積する有限リソース**（上限あり）。各戦法に**采配コスト**を設定し、貯めて大技／小刻みに小技、の配分を選ばせる。
- 接続：新 `CommandGaugeRules`/`CommandGauge`（Core・純ロジック・test-first）。`ActiveCommandRules` の発動可否に**コスト**を足す（cooldown と併存・置換しない）。`FleetMorale`（士気）とは別物。

#### SGT 号令・采配＝全軍/範囲の同時強化アクティブ
- **号令**：采配ゲージを大きく消費し、**全自軍（または範囲内の味方）**の能力（攻撃/機動/被ダメ）を一斉に底上げする大技。攻め時を作る一手。
- 接続：新 `ArmyCommandRules`（Core・`ActiveCommandRules` の全軍版＝倍率は `CombatModifiers`/`ModifierStack` に積む）。消費は SGT-1 の采配ゲージ。提督の階級/能力で範囲・効果が変わる。

#### SGT 知力が会戦戦法に効く（威力・抵抗・成功率・効果時間）
- 戦法/号令の**威力・効果時間**を発動側 `EffectiveIntelligence` で増減、**妨害/ダメージ計略の抵抗・成功率**を対象側 `EffectiveIntelligence` で決める＝**頭脳が武力を覆す**。
- 接続：新 `StrategemPowerRules`（Core・実効値パターン）。`ActiveCommandRules`/`ArmyCommandRules` の効果量へ係数で橋渡し（`CombatModifiers` 方針）。眠っている知力に会戦での役割を与える。

### ★★ 高（会戦の駆け引きを厚くする）

#### SGT 艦種の三すくみ（兵種相性のじゃんけん・ShipClass 間）
- 艦種（戦艦/巡航艦/駆逐艦/空母…＝`ShipClass`#80）どうしに**相性倍率**（じゃんけん）。編成と当て方に意味を足す。
- 接続：新 `ShipClassMatchupRules`（Core・`FormationMatchupRules` の**艦種版**＝別軸）。`ShipCombat.ComputeDamage` が陣形相性と並べて消費。

#### SGT 突撃の助走ボーナス（運動量→突撃ダメージ・止められる）
- 突撃の威力を**助走距離・速度（運動量）**で増減。槍衾的な迎撃・障害（ブラックホール/小惑星）・**伏兵**（SGT-8）で**突撃状態が解除**される。
- 接続：新 `ChargeMomentumRules`（Core）。`ActiveCommand 突撃`（#2175）＋`ShipCombat`＋`FleetMovement`（速度）に橋渡し。

#### SGT 乱戦＝近接の揉み合い（押し引き）
- 至近で敵味方が**接触すると乱戦**：射界・陣形の寄与が下がり**兵力×武力**が支配的に、**相互に減速**して揉み合う（押し引き）。
- 接続：新 `MeleeBrawlRules`（Core）。`ShipCombat`（至近距離補正）＋既存の混雑/分離（congestion/separation）に押し引きとして接続。

### ★ 中（編成の駆け引き・伏兵）

#### SGT コスト制の出撃編成（出撃ポイント予算でデッキ）
- 1会戦の**出撃ポイント予算**内で、精鋭少数（高コスト）か数の暴力（低コスト多数）かを選ぶドラフト。
- 接続：新 `SortieCostRules`（Core）。`FleetPool`/`FleetRoster`/`ScenarioData` の編成に**予算制約**を足す（総プール配分#148 を作り直さず接続）。

#### SGT 伏兵（潜伏→接触で奇襲・知力依存・突撃を止める）
- 伏せた部隊は**接触するまで不可視**、接触で**奇襲ダメージ**（発動側 `EffectiveIntelligence` 依存・SGT-3）＋敵の**突撃を解除**（SGT-5）。
- 接続：新 `AmbushRules`（Core）。偵察艦#119（隠密の系譜）＋`ShipCombat`＋SGT-3/SGT-5 に接続。

### ❌ 不採用（重複・既存で十分・性質が異なる）

| 不採用 | 理由 |
|---|---|
| 武将の特技パッシブ（魅力/勇猛/防柵…） | **`TalentCatalog`#特技 が既にカバー**。新特技はカタログ登録のみ（SGT で別実装しない） |
| 陣形の三すくみ | **`FormationMatchupRules`#2177 が既存**（SGT-4 は**艦種版**＝別軸で接続） |
| 単艦アクティブ戦法そのもの | **`ActiveCommandRules`#2175 が既存**（SGT-1/2 は采配資源化・全軍化で**拡張**） |
| 士気（能力補正・敗走） | **`FleetMorale`（士気）が既存**（SGT-1 は別概念の**采配ゲージ**） |
| 城門・拠点の攻防 | **要塞#76-78・勝利条件`要塞攻略/防衛` が既存**（接続のみ） |
| カード収集/レア度/課金/ランカー/対人マッチング | ゲームの性質が異なる（本作は1人用の戦略＝無関係） |
| カードを物理スライドで操作する操作系 | **`FleetCommander` の選択/指揮UI で代替**＝マイクロ操作を増やさない（タイクン化回避） |

### 推奨着手順
`SGT-1 → SGT-2 → SGT-3`（采配ゲージ→号令→知力＝三国志大戦の駆け引きの核三本）→ `SGT-4 → SGT-5`（艦種相性→突撃運動量＝会戦の当て方）→ `SGT-8`（伏兵＝突撃を止める駆け引き）→ `SGT-6`（乱戦）→ `SGT-7`（出撃編成）。

> いずれも既存会戦ロジック（`ActiveCommandRules`/`FormationMatchupRules`/`TalentCatalog`/`FleetMorale`/要塞）を**後退させず接続・拡張**する additive 設計。タイクン化回避（高位の決断→エンジン→創発帰結）。
