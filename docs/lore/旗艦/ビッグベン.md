# ビッグベン

> 刻を告げる大時鐘の名を負う、猛攻の旗艦。

## 概要
[[アウレリア・ファルケンハイト]]（PER-002）の専用旗艦。名は失われた故郷の世界遺産・ウェストミンスターの**大時鐘ビッグベン**に因む。鐘が刻を告げて時を制するように、機先を制して斬り込むアウレリアの攻めの戦を象徴する。

## 座乗提督
- [[アウレリア・ファルケンハイト]]（[[黎明評議会]]の少尉・元貴族）。専用旗艦＝`signatureShipName`＝「ビッグベン」で固定。

## 来歴・戦歴
- 親友[[ミレイア・セルウィン]]の旗艦[[グリニッジ]]（航海の基準点）と対をなす。**標準時のグリニッジ／大時鐘のビッグベン**――時を司る二艦が、攻守の対として並ぶ。
