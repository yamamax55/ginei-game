# {{title}}の軍編成（order of battle）

> 勢力の総艦艇（`FleetPool`）を梯団（`OrderOfBattle`/`MilitaryFormation`）に編制し、艦隊（`FleetUnitData`）へ司令を配属する見取り図。兵力・指揮官は scenario/runtime で変動（正は `FleetRoster`）。

## ドクトリン（戦法・陣形）
- **戦法**：（勢力の tactics）
- **推奨陣形**：（勢力の formation）＝自動切替は `FormationDoctrineRules`（#5）
- **編成思想**：（物量で押すか／遊撃・私掠か／連携・包囲か／速攻集中か／要塞・傭兵か）

## 梯団階層（`EchelonType` ＋ 階級対応）
> 序列：戦隊 ＜ 分艦隊 ＜ **艦隊**（基幹・約1.2〜1.5万隻）＜ 軍団 ＜ 軍 ＜ 軍集団（方面軍）＜ 宇宙艦隊（総軍）。必要階級は `OrderOfBattle.RequiredTier`／`CommandCapacityRules.EchelonForTier`。

| 梯団 | 規模 | 指揮階級 |
|---|---|---|
| 戦隊 | 数百〜千隻 | 大佐相当 |
| 分艦隊 | 数千隻 | 准将／少将 |
| **艦隊** | 約1.2〜1.5万隻（基幹単位） | 中将／大将 |
| 軍団 | 複数艦隊 | 大将／中将 |
| 軍／軍集団 | 方面軍 | 元帥／上級大将 |
| 宇宙艦隊 | 総軍 | 元帥（総司令） |

## 兵力プール（`FleetPool` → 配分 `FleetPoolRules`）
- 総保有艦艇を各艦隊の `baseStrength` 合計が超えないよう配分。建艦（`ShipyardRules.CommissionToPool`）で増え、会戦で盤面戦力が減ってもプール総数は別管理。
